## Putnam 2020 questions (Kedlaya archive community mirror) · A1（`putnam-2020-AB-questions-qA1`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:基础热身 / 奇偶与同余 / 变量代换与重参数化 / 易错:边界与退化情形 / 易错:计数重复与漏算
- **知识专题**：初等数论 / 同余与整除 / 组合计数

### 原题整理

有多少个正整数 \(N\) 同时满足以下三个条件：
(i) \(N\) 能被 \(2020\) 整除；
(ii) \(N\) 的十进制表示至多有 \(2020\) 位；
(iii) \(N\) 的十进制数字由一串连续的 \(1\) 后接一串连续的 \(0\) 组成。

### 1. 只看原题盲解尝试

**切入思路**：将十进制由连续 \(a\) 个 \(1\) 后接连续 \(b\) 个 \(0\) 组成的正整数表示为 \(N = \frac{10^a - 1}{9} \cdot 10^b\)，分解 \(2020 = 2^2 \times 5 \times 101\) 后分别利用整除条件确定 \(a, b\) 的限制，再在位数约束 \(a + b \le 2020\) 下对等差数列求和计数。

**推演步骤**：
- 由条件 (iii) 及 \(N\) 为正整数，设 \(N\) 的十进制表示由 \(a\) 个 \(1\) 后接 \(b\) 个 \(0\) 组成，其中 \(a \ge 1\)，\(b \ge 0\)。则 \[N = \frac{10^a - 1}{9} \cdot 10^b,\] 且 \(N\) 的位数为 \(a + b\)。不同的有序对 \((a, b)\) 对应不同的正整数 \(N\)。由条件 (ii) 得 \(a + b \le 2020\)。
- 将 \(2020\) 质因数分解得 \(2020 = 2^2 \times 5 \times 101\)。条件 (i) 等价于 \(4 \mid N\)、\(5 \mid N\) 且 \(101 \mid N\)。由于 \(\frac{10^a - 1}{9}\) 的个位数字是 \(1\)，它与 \(2\) 和 \(5\) 都互素，因此 \(2^2 \times 5 \mid N\) 等价于 \(2^2 \times 5 \mid 10^b\)，即 \(b \ge 2\)。
- 因为 \(\gcd(101, 9) = 1\) 且 \(\gcd(101, 10^b) = 1\)，所以 \(101 \mid N\) 等价于 \(101 \mid (10^a - 1)\)，即 \(10^a \equiv 1 \pmod{101}\)。注意到 \(10^2 = 100 \equiv -1 \pmod{101}\)，从而 \(10^1 \equiv 10\)，\(10^2 \equiv -1\)，\(10^3 \equiv -10\)，\(10^4 \equiv 1 \pmod{101}\)，故 \(10\) 模 \(101\) 的阶为 \(4\)。于是 \(101 \mid (10^a - 1)\) 当且仅当 \(4 \mid a\)。设 \(a = 4k\)（\(k \ge 1\) 为正整数）。
- 综合上述条件，合法的 \((a, b)\) 等价于整数对 \((k, b)\) 满足 \(k \ge 1\)，\(b \ge 2\)，且 \(4k + b \le 2020\)。由 \(2 \le b \le 2020 - 4k\) 可知 \(4k \le 2018\)，故 \(1 \le k \le \lfloor 2018 / 4 \rfloor = 504\)。对于每个固定的 \(k \in \{1, 2, \dots, 504\}\)，\(b\) 的合法取值个数为 \((2020 - 4k) - 2 + 1 = 2019 - 4k\)。
- 对所有 \(k = 1, 2, \dots, 504\) 求和，这是一个首项为 \(2019 - 4 = 2015\)、末项为 \(2019 - 4 \times 504 = 3\)、共 \(504\) 项的等差数列，总数为 \[\sum_{k=1}^{504} (2019 - 4k) = \frac{(2015 + 3) \times 504}{2} = 1009 \times 504 = 508536.\]

**盲解结论**：满足条件的正整数 \(N\) 共有 \(508536\) 个。

### 2. 对照答案复盘

盲解（Turn 1）与参考解答结论完全一致，均得到正确答案 \(508536\)，核心数论推导（质因数分解 \(2020 = 2^2 \cdot 5 \cdot 101\)、分离 \(10^b\) 与 \(10^{a-b}-1\) 的整除性、利用 \(10^2 \equiv -1 \pmod{101}\) 得到阶为 \(4\)）完全相同。主要差异在于参数化与求和顺序：参考解答以总位数 \(a\) 和末尾 \(0\) 的个数 \(b\) 参数化为 \(N = (10^a - 10^b)/9\)，先消去 \(9=3^2\) 的整除条件，再固定 \(b\) 对 \(a\) 计数得到 \(\lfloor (2020-b)/4 \rfloor\) 并按每 \(4\) 项分组求和；而盲解直接以 \(1\) 的个数与 \(0\) 的个数参数化，先固定 \(1\) 的个数为 \(4k\) 再对 \(0\) 的个数计数，直接化为等差数列 \(\sum_{k=1}^{504}(2019-4k)\) 求和，避免了取整函数的端点分组讨论。两种参数化均为完全严谨的有效解法。

### 3. 困难点与破局关键

- **数字形态的代数参数化**：把“一串连续的 \(1\) 后接一串连续的 \(0\)”这一数字模式改写为代数式 \(N = \frac{10^a - 10^b}{9} = \frac{10^b(10^{a-b}-1)}{9}\)，从而将整除与位数限制一并转化为关于两个整数参数 \((a, b)\) 的算术条件。
- **整除条件的互素分解与变量解耦**：将合数模 \(2020\) 拆分为两两互素的模 \(4\)、\(5\)、\(101\)，分别作用于表达式的不同因子：\(10^b\) 单独承担 \(2^2 \cdot 5\) 的整除要求，而 \(10^{a-b}-1\) 单独承担 \(101\)（及 \(9\)）的整除要求，实现了变量 \(b\) 与变量 \(a-b\) 的彻底解耦。

### 4. 问题拆解（教学引导）

- **识别结构化特征并建立参数表示**：题目要求统计满足三个条件的正整数 \(N\)：被 \(2020\) 整除、位数不超过 \(2020\)、十进制数字先是连续的 \(1\) 再是连续的 \(0\)。由于结构高度受限，应优先用少量整数参数唯一刻画所有满足位数与数字形态（即条件 (ii)、(iii)）的整数。
- **将十进制数字串转化为指数差表达式**：观察到 \(11\dots 100\dots 0\) 可写为两段十进制幂之差除以 \(9\)，即设总位数为 \(a\)、末尾 \(0\) 的个数为 \(b\)，则 \(N = \frac{10^a - 10^b}{9}\)，其中 \(0 \le b < a \le 2020\)（因为 \(N > 0\) 至少有一位 \(1\)，故 \(a > b\)）。
- **分解模数并把整除条件分离到独立因子上**：将合数除数 \(2020\) 做质因数分解 \(2020 = 2^2 \cdot 5 \cdot 101\)，把整除条件 \(2020 \mid N\) 转化为分子 \(10^b(10^{a-b}-1)\) 同时被 \(3^2\)、\(2^2 \cdot 5\) 和 \(101\) 整除，再利用互素性质逐个剥离对 \(b\) 和 \(a-b\) 的约束。

### 5. 答案拆解（逻辑骨架）

- **建立双参数代数模型**（*动机*：将离散的十进制数位描述精确转化为双参数代数表达式，使得整除判定与计数可以同时落在 \((a, b)\) 上。）：所有满足条件 (ii) 与 (iii) 的正整数 \(N\) 恰好具有形式 \(N = \frac{10^a - 10^b}{9}\)，其中 \(0 \le b < a \le 2020\)。这唯一对应总位数为 \(a\)、前 \(a-b\) 位为 \(1\)、后 \(b\) 位为 \(0\) 的十进制正整数。
- **分解 \(2020\) 并消去分母 \(9\) 的影响**（*动机*：先把分母 \(9\) 转化为分子被 \(3^2\) 整除的条件，并验证其对所有参数恒成立，避免后续同余分析中被分数干扰。）：因为 \(2020 = 2^2 \cdot 5 \cdot 101\)，\(N = \frac{10^b(10^{a-b}-1)}{9}\) 能被 \(2020\) 整除当且仅当分子 \(10^b(10^{a-b}-1)\) 同时被 \(3^2\)、\(2^2 \cdot 5\) 和 \(101\) 整除。由于 \(10 \equiv 1 \pmod 9\)，\(9 \mid (10^{a-b}-1)\) 恒成立，故分母 \(9\) 的整除条件自动满足。
- **分别求解 \(2^2 \cdot 5\) 与 \(101\) 的整除条件**（*动机*：分别利用 \(\gcd(10^{a-b}-1, 10) = 1\) 和 \(\gcd(10^b, 101) = 1\)，把原本耦合在同一个数中的两个因子完全拆开，各自独立转化为简单的下界与同余条件。）：由于 \(a - b \ge 1\)，\(10^{a-b} - 1\) 为奇数且末位是 \(9\)（与 \(2, 5\) 均互素），因此 \(2^2 \cdot 5 \mid 10^b(10^{a-b}-1)\) 当且仅当 \(2^2 \cdot 5 \mid 10^b\)，即 \(b \ge 2\)。又因为 \(\gcd(101, 10^b) = 1\)，\(101 \mid 10^b(10^{a-b}-1)\) 等价于 \(10^{a-b} \equiv 1 \pmod{101}\)。利用 \(10^2 = 100 \equiv -1 \pmod{101}\)，可得 \(10^{a-b}\) 模 \(101\) 按 \(a - b \equiv 1, 2, 3, 0 \pmod 4\) 依次同余于 \(10, -1, -10, 1\)，从而 \(101 \mid (10^{a-b} - 1)\) 当且仅当 \(4 \mid (a - b)\)。
- **转化为格点计数并分组求和**（*动机*：在所有数论约束彻底化为线性不等式与整除条件后，选择合适的求和顺序（或利用商每 \(4\) 步递减 \(1\) 的周期性）避免逐项枚举并防止端点差错。）：问题归结为计数整数对 \((a, b)\)，满足 \(2 \le b < a \le 2020\) 且 \(4 \mid (a - b)\)。对固定的 \(b \in \{2, 3, \dots, 2020\}\)，合法的 \(a\) 形如 \(b + 4k\)（\(1 \le k \le \lfloor \frac{2020 - b}{4} \rfloor\)），共有 \(\lfloor \frac{2020 - b}{4} \rfloor\) 个。将 \(b = 2, 3, \dots, 2016\) 对应的商按模 \(4\) 分组写出，有 \(3\) 个 \(504\)（对应 \(b=2,3,4\)）以及各 \(4\) 个 \(503, 502, \dots, 1\)，因此总数为 \[4(504 + 503 + \dots + 1) - 504 = 4 \cdot \frac{504 \times 505}{2} - 504 = 504 \times 1009 = 508536.\]（等价地，也可先固定 \(a - b = 4k\)，对 \(k = 1, \dots, 504\) 直接将 \(b\) 的个数 \(2019 - 4k\) 按等差数列求和，同样得 \(508536\)。）

### 6. 易错点分析

- **忽视因子 \(4\) 而误取 \(b \ge 1\)**：常见错法——误以为被 \(2020\) 整除只需末尾至少有 \(1\) 个 \(0\)（即 \(b \ge 1\)），漏掉 \(4 \mid N\) 对末尾至少两个 \(0\) 的要求。；错因——因为 \(2020 = 4 \times 5 \times 101\) 含有 \(2^2\)，而所有 \(1\) 组成的数（或 \(10^{a-b}-1\)）是奇数，故全部 \(2^2\) 因子必须由 \(10^b\) 提供，仅 \(b=1\) 只能提供 \(2^1\)，无法被 \(4\) 整除。；避坑策略——先检查 \(N\) 被 \(2^2 \cdot 5\) 整除的局部尾数条件：由于 \(1\) 后面至少要有 \(2\) 个 \(0\) 才能被 \(4\) 整除（否则十位为 \(1\)、个位为 \(0\) 的数模 \(4\) 余 \(2\)），明确写出 \(b \ge 2\) 这一不等式后再讨论 \(a\)。
- **按余数分组求和时的端点多算或漏算**：常见错法——在按 \(b\) 分类计数 \(\lfloor (2020 - b)/4 \rfloor\) 时误以为每个整数商都出现 \(4\) 次，从而写成 \(4(504 + 503 + \dots + 1)\)，多算了 \(b=1\) 对应的一项。；错因——当 \(b\) 从 \(2\) 取到 \(2016\) 时，\(2020 - b\) 从 \(2018\) 降到 \(4\)。其中商为 \(504\) 的 \(2020 - b\) 只有 \(2018, 2017, 2016\) 共 \(3\) 个，比完整的一组少 \(1\) 个（缺少 \(b=1\) 对应的 \(2019\)），直接乘 \(4\) 会多计入 \(504\)。；避坑策略——对最小临界值与最大临界值做小规模代入检验，例如将上限 \(2020\) 替换为 \(8\) 或 \(12\) 手算计数，或用分组求和式 \(4(504+\dots+1)-504\) 与换序后的等差数列求和交叉验算。
- **混淆 \(10^k \equiv -1\) 与 \(10^k \equiv 1\) 的同余周期**：常见错法——看到 \(10^2 \equiv -1 \pmod{101}\) 后误以为周期为 \(2\)，或者错误地将 \(10^{a-b} \equiv 1 \pmod{101}\) 写成 \(2 \mid (a-b)\)。；错因——\(10^2 \equiv -1 \pmod{101}\) 说明 \(10^{2} - 1 \equiv -2 \not\equiv 0 \pmod{101}\)，\(a-b=2\) 对应的 \(1100\) 并不能被 \(101\) 整除；只有平方两次得到 \(10^4 \equiv 1 \pmod{101}\)，才要求 \(4 \mid (a-b)\)。；避坑策略——通过阶的定义逐次验证 \(10^1, 10^2, 10^3, 10^4 \pmod{101}\)，并结合欧拉定理确认阶必须整除 \(\varphi(101)=100\)，不要仅凭单个同余式直接断定指数周期。

**教学小结**：面对十进制数字串的整除问题，应先将其代数化为 \(10\) 的幂的线性组合，再对模数作两两互素的质因数分解，使不同素因子幂分别由最容易处理的指数因子承担；此外，在双变量计数中若出现取整函数，往往可以通过交换求和次序（先固定整除倍数参数）直接化为无取整的等差数列求和以降低出错率。

## Putnam 2023 questions (Kedlaya archive community mirror) · A1（`putnam-2023-AB-questions-qA1`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:基础热身 / 放缩与估值 / 生成函数与多项式 / 易错:计算精度与等价替换 / 易错:符号与方向
- **知识专题**：微积分 / 泰勒展开与高阶导数 / 数列求和

### 原题整理

对于正整数 \(n\)，令 \(f_n(x) = \cos(x)\cos(2x)\cos(3x)\cdots\cos(nx)\)。求满足 \(|f_n''(0)| > 2023\) 的最小正整数 \(n\)。

### 1. 只看原题盲解尝试

**切入思路**：利用余弦函数在 \(x=0\) 处的泰勒展开（或对数求导法）直接求出 \(f_n''(0)\) 的闭式表达式，进而将其转化为平方和不等式 \(\sum_{k=1}^n k^2 > 2023\)，估算并验证最小正整数 \(n\)。

**推演步骤**：
- 将每个因子在 \(x=0\) 处作泰勒展开：对任意正整数 \(k\)，有 \[\cos(kx) = 1 - \frac{k^2}{2}x^2 + O(x^4)\]。
- 将 \(n\) 个因子相乘，只保留到 \(x^2\) 项，得到 \[f_n(x) = \prod_{k=1}^n \left(1 - \frac{k^2}{2}x^2 + O(x^4)\right) = 1 - \left(\frac{1}{2}\sum_{k=1}^n k^2\right)x^2 + O(x^4)\]。
- 另一方面，由泰勒公式 \(f_n(x) = f_n(0) + f_n'(0)x + \frac{f_n''(0)}{2}x^2 + O(x^3)\)，比较 \(x^2\) 的系数可得 \[f_n''(0) = -\sum_{k=1}^n k^2 = -\frac{n(n+1)(2n+1)}{6}\]。因此 \(|f_n''(0)| = \frac{n(n+1)(2n+1)}{6}\)，且其随 \(n\) 严格递增。
- 令 \(\frac{n(n+1)(2n+1)}{6} > 2023\)，即 \(n(n+1)(2n+1) > 12138\)。注意到 \(2n^3 \approx 12138\) 给出 \(n \approx 18.2\)，分别代入 \(n=17\) 与 \(n=18\) 检验：当 \(n=17\) 时，\[|f_{17}''(0)| = \frac{17 \times 18 \times 35}{6} = 1785 \le 2023\]；当 \(n=18\) 时，\[|f_{18}''(0)| = 1785 + 18^2 = 1785 + 324 = 2109 > 2023\]。
- 由于 \(|f_n''(0)|\) 关于 \(n\) 单调递增，故满足条件的最小正整数为 \(n = 18\)。

**盲解结论**：\(18\)

### 2. 对照答案复盘

盲解结果与标准答案完全一致，最终均得到 \(n=18\)。方法上略有差异：标准解答直接对乘积函数使用广义乘积求导法则（莱布尼茨法则），利用 \(\sin(0)=0\) 使所有一阶导交叉项在 \(x=0\) 处消去，仅保留单个因子求二阶导的项；盲解则通过各因子在 \(x=0\) 处的泰勒展开至 \(x^2\) 项直接比较系数，二者本质等价且计算量相当。

### 3. 困难点与破局关键

- **避免 \(n\) 重乘积求导的组合爆炸**：当 \(n\) 较大时，直接展开 \(f_n'(x)\) 再求导会产生大量含正弦与余弦乘积的项。解题的关键在于提前利用 \(x=0\) 这一局部性质——即 \(\cos(0)=1\) 且 \((\cos kx)'|_{x=0} = -k\sin(0) = 0\)，从而避开繁琐的全局求导。
- **三次不等式的快速定位与精确验证**：解三次不等式 \(\frac{n(n+1)(2n+1)}{6} > 2023\) 时，不宜硬解三次方程，而应利用单调性与主项近似 \(n^3/3 \approx 2023\) 快速定位候选整数，再通过精确算术验证相邻两个整数的界限。

### 4. 问题拆解（教学引导）

- **识别局部特征（仅需 \(x=0\) 处的二阶导数）**：题目要求 \(f_n''(0)\) 而非一般的 \(f_n''(x)\)，这意味着求导与代入 \(x=0\) 可以结合处理，重点关注各个因子 \(\cos(kx)\) 在 \(x=0\) 处的各阶导数信息（\(0\) 阶为 \(1\)，\(1\) 阶为 \(0\)，\(2\) 阶为 \(-k^2\)）。
- **选择乘积转求和的工具**：由于 \(f_n(x)\) 是 \(n\) 个函数之积，求二阶导时既可以用广义乘积求导法则，也可以用泰勒展开（截断到 \(x^2\) 项）或对数求导法，三条路径都能将乘积转化为求和。
- **转化为离散单调不等式求解**：得到 \(|f_n''(0)|\) 关于 \(n\) 的显式表达式后，利用其单调性，将存在性问题转化为求解最小正整数 \(n\) 满足不等式。

### 5. 答案拆解（逻辑骨架）

- **用莱布尼茨法则分类展开二阶导数**（*动机*：直接计算 \(n\) 个函数乘积的二阶导数时，按每个因子被求导的次数对各项分类，可使结构最清晰。）：利用广义乘积求导法则计算 \(f_n''(x)\)，所有项按求导分配方式分为两类：第一类是两个不同因子 \(\cos(m_1 x)\) 与 \(\cos(m_2 x)\) 各求导一次；第二类是单个因子 \(\cos(mx)\) 求导两次，其余因子不求导。
- **代入 \(x=0\) 消去交叉项并求和**（*动机*：利用 \(\cos(0)=1\) 与 \(\sin(0)=0\) 的特殊性质，使第一类交叉项整体消去，将乘积求导简化为平方和。）：代入 \(x=0\) 时，第一类项中均含有 \(\sin(m_1 \cdot 0) = 0\)，因此全部为零；第二类项中未求导的因子 \(\cos(0)=1\)，而 \((\cos(mx))''|_{x=0} = -m^2\)。求和即得 \(f_n''(0) = -\sum_{m=1}^n m^2\)，从而 \(|f_n''(0)| = \frac{n(n+1)(2n+1)}{6}\)。
- **利用单调性与主项估算确定临界整数**（*动机*：借助单调性与主项近似避免求解一般三次方程，只需验证临界处的两个连续整数即可严谨定界。）：令 \(g(n) = \frac{n(n+1)(2n+1)}{6}\)，显然 \(g(n)\) 在正整数集上严格递增。估算 \(n^3/3 \approx 2023\) 得 \(n \approx 18.2\)，直接计算 \(g(17) = 1785 \le 2023\) 与 \(g(18) = 2109 > 2023\)，因此最小正整数为 \(n=18\)。

### 6. 易错点分析

- **混淆泰勒展开系数与二阶导数值**：常见错法——在用泰勒展开求二阶导数时，直接将 \(x^2\) 的系数 \(-\frac{1}{2}\sum_{k=1}^n k^2\) 当作 \(f_n''(0)\)，漏掉乘以 \(2! = 2\)。；错因——泰勒级数中 \(x^2\) 的系数是 \(\frac{f_n''(0)}{2!}\)，而非 \(f_n''(0)\) 本身，漏掉系数 \(2\) 会导致结果缩小一半，进而得出错误阈值。；避坑策略——用标准函数（如 \(f_1(x)=\cos x\)，此时 \(f_1''(0)=-1\)）校验系数，明确写出 \(\frac{f_n''(0)}{2!}\) 与 \(x^2\) 项系数的对应关系。
- **仅凭渐近估算直接下结论而忽略精确边界检验**：常见错法——仅通过主项近似 \(\frac{n^3}{3} > 2023\)（即 \(n > \sqrt[3]{6069} \approx 18.24\)）就直接取 \(n=19\)，未代入边界整数验证。；错因——\(\frac{n(n+1)(2n+1)}{6} = \frac{n^3}{3} + \frac{n^2}{2} + \frac{n}{6}\) 比主项 \(\frac{n^3}{3}\) 更大，忽略低阶正项会低估实际数值，导致答案偏大 \(1\)。；避坑策略——在利用 \(\frac{n^3}{3} \approx 2023\) 估算出 \(n \approx 18.2\) 后，务必分别精确计算相邻整数 \(n=17\) 与 \(n=18\) 对应的精确值 \(1785\) 和 \(2109\)，确认 \(1785 \le 2023 < 2109\)。
- **高阶乘积求导时未及时利用在 \(x=0\) 处的零值性质化简**：常见错法——使用乘积求导法则时，漏算或错算交叉项，或者误以为需要展开全部 \(n^2\) 项后逐一求和。；错因——若不先观察到 \((\cos kx)'|_{x=0} = 0\)，直接硬算 \(f_n'(x)\) 再求导会使表达式迅速膨胀，容易在代数整理中出错。；避坑策略——在展开乘积或应用莱布尼茨求导法则前，先检查各因子的奇偶性或一阶导数在目标点的值（\(\cos'(0)=0\)），并严格按照“各因子求导次数之和为 \(2\)”进行无遗漏分类。

**教学小结**：求解多因子乘积在特定点处的低阶导数时，优先利用泰勒截断展开或“带零点消元的广义乘积法则”，能在第一时间把复杂的乘积结构化简为简单求和。

## Putnam 2023 questions (Kedlaya archive community mirror) · A2（`putnam-2023-AB-questions-qA2`）

- **学段**：本科 · **盲解结果**：盲解完全正确

- **知识专题**：多项式 / 因式分解 / 根与系数关系

### 原题整理

设 \(n\) 为正偶数，\(p\) 为首一的 \(2n\) 次实系数多项式，即 \(p(x) = x^{2n} + a_{2n-1}x^{2n-1} + \cdots + a_1 x + a_0\)，其中 \(a_0, \dots, a_{2n-1} \in \mathbb{R}\)。已知对所有满足 \(1 \le |k| \le n\) 的整数 \(k\)，均有 \(p(1/k) = k^2\)。求所有其他满足 \(p(1/x) = x^2\) 的实数 \(x\)。

### 1. 只看原题盲解尝试

**切入思路**：构造辅助多项式 \(Q(x) = x^{2n+2} - x^{2n}p(1/x)\)，利用 \(p(x)\) 为首一 \(2n\) 次多项式确定 \(Q(x)\) 的次数、首项系数、\(x^{2n+1}\) 项系数以及常数项 \(Q(0)\)，再结合已知的 \(2n\) 个整数根 \(\pm 1, \pm 2, \dots, \pm n\) 完成因式分解，从而求出其余实根。

**推演步骤**：
- 首先注意 \(x = 0\) 不在方程 \(p(1/x) = x^2\) 的定义域内。对任意非零实数 \(x\)，方程 \(p(1/x) = x^2\) 等价于 \(x^{2n+2} - x^{2n}p(1/x) = 0\)。
- 定义多项式 \[Q(x) = x^{2n+2} - x^{2n}p(1/x) = x^{2n+2} - a_0 x^{2n} - a_1 x^{2n-1} - \cdots - a_{2n-1}x - 1\]。 由表达式可知，\(Q(x)\) 是首一的 \(2n+2\) 次实系数多项式，其中 \(x^{2n+1}\) 项的系数为 \(0\)，且常数项 \(Q(0) = -1\)。
- 由题意，对所有满足 \(1 \le |k| \le n\) 的整数 \(k\)，均有 \(p(1/k) = k^2\)，故 \(Q(k) = 0\)。因此 \(Q(x)\) 被 \(\prod_{k=1}^{n}(x^2 - k^2)\) 整除。由于 \(Q(x)\) 是首一的 \(2n+2\) 次多项式，可设 \[Q(x) = (x^2 + bx + c)\prod_{k=1}^{n}(x^2 - k^2)\]， 其中 \(b, c \in \mathbb{R}\)。
- 比较等式两边 \(x^{2n+1}\) 项的系数：由于 \(\prod_{k=1}^{n}(x^2 - k^2)\) 只含 \(x\) 的偶次幂，右边 \(x^{2n+1}\) 项的系数为 \(b\)，而左边该项系数为 \(0\)，因此 \(b = 0\)。
- 代入 \(x = 0\)，得 \[Q(0) = c \prod_{k=1}^{n}(-k^2) = c(-1)^n (n!)^2\]。 因为 \(n\) 是正偶数，所以 \((-1)^n = 1\)，从而 \(c(n!)^2 = -1\)，解得 \(c = -\frac{1}{(n!)^2}\)。
- 于是 \[Q(x) = \left(x^2 - \frac{1}{(n!)^2}\right)\prod_{k=1}^{n}(x^2 - k^2)\]。 其除了 \(\pm 1, \pm 2, \dots, \pm n\) 之外的实根为 \(x = \pm \frac{1}{n!}\)。又因 \(n \ge 2\) 为偶数，有 \(0 < \frac{1}{n!} \le \frac{1}{2} < 1\)，故 \(\pm \frac{1}{n!}\) 非零且均不在 \(\{\pm 1, \pm 2, \dots, \pm n\}\) 中。因此所求的其余实数 \(x\) 为 \(\pm \frac{1}{n!}\)。

**盲解结论**：满足 \(p(1/x) = x^2\) 的其余实数 \(x\) 为 \(x = \frac{1}{n!}\) 和 \(x = -\frac{1}{n!}\)（即 \(x = \pm \frac{1}{n!}\)）。

### 2. 对照答案复盘

盲解与参考解答完全一致，均通过构造辅助多项式 \(Q(x) = x^{2n+2} - x^{2n}p(1/x)\)，利用已知的 \(2n\) 个根进行因式分解，再比较 \(x^{2n+1}\) 项系数与常数项 \(x^0\) 系数，最终求得唯一多出的两个实根 \(\pm \frac{1}{n!}\)。

### 3. 困难点与破局关键

- **从 \(p(1/x) = x^2\) 到辅助多项式 \(Q(x)\) 的构造**：题目给出的是 \(p(1/k) = k^2\)，直接对 \(p\) 使用因式定理并不顺手（因为插值余项是 \(x^2\) 的函数而非固定常数）。关键跃迁在于乘以 \(x^{2n}\) 将倒数多项式 \(p(1/x)\) 转化为关于 \(x\) 的正规多项式，使方程化为单一多项式 \(Q(x) = 0\) 的求根问题。
- **利用高次缺项与常数项锁定剩余二次因子**：\(Q(x)\) 共有 \(2n+2\) 个复根，已知 \(2n\) 个根后还差一个首一二次因式 \(x^2 + ax + b\)。学生容易直觉认为需要求出 \(p(x)\) 的全部系数，但实际上只需观察到 \(Q(x)\) 缺 \(x^{2n+1}\) 项且常数项固定为 \(-1\)，即可直接锁定 \(a\) 和 \(b\)。

### 4. 问题拆解（教学引导）

- **统计自由度与唯一性**：注意到 \(p(x)\) 是首一的 \(2n\) 次多项式，共有 \(2n\) 个待定系数 \(a_0, \dots, a_{2n-1}\)，而题目恰好给出了 \(2n\) 个点值 \(p(1/k) = k^2\)（\(1 \le |k| \le n\)），这意味着 \(p(x)\) 被唯一确定。
- **去分母化归为多项式方程**：方程 \(p(1/x) = x^2\) 中同时出现了 \(1/x\) 和 \(x^2\)，不是直接关于 \(x\) 的多项式方程。将其两边同乘 \(x^{2n}\)（在 \(x \neq 0\) 的前提下），即可消去分母，转化为关于 \(x\) 的 \(2n+2\) 次多项式方程。
- **捕捉「\(n\) 为正偶数」这一结构线索**：题干特意强调「\(n\) 为正偶数」，在代数恒等变形中，奇偶性往往会在 \((-1)^n\) 处起决定性作用（例如决定根的判别式或二次项系数的正负）。

### 5. 答案拆解（逻辑骨架）

- **构造辅助多项式 \(Q(x)\)**（*动机*：消去 \(1/x\) 的分母，将问题转化为标准多项式求根。）：在 \(x \neq 0\) 时，\(p(1/x) = x^2\) 等价于 \(Q(x) = 0\)，其中 \[Q(x) = x^{2n+2} - x^{2n}p(1/x) = x^{2n+2} - (a_0 x^{2n} + a_1 x^{2n-1} + \cdots + a_{2n-1}x + 1)\]。 这样做的好处是把 \(p\) 的首项 \(1 \cdot (1/x)^{2n}\) 变成了 \(Q(x)\) 的常数项 \(-1\)，且 \(Q(x)\) 成为首一的 \(2n+2\) 次多项式，同时天然缺少 \(x^{2n+1}\) 项。
- **因式分解提取已知根**（*动机*：利用已知的 \(2n\) 个根大幅降低未知自由度，只留下 \(a, b\) 两个参数。）：因为 \(k \in \{\pm 1, \dots, \pm n\}\) 均满足 \(p(1/k) = k^2\)，所以这 \(2n\) 个非零整数都是 \(Q(x)\) 的根。由此可将 \(Q(x)\) 分解为 \[Q(x) = (x^2 + ax + b)\prod_{k=1}^{n}(x^2 - k^2)\]， 其中 \(x^2 + ax + b\) 为某个首一实二次多项式。
- **比较系数确定二次因子**（*动机*：无需计算 \(a_0, \dots, a_{2n-1}\)，仅凭 \(Q(x)\) 已知的两个系数直接确定 \(a, b\)。）：比较 \(Q(x)\) 展开式与因式分解式两边 \(x^{2n+1}\) 项的系数：由于 \(\prod_{k=1}^{n}(x^2 - k^2)\) 只含偶次幂，右边 \(x^{2n+1}\) 项系数就是 \(a\)，而左边为 \(0\)，故 \(a = 0\)。再比较常数项（即取 \(x = 0\)）：左边为 \(-1\)，右边为 \(b \prod_{k=1}^{n}(-k^2) = b(-1)^n (n!)^2\)。利用 \(n\) 为偶数得 \((-1)^n = 1\)，从而 \(b = -\frac{1}{(n!)^2}\)。
- **求根并验证互异性**（*动机*：完成求解并严格核验「非零」与「不同于已知根」的条件。）：由 \(x^2 - \frac{1}{(n!)^2} = 0\) 解得 \(x = \pm \frac{1}{n!}\)。因为 \(n\) 是正偶数，所以 \(n \ge 2\)，从而 \(0 < \frac{1}{n!} \le \frac{1}{2} < 1\)，这表明 \(\pm \frac{1}{n!}\) 既不为 \(0\)，也不与 \(\pm 1, \dots, \pm n\) 中的任何数重合，因此它们正是全部其余实根。

### 6. 易错点分析

- **常数项符号或 \((-1)^n\) 奇偶性出错**：常见错法——忽略 \(Q(0) = -1\) 的负号或未利用 \(n\) 为偶数的条件，误得 \(b = +\frac{1}{(n!)^2}\)，从而错误得出「不存在其他实根」的结论。；错因——\(Q(x) = x^{2n+2} - (a_0 x^{2n} + \cdots + a_{2n-1}x + 1)\) 的常数项为 \(-1\)（来自首一多项式 \(p\) 的首项 \(x^{2n}\)），而 \(\prod_{k=1}^{n}(x^2-k^2)\) 的常数项为 \((-1)^n (n!)^2\)；只有当 \(n\) 为偶数时两者比值才为负。；避坑策略——计算常数项时先明确写出 \(Q(x) = x^{2n+2} - x^{2n}p(1/x)\) 的展开式与常数项符号，并在最后一步显式利用「\(n\) 为偶数，故 \((-1)^n = 1\)」来确定 \(b < 0\)。
- **忽略定义域 \(x \neq 0\) 与根的互异性检验**：常见错法——直接等价变形而不排除 \(x = 0\)，或未验证所求出的根 \(\pm \frac{1}{n!}\) 确实不同于已知的 \(\pm 1, \dots, \pm n\)。；错因——题目要求的是「其他」满足 \(p(1/x) = x^2\) 的实数 \(x\)。若 \(n=1\)（虽不在本题正偶数范围内），\(\frac{1}{1!} = 1\) 就会与已有根重合；且 \(1/x\) 在 \(x=0\) 处无定义。；避坑策略——在乘以 \(x^{2n}\) 前注明 \(x \neq 0\)，在求得根后检查 \(\pm \frac{1}{n!} \neq 0\) 且由于 \(n \ge 2\) 有 \(0 < \frac{1}{n!} \le \frac{1}{2} < 1\)，确认它们与已知整数根互异。
- **陷入显式求解 \(p(x)\) 系数的繁琐计算**：常见错法——试图先通过拉格朗日插值求出 \(p(x)\) 的全部系数 \(a_0, \dots, a_{2n-1}\)，再代回解高次方程。；错因——虽然 \(2n\) 个条件确实唯一确定了 \(p(x)\)，但 \(n\) 是一般偶数，显式写出插值系数极其繁琐且毫无必要；实际上我们只关心 \(Q(x)\) 的两个极低/极高次项系数。；避坑策略——直接构造多项式 \(Q(x) = x^{2n+2} - x^{2n}p(1/x)\)，利用根的因式分解一次性跳过求 \(a_0, \dots, a_{2n-1}\) 的过程。

**教学小结**：遇到形如 \(p(1/x) = r(x)\) 的多项式插值或求根问题时，优先考虑乘以 \(x^{\deg p}\) 构造「倒数多项式」来消去分母，并通过观察高次缺项与常数项（往往由首一性决定）快速锁定未知低次因式。

## Putnam 2023 questions (Kedlaya archive community mirror) · A3（`putnam-2023-AB-questions-qA3`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 变量代换与重参数化 / 放缩与估值 / 构造与反例 / 易错:定义域与分母为零 / 易错:边界与退化情形 / 易错:隐含假设与越界推广
- **知识专题**：微分中值定理 / 极角代换 / 微分不等式

### 原题整理

求最小的正实数 \(r\)，使得存在可微函数 \(f:\mathbb{R}\to\mathbb{R}\) 和 \(g:\mathbb{R}\to\mathbb{R}\)，满足：
(a) \(f(0)>0\)；
(b) \(g(0)=0\)；
(c) 对所有 \(x\in\mathbb{R}\)，有 \(|f'(x)|\le |g(x)|\)；
(d) 对所有 \(x\in\mathbb{R}\)，有 \(|g'(x)|\le |f(x)|\)；
(e) \(f(r)=0\)。

### 1. 只看原题盲解尝试

**切入思路**：先通过构造特例 \(f(x)=\cos x, g(x)=\sin x\) 说明 \(r=\frac{\pi}{2}\) 是可行的。再证明对任意满足条件的 \(r>0\) 必有 \(r\ge\frac{\pi}{2}\)：首先取 \(f\) 在 \((0,r]\) 上的最小零点 \(r_0\)，在 \([0,r_0)\) 上考虑 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\)，利用导数不等式证明 \(|\theta'(x)|\le 1\)，从而 \(|\theta(x)|\le x\)。若 \(r_0<\frac{\pi}{2}\)，则令 \(x\to r_0^-\) 可推出 \(g(r_0)=0\)；另一方面，通过能量函数 \(E(x)=f(x)^2+g(x)^2\) 满足 \(E'(x)+2E(x)\ge 0\) 可证 \(E(r_0)\ge e^{-2r_0}f(0)^2>0\)，与 \(f(r_0)=g(r_0)=0\) 矛盾。

**推演步骤**：
- 1. 构造可行解：取 \(f(x)=\cos x\) 和 \(g(x)=\sin x\)。两者在 \(\mathbb{R}\) 上均可微，且满足 \(f(0)=1>0\)，\(g(0)=0\)，\(|f'(x)|=|-\sin x|=|g(x)|\)，\(|g'(x)|=|\cos x|=|f(x)|\)，以及 \(f\left(\frac{\pi}{2}\right)=0\)。因此 \(r=\frac{\pi}{2}\) 满足所有条件，最小正实数 \(r\le\frac{\pi}{2}\)。
- 2. 简化区间：设 \(f,g\) 满足题设条件。由于 \(f\) 可微因而连续，集合 \(Z=\{x\in[0,r]:f(x)=0\}\) 是闭集且非空（含 \(r\)），故存在最小元 \(r_0=\min Z\)。由 \(f(0)>0\) 知 \(0<r_0\le r\)，且由连续性与最小性可知对所有 \(x\in[0,r_0)\) 有 \(f(x)>0\)，同时 \(f(r_0)=0\)。
- 3. 利用“能量函数”排除同时为零：记 \(E(x)=f(x)^2+g(x)^2\)，则 \(E\) 在 \(\mathbb{R}\) 上可微，且
\[E'(x)=2f(x)f'(x)+2g(x)g'(x)\ge -2|f(x)||f'(x)|-2|g(x)||g'(x)|\ge -4|f(x)||g(x)|\ge -2\bigl(f(x)^2+g(x)^2\bigr)=-2E(x)\]。
令 \(\Phi(x)=e^{2x}E(x)\)，则 \(\Phi'(x)=e^{2x}\bigl(E'(x)+2E(x)\bigr)\ge 0\)，故 \(\Phi(x)\) 在 \(\mathbb{R}\) 上单调不减。特别地，
\[e^{2r_0}\bigl(f(r_0)^2+g(r_0)^2\bigr)=\Phi(r_0)\ge\Phi(0)=f(0)^2+g(0)^2=f(0)^2>0\]。
因为 \(f(r_0)=0\)，所以必有 \(g(r_0)^2\ge e^{-2r_0}f(0)^2>0\)，即 \(g(r_0)\neq 0\)。
- 4. 利用辐角函数估计 \(r_0\) 的下界：在 \([0,r_0)\) 上 \(f(x)>0\)，故可定义可微函数
\[\theta(x)=\arctan\frac{g(x)}{f(x)},\qquad x\in[0,r_0)\]。
由条件 (b) 得 \(\theta(0)=\arctan 0=0\)。对 \(\theta(x)\) 求导并利用条件 (c)、(d) 得
\[|\theta'(x)|=\left|\frac{g'(x)f(x)-g(x)f'(x)}{f(x)^2+g(x)^2}\right|\le\frac{|g'(x)||f(x)|+|g(x)||f'(x)|}{f(x)^2+g(x)^2}\le\frac{f(x)^2+g(x)^2}{f(x)^2+g(x)^2}=1\]。
由中值定理，对任意 \(x\in[0,r_0)\) 有 \(|\theta(x)|=|\theta(x)-\theta(0)|\le x\)。
- 5. 导出矛盾完成证明：若 \(r_0<\frac{\pi}{2}\)，则对所有 \(x\in[0,r_0)\) 有 \(|\theta(x)|\le x<r_0<\frac{\pi}{2}\)，从而
\[|g(x)|=f(x)|\tan\theta(x)|\le f(x)\tan r_0\]。
令 \(x\to r_0^-\)，由 \(f,g\) 的连续性及 \(f(r_0)=0\) 可得 \(|g(r_0)|\le f(r_0)\tan r_0=0\)，即 \(g(r_0)=0\)，这与第 3 步中 \(g(r_0)\neq 0\) 矛盾。因此必有 \(r\ge r_0\ge\frac{\pi}{2}\)。综合第 1 步，最小正实数 \(r=\frac{\pi}{2}\)。

**盲解结论**：最小的正实数 \(r\) 为 \(\frac{\pi}{2}\)。

### 2. 对照答案复盘

盲解结果完全正确，核心思路与参考解答中的第一种解法高度一致：均以 \(f(x)=\cos x, g(x)=\sin x\) 给出 \(r=\frac{\pi}{2}\) 的构造，并通过取最小零点、极角函数 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\) 的导数估计 \(|\theta'(x)|\le 1\)，以及能量函数 \(E(x)=f(x)^2+g(x)^2\) 证明 \(g(r_0)\neq 0\) 来导出 \(r<\frac{\pi}{2}\) 的矛盾。盲解中采用 \(e^{2x}E(x)\) 单调不减来替代参考解答中的 \(\log k(x)\) 导数估计，避免了预先论证 \(k(x)>0\)，表述上同样严谨简洁。

### 3. 困难点与破局关键

- **用极角代换将耦合不等式降维**：题目只给出导数模长的上界 \(|f'|\le |g|, |g'|\le |f|\)，并未给出符号关系。通过引入极角 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\)，把耦合的微分不等式转化为单一标量函数导数的绝对值界 \(|\theta'(x)|\le 1\)，绕开了符号讨论。
- **排除 \(f(r_0)\) 与 \(g(r_0)\) 同时为零的退化情形**：仅凭 \(|\theta(x)|\le x<\frac{\pi}{2}\) 只能得到 \(|g(x)|\le f(x)\tan r_0\)，必须在另一侧证明平面向量 \((f(x),g(x))\) 不会在有限时间退化到原点，即通过能量函数证明 \(g(r_0)\neq 0\)。

### 4. 问题拆解（教学引导）

- **识别标准微分模型并猜测答案**：看到 \(|f'|\le |g|\)、\(|g'|\le |f|\) 与初值 \(f(0)>0,g(0)=0\)，立刻联想到等号成立的标准模型 \(f(x)=\cos x, g(x)=\sin x\)，从而猜测最小零点位置为 \(r=\frac{\pi}{2}\)。
- **锁定几何意义并缩减至首个零点**：要使 \(f\) 尽快降到 \(0\)，直观上应让 \(f'\) 尽量负、\(g\) 尽量大，这正是平面向量 \((f(x),g(x))\) 绕原点旋转角速度受限的体现；另一方面，必须先将 \(r\) 缩减为 \(f\) 的第一个正零点 \(r_0\)，保证此前 \(f(x)>0\)。
- **分离“角度”与“模长”两条估计主线**：将平面坐标 \((f(x),g(x))\) 转为极坐标角度 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\) 与模长平方 \(E(x)=f(x)^2+g(x)^2\)：前者控制旋转角度不超过 \(x\)，后者保证向量不会在 \(r_0\) 处坍缩为 \((0,0)\)。

### 5. 答案拆解（逻辑骨架）

- **构造可行解确立上界**（*动机*：先通过显式构造确立答案上界，明确反证目标为 \(r<\frac{\pi}{2}\) 不可能。）：取 \(f(x)=\cos x\) 与 \(g(x)=\sin x\)，直接验证 \(f(0)=1>0\)、\(g(0)=0\)、\(|f'(x)|=|g(x)|\)、\(|g'(x)|=|f(x)|\) 且 \(f(\frac{\pi}{2})=0\)，说明 \(r=\frac{\pi}{2}\) 可达。
- **取最小正零点以保证 \(f(x)>0\)**（*动机*：为了在 \([0,r_0)\) 上合法地对 \(\frac{g(x)}{f(x)}\) 求导并应用中值定理，必须先排除区间内部的零点。）：假设存在 \(0<r<\frac{\pi}{2}\) 满足条件。由 \(f\) 连续且 \(f(0)>0,f(r)=0\)，集合 \(\{x\in[0,r]:f(x)=0\}\) 为非空闭集，取其最小元 \(r_0\in(0,r]\)，则对一切 \(x\in[0,r_0)\) 有 \(f(x)>0\)。
- **用能量函数证明 \(g(r_0)\neq 0\)**（*动机*：防止极限情形中 \(f(x)\) 与 \(g(x)\) 同时趋于 \(0\)，从而让角界发挥威力。）：令 \(E(x)=f(x)^2+g(x)^2\)，由题设得 \(|E'(x)|=2|f(x)f'(x)+g(x)g'(x)|\le 4|f(x)g(x)|\le 2E(x)\)。于是 \((e^{2x}E(x))'=e^{2x}(E'(x)+2E(x))\ge 0\)，故 \(e^{2r_0}E(r_0)\ge E(0)=f(0)^2>0\)。结合 \(f(r_0)=0\) 得 \(g(r_0)\neq 0\)。
- **通过极角函数导出矛盾**（*动机*：利用极角变化率不超过 \(1\) 限制轨线不能在时间 \(r_0<\frac{\pi}{2}\) 内转到纵轴（\(f=0\) 且 \(g\neq 0\)）。）：在 \([0,r_0)\) 上定义 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\)，则 \(\theta(0)=0\) 且
\[|\theta'(x)|=\left|\frac{f(x)g'(x)-g(x)f'(x)}{f(x)^2+g(x)^2}\right|\le\frac{|f(x)|^2+|g(x)|^2}{f(x)^2+g(x)^2}=1\]。
由中值定理有 \(|\theta(x)|\le x<r_0<\frac{\pi}{2}\)，从而 \(|g(x)|\le f(x)\tan r_0\)。令 \(x\to r_0^-\) 得 \(g(r_0)=0\)，矛盾。

### 6. 易错点分析

- **未取最小零点导致分母为零**：常见错法——直接在 \([0,r)\) 上定义 \(\theta(x)=\arctan\frac{g(x)}{f(x)}\)，而未说明 \(f(x)\) 在 \([0,r)\) 上不取零。；错因——题目只给出 \(f(r)=0\)，并未排除 \(f\) 在 \((0,r)\) 内提前取零的可能；一旦 \(f\) 在区间内部有零点，商 \(\frac{g(x)}{f(x)}\) 及 \(\theta(x)\) 就失去定义与可微性。；避坑策略——在构造 \(\arctan\frac{g(x)}{f(x)}\) 之前，先利用连续函数零点集的闭性取 \(f\) 在 \((0,r]\) 中的最小零点 \(r_0\)，从而确保在 \([0,r_0)\) 上严格有 \(f(x)>0\)。
- **忽略排除 \(f(r_0)=g(r_0)=0\) 的情形**：常见错法——得到 \(|g(x)|\le f(x)\tan r_0\) 后直接认为与 \(f(r_0)=0\) 矛盾，而忽略了 \(g(r_0)\) 也可能为 \(0\)。；错因——若 \(g(r_0)=0\) 且 \(f(r_0)=0\)，不等式 \(|g(x)|\le f(x)\tan r_0\) 在 \(x\to r_0^-\) 时只给出 \(0\le 0\)，无法产生任何矛盾。；避坑策略——利用能量函数 \(E(x)=f(x)^2+g(x)^2\) 满足 \(E'(x)+2E(x)\ge 0\)（即 \(e^{2x}E(x)\) 单调不减），严格证明 \(E(r_0)\ge e^{-2r_0}f(0)^2>0\)，从而排除 \(g(r_0)=0\)。
- **默认可微函数的导数连续或可积**：常见错法——在没有验证 \(f',g'\) 是否可积的情况下，直接对 \(f'\) 或 \(g'\) 使用微积分基本定理 \(\int_0^x g'(t)\,dt=g(x)-g(0)\)。；错因——题目仅假设 \(f,g\) 可微，并未给出 \(C^1\) 条件；虽然本题中 \(|f'|,|g'|\) 被连续函数控制因而有界，但若只用常规黎曼积分下的微积分基本定理仍需说明 \(f',g'\) 的可积性（或说明有界导数在 Lebesgue 积分下适用）。；避坑策略——使用微分中值定理和辅助函数 \(e^{2x}E(x)\) 代替对 \(f',g'\) 的积分，全过程只需 \(f,g\) 处处可微，无需任何关于导函数连续性的额外假设。

**教学小结**：面对耦合的一阶微分不等式组（尤其是与三角或双曲函数特征相似时），将平面向量 \((f,g)\) 分解为极角 \(\arctan(g/f)\) 与能量 \(f^2+g^2\)，往往能同时精准控制“旋转速度”与“非退化性”。

## Putnam 2023 questions (Kedlaya archive community mirror) · A4（`putnam-2023-AB-questions-qA4`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 局部-整体转化 / 构造与反例 / 辅助线与几何变换 / 易错:隐含假设与越界推广 / 易错:计算精度与等价替换
- **知识专题**：立体几何 / 格点与稠密性 / 丢番图逼近

### 原题整理

设 \(v_1, \dots, v_{12} \in \mathbb{R}^3\) 是从原点指向正十二面体各顶点的单位向量。证明：对任意向量 \(v \in \mathbb{R}^3\) 和任意 \(\varepsilon > 0\)，存在整数 \(a_1, \dots, a_{12}\)，使得 \(\|a_1 v_1 + \cdots + a_{12} v_{12} - v\| < \varepsilon\)。

### 1. 只看原题盲解尝试

**切入思路**：利用正十二面体的中心对称性与标准坐标表示：将正十二面体通过正交变换置于标准位置，使其顶点坐标仅含 \(0, \pm 1, \pm \phi\)（其中 \(\phi = \frac{1+\sqrt{5}}{2}\) 为黄金分割比）。通过将相邻顶点相加，在整数线性组合生成的格点集合中构造出三个坐标轴方向上长度分别为 \(\frac{2}{r}\) 与 \(\frac{2\phi}{r}\) 的向量。再利用 \(\mathbb{Z} + \mathbb{Z}\phi\) 在 \(\mathbb{R}\) 中稠密（例如通过 \((\phi-1)^k \to 0\) 构造任意小的正步长），即可在三个坐标分量上分别以任意精度逼近目标向量。

**推演步骤**：
- 1. 确定正十二面体的中心与标准坐标：正十二面体的外接球是唯一的。由于 \(v_1, \dots, v_{12}\) 均为单位向量，正十二面体的 \(12\) 个顶点都落在以原点为球心的单位球面上，因此原点必为该正十二面体的中心。由于正交变换保持欧几里得范数不变，不妨作适当的旋转或反射变换，使 \(v_1, \dots, v_{12}\) 取如下标准形式：
\[\frac{1}{r}(\pm 1, \pm \phi, 0), \quad \frac{1}{r}(0, \pm 1, \pm \phi), \quad \frac{1}{r}(\pm \phi, 0, \pm 1),\]
其中 \(\phi = \frac{1+\sqrt{5}}{2}\) 为黄金分割比（满足 \(\phi^2 = \phi + 1\)），\(r = \sqrt{1+\phi^2}\)。直接验证可知，每个顶点到其最近的 \(5\) 个顶点的距离平方均为 \(\frac{4}{r^2}\)，故这 \(12\) 个点确实构成正十二面体的顶点。
- 2. 构造沿三个坐标轴方向的向量：设 \(\Lambda = \left\{\sum_{i=1}^{12} a_i v_i : a_i \in \mathbb{Z}\right\}\) 为 \(v_1, \dots, v_{12}\) 生成的整系数线性组合集合（即 \(\mathbb{Z}\)-模）。在 \(\Lambda\) 中取如下成对顶点相加：
\[\frac{1}{r}(1, \phi, 0) + \frac{1}{r}(1, -\phi, 0) = \frac{1}{r}(2, 0, 0) \in \Lambda, \qquad \frac{1}{r}(\phi, 0, 1) + \frac{1}{r}(\phi, 0, -1) = \frac{1}{r}(2\phi, 0, 0) \in \Lambda,\]
\[\frac{1}{r}(0, 1, \phi) + \frac{1}{r}(0, 1, -\phi) = \frac{1}{r}(0, 2, 0) \in \Lambda, \qquad \frac{1}{r}(1, \phi, 0) + \frac{1}{r}(-1, \phi, 0) = \frac{1}{r}(0, 2\phi, 0) \in \Lambda,\]
\[\frac{1}{r}(\phi, 0, 1) + \frac{1}{r}(-\phi, 0, 1) = \frac{1}{r}(0, 0, 2) \in \Lambda, \qquad \frac{1}{r}(0, 1, \phi) + \frac{1}{r}(0, -1, \phi) = \frac{1}{r}(0, 0, 2\phi) \in \Lambda.\]
因此，对任意整数 \(m_1, n_1, m_2, n_2, m_3, n_3 \in \mathbb{Z}\)，向量
\[w = \frac{2}{r}\big(m_1 + n_1\phi,\; m_2 + n_2\phi,\; m_3 + n_3\phi\big)\]
都属于 \(\Lambda\)。
- 3. 证明 \(\mathbb{Z} + \mathbb{Z}\phi\) 在 \(\mathbb{R}\) 中稠密：注意到 \(\phi - 1 = \frac{\sqrt{5}-1}{2} \in (0, 1)\)。由数学归纳法，对任意正整数 \(k \ge 1\)，均有 \((\phi - 1)^k \in \mathbb{Z} + \mathbb{Z}\phi\)：
- 当 \(k = 1\) 时，\(\phi - 1 = -1 + 1\cdot\phi \in \mathbb{Z} + \mathbb{Z}\phi\)；
- 若 \((\phi - 1)^k = a + b\phi\)（\(a, b \in \mathbb{Z}\)），则利用 \(\phi^2 = \phi + 1\) 可得
  \[(\phi - 1)^{k+1} = (a + b\phi)(\phi - 1) = a\phi - a + b(\phi + 1) - b\phi = (b - a) + a\phi \in \mathbb{Z} + \mathbb{Z}\phi.\]
由于 \(0 < \phi - 1 < 1\)，当 \(k \to \infty\) 时 \((\phi - 1)^k \to 0\)。对任意 \(\delta > 0\)，可取 \(k \ge 1\) 使得 \(t = (\phi - 1)^k \in (0, \delta)\)。对任意实数 \(y \in \mathbb{R}\)，取 \(c = \lfloor y/t \rfloor \in \mathbb{Z}\)，则 \(0 \le y - ct < t < \delta\)，且 \(ct \in \mathbb{Z} + \mathbb{Z}\phi\)。这说明 \(\mathbb{Z} + \mathbb{Z}\phi\) 在 \(\mathbb{R}\) 中稠密。
- 4. 完成逼近：设 \(v = (x, y, z) \in \mathbb{R}^3\)，给定 \(\varepsilon > 0\)。取 \(\delta = \frac{r\varepsilon}{2\sqrt{3}} > 0\)。由步骤 3，分别存在整数 \(m_j, n_j \in \mathbb{Z}\)（\(j = 1, 2, 3\)）使得
\[\left|(m_1 + n_1\phi) - \frac{rx}{2}\right| < \delta, \quad \left|(m_2 + n_2\phi) - \frac{ry}{2}\right| < \delta, \quad \left|(m_3 + n_3\phi) - \frac{rz}{2}\right| < \delta.\]
令 \(w = \frac{2}{r}(m_1 + n_1\phi,\; m_2 + n_2\phi,\; m_3 + n_3\phi) \in \Lambda\)，则
\[\|w - v\| = \frac{2}{r}\sqrt{\left|(m_1 + n_1\phi) - \frac{rx}{2}\right|^2 + \left|(m_2 + n_2\phi) - \frac{ry}{2}\right|^2 + \left|(m_3 + n_3\phi) - \frac{rz}{2}\right|^2} < \frac{2}{r}\sqrt{3\delta^2} = \varepsilon.\]
证毕。

**盲解结论**：对任意 \(v \in \mathbb{R}^3\) 与 \(\varepsilon > 0\)，均存在整数 \(a_1, \dots, a_{12}\) 使得 \(\|a_1 v_1 + \cdots + a_{12} v_{12} - v\| < \varepsilon\)（即 \(\{v_1, \dots, v_{12}\}\) 的整系数线性组合在 \(\mathbb{R}^3\) 中稠密）。

### 2. 对照答案复盘

盲解与官方参考解答的核心思路完全一致，均为“正确”（outcome = correct）。两者都先通过外接球唯一性说明正十二面体中心必在原点，再利用正交变换与缩放将顶点置于含黄金分割比 \(\phi = \frac{1+\sqrt{5}}{2}\) 的标准坐标，进而证明生成子群包含沿三个坐标轴的直积 \(G \times G \times G\)（其中 \(G = \mathbb{Z} + \mathbb{Z}\phi\)，盲解中因未先除以 \(2\) 而得到等效的 \(\frac{2}{r}(G \times G \times G)\)），最后归结为一维稠密性。官方解答直接引用无理数在 \(\mathbb{R}/\mathbb{Z}\) 中生成稠密子群的结论，而盲解额外利用 \((\phi-1)^k \to 0\) 给出了自包含的初等证明与显式 \(\varepsilon/\sqrt{3}\) 误差控制。

### 3. 困难点与破局关键

- **建立几何对称性与标准坐标之间的桥梁**：将正十二面体的 \(12\) 个方向向量与代数中的黄金分割比 \(\phi = \frac{1+\sqrt{5}}{2}\) 联系起来，并意识到无需显式求解 \(12\) 元整系数方程，只需通过对称顶点相加即可消去其余分量、分离出三个正交坐标轴。
- **从三维格点稠密性降维到一维加法子群稠密性**：把三维向量空间 \(\mathbb{R}^3\) 中的整系数逼近问题，拆解为三个互不干扰的一维稠密子群问题（\(G \times G \times G\)），再通过 \(\phi\) 的无理性完成降维打击。

### 4. 问题拆解（教学引导）

- **1. 将 \(\varepsilon\)-逼近问题转化为子群稠密性问题**：题目要求对任意 \(v \in \mathbb{R}^3\) 和 \(\varepsilon > 0\) 找到整数 \(a_1, \dots, a_{12}\) 使 \(\|\sum a_i v_i - v\| < \varepsilon\)，等价于证明由 \(v_1, \dots, v_{12}\) 生成的加法子群 \(\Lambda = \sum_{i=1}^{12} \mathbb{Z} v_i\) 在 \(\mathbb{R}^3\) 中稠密。
- **2. 挖掘“单位向量”的几何隐含条件**：已知 \(v_1, \dots, v_{12}\) 均为单位向量，即 \(12\) 个顶点都位于以原点为球心的单位球面上。由正十二面体外接球的唯一性，原点必为正十二面体的中心。
- **3. 利用对称性与缩放不变性简化坐标**：正交变换保持距离不变，非零常数伸缩不改变子群在 \(\mathbb{R}^3\) 中的稠密性，因此可以自由选取最便于代数计算的坐标系与尺度。
- **4. 寻找坐标轴方向的基元向量**：若能用顶点的整系数线性组合分别生成 \((c, 0, 0), (c\phi, 0, 0)\) 及其轮换，就能把三维问题完全解耦为三个独立的一维子群稠密性问题。

### 5. 答案拆解（逻辑骨架）

- **1. 确定中心并标准化顶点坐标**（*动机*：消除一般位置带来的复杂参数，引入高度对称且坐标形式极简的黄金矩形表示。）：由于正十二面体唯一内接于一个球面，而所有顶点到原点的距离均为 \(1\)，故原点必为其中心。又因旋转、反射与正比例缩放均保持稠密性结论不变，可取标准坐标，使 \(12\) 个顶点为 \((\pm \frac{1}{2}, \pm \frac{1}{2}\phi, 0)\) 的循环置换，其中 \(\phi = \frac{1+\sqrt{5}}{2}\)。
- **2. 构造直积子群 \(G \times G \times G\)**（*动机*：利用顶点成对出现的符号对称性消去冗余坐标，实现三个维度的解耦。）：将第一分量相同的对称顶点相加：\((\frac{1}{2}, \frac{1}{2}\phi, 0) + (\frac{1}{2}, -\frac{1}{2}\phi, 0) = (1, 0, 0)\)，以及 \((\frac{1}{2}\phi, 0, \frac{1}{2}) + (\frac{1}{2}\phi, 0, -\frac{1}{2}) = (\phi, 0, 0)\)。同理对另外两个坐标轴轮换，可知生成子群包含 \(G \times G \times G\)，其中 \(G = \mathbb{Z} + \mathbb{Z}\phi\)。
- **3. 证明一维稠密性并推广到三维**（*动机*：将高维稠密性归结为熟知的一维无理数加法群稠密性。）：因为 \(\phi\) 是无理数，由鸽巢原理（或 Kronecker 定理）可知 \(\phi\) 在 \(\mathbb{R}/\mathbb{Z}\) 中生成的子群稠密，从而 \(G = \mathbb{Z} + \mathbb{Z}\phi\) 在 \(\mathbb{R}\) 中稠密。于是直积 \(G \times G \times G\) 在 \(\mathbb{R}^3\) 中稠密，即任意向量都能被 \(v_1, \dots, v_{12}\) 的整系数线性组合任意逼近。

### 6. 易错点分析

- **忽略对中心位置与坐标标准化合法性的说明**：常见错法——未作说明就直接假设正十二面体以原点为中心且处于标准坐标位置。；错因——题目只给出从原点出发到顶点的向量为单位向量，并未直接写出“中心在原点”；若不说明外接球唯一性，推导在逻辑上存在跳跃。；避坑策略——先利用“外接球唯一”说明 \(12\) 个等长顶点向量必意味着正十二面体的中心在原点，再说明正交变换与非零伸缩不改变整系数生成子群的稠密性。
- **分维逼近时遗漏欧氏范数的 \(\sqrt{3}\) 因子**：常见错法——在三个坐标轴上分别给出误差小于 \(\varepsilon\) 的逼近后，直接声称三维向量的欧氏距离也小于 \(\varepsilon\)。；错因——若三个分量误差均为 \(\frac{2}{3}\varepsilon\)，欧氏距离为 \(\frac{2\sqrt{3}}{3}\varepsilon > \varepsilon\)，不满足题目要求。；避坑策略——用 \(\delta = \frac{\varepsilon}{\sqrt{3}}\) 控制每个坐标分量的误差（若带有伸缩因子 \(r\)，则取相应缩放后的 \(\delta\)），从而保证三维欧氏距离严格小于 \(\varepsilon\)。
- **未交代一维稠密性的根据**：常见错法——仅写出“\(\phi\) 是无理数，所以整数线性组合可以逼近任意实数”，却未说明具体结构是 \(\mathbb{Z} + \mathbb{Z}\phi\)。；错因——单纯“有理数与无理数的组合”若只允许有限种组合或系数受限未必稠密，必须明确指出所生成的是加法群 \(\mathbb{Z} + \mathbb{Z}\phi\)。；避坑策略——使用标准结论（无理数 \(\alpha\) 在 \(\mathbb{R}/\mathbb{Z}\) 中生成的子群稠密）或用初等方法（如利用 \(0 < \phi - 1 < 1\) 使得 \((\phi - 1)^k \in \mathbb{Z} + \mathbb{Z}\phi\) 趋于 \(0\)）给出完整论证。

**教学小结**：遇到正多面体或高度对称几何体的向量问题时，应第一时间通过正交变换与缩放将其置于标准坐标下；面对多维整系数线性组合的稠密性问题，核心策略是利用对称向量相消构造出沿各个坐标轴独立伸缩的直积结构，从而将高维问题降维为一维无理数子群的稠密性。

## Putnam 2023 questions (Kedlaya archive community mirror) · A5（`putnam-2023-AB-questions-qA5`）

- **学段**：本科 · **盲解结果**：盲解正确（不同有效解法）
- **教学标签**：训练:技巧进阶 / 生成函数与多项式 / 算子与线性化 / 归纳与递推 / 易错:符号与方向 / 易错:计算精度与等价替换
- **知识专题**：多项式 / 生成函数 / 差分算子

### 原题整理

对于非负整数 \(k\)，设 \(f(k)\) 表示 \(k\) 的三进制表示中数字 \(1\) 的个数。求所有复数 \(z\)，使得
\[\sum_{k=0}^{3^{1010}-1} (-2)^{f(k)} (z+k)^{2023} = 0.\]

### 1. 只看原题盲解尝试

**切入思路**：利用指数生成函数将关于三进制数字之和（1的个数）的多项式求和转化为乘积形式，通过对称化提取双曲正弦函数 \(\sinh\) 的偶函数性质，直接求出 \(t^{2023}\) 次项的系数并分解因式求解。

**推演步骤**：
- 令 \(n = 1010\)，则 \(2023 = 2n + 3\)。考虑指数生成函数
\[H(t) = \sum_{k=0}^{3^n-1} (-2)^{f(k)} e^{t(z+k)} = \sum_{m=0}^{\infty} \left(\sum_{k=0}^{3^n-1} (-2)^{f(k)} (z+k)^m\right) \frac{t^m}{m!}.\]
原方程等价于 \(H(t)\) 中 \(t^{2n+3}\) 的系数为 \(0\)。
- 将 \(k \in \{0, 1, \dots, 3^n - 1\}\) 唯一地写成 \(n\) 位三进制数 \(k = \sum_{j=0}^{n-1} d_j 3^j\)（\(d_j \in \{0, 1, 2\}\)）。记 \(w(0) = w(2) = 1\)，\(w(1) = -2\)，则 \((-2)^{f(k)} = \prod_{j=0}^{n-1} w(d_j)\)，于是
\[H(t) = e^{tz} \prod_{j=0}^{n-1} \left(1 - 2e^{t 3^j} + e^{2t 3^j}\right) = e^{tz} \prod_{j=0}^{n-1} \left(e^{t 3^j} - 1\right)^2.\]
- 利用恒等式 \(e^u - 1 = u e^{u/2} \cdot \frac{\sinh(u/2)}{u/2}\)，将每一项改写为对称形式：
\[\left(e^{t 3^j} - 1\right)^2 = t^2 3^{2j} e^{t 3^j} \left(\frac{\sinh(t 3^j / 2)}{t 3^j / 2}\right)^2.\]
对 \(j = 0, 1, \dots, n-1\) 连乘，并注意到 \(\sum_{j=0}^{n-1} 3^j = \frac{3^n - 1}{2}\)，设 \(w = z + \frac{3^n - 1}{2}\)，则
\[H(t) = 3^{n(n-1)} t^{2n} e^{tw} \prod_{j=0}^{n-1} \left(\frac{\sinh(t 3^j / 2)}{t 3^j / 2}\right)^2.\]
- 记 \(G(t) = \prod_{j=0}^{n-1} \left(\frac{\sinh(t 3^j / 2)}{t 3^j / 2}\right)^2\)。由于 \(\frac{\sinh x}{x} = 1 + \frac{x^2}{6} + O(x^4)\) 是偶函数，\(G(t)\) 也是偶函数（只含 \(t\) 的偶次幂）。展开每一项的 \(t^2\) 系数：
\[\left(\frac{\sinh(t 3^j / 2)}{t 3^j / 2}\right)^2 = \left(1 + \frac{3^{2j}}{24} t^2 + O(t^4)\right)^2 = 1 + \frac{3^{2j}}{12} t^2 + O(t^4),\]
从而
\[G(t) = 1 + \left(\sum_{j=0}^{n-1} \frac{3^{2j}}{12}\right) t^2 + O(t^4) = 1 + \frac{9^n - 1}{96} t^2 + O(t^4).\]
- 将 \(e^{tw} = 1 + wt + \frac{w^2}{2}t^2 + \frac{w^3}{6}t^3 + O(t^4)\) 与 \(G(t)\) 相乘，提取 \(t^3\) 的系数（对应 \(H(t)\) 中 \(t^{2n+3}\) 的系数）：
\[[t^{2n+3}] H(t) = 3^{n(n-1)} \left(\frac{w^3}{6} + \frac{9^n - 1}{96} w\right) = \frac{3^{n(n-1)}}{6} w \left(w^2 + \frac{9^n - 1}{16}\right).\]
- 令 \(t^{2n+3}\) 的系数为 \(0\)，得 \(w = 0\) 或 \(w = \pm \frac{\sqrt{9^n - 1}}{4}i = \pm \frac{\sqrt{3^{2n} - 1}}{4}i\)。代入 \(n = 1010\) 及 \(z = w - \frac{3^{1010} - 1}{2}\)，即得全部三个复数解。

**盲解结论**：满足条件的复数 \(z\) 共有三个，分别为：
\[z = -\frac{3^{1010} - 1}{2}, \quad z = -\frac{3^{1010} - 1}{2} + \frac{\sqrt{3^{2020} - 1}}{4}i, \quad z = -\frac{3^{1010} - 1}{2} - \frac{\sqrt{3^{2020} - 1}}{4}i.\]

### 2. 对照答案复盘

盲解结果与标准答案完全一致（均为 \(-\frac{3^{1010}-1}{2}\) 与 \(-\frac{3^{1010}-1}{2} \pm \frac{\sqrt{9^{1010}-1}}{4}i\)）。两者的核心代数结构本质相同，但实现路径不同：盲解采用指数生成函数 \(H(t) = e^{tz}\prod_{j=0}^{n-1}(e^{t 3^j}-1)^2\)，将其对称化为 \(\sinh\) 乘积并直接提取 \(t^{2n+3}\) 系数（借助偶函数性质自动消去奇次项）；参考解答则将乘积结构转化为多项式上的平移算子 \(S(p(z))=p(z+1)\) 与对称二阶差分算子 \(S^\ell - 2I + S^{-\ell}\) 的复合，再对作用次数 \(i\) 做数学归纳，确定最终三次多项式的主项与次主项系数。

### 3. 困难点与破局关键

- **从三进制数位性质到生成函数乘积分解**：识别出 \((-2)^{f(k)}\) 在三进制下是每位独立相乘的乘性函数，从而将长度为 \(3^n\) 的和式压缩为 \(n\) 项乘积 \(\prod_{j=0}^{n-1}(x^{2\cdot 3^j}-2x^{3^j}+1)\)。
- **平移算子对称化与降次规律的发现**：把参数 \(x\) 的多项式恒等式转化为平移算子 \(S\) 作用在 \(z^{2n+3}\) 上，并进一步把 \(S^{2\ell} - 2S^\ell + I\) 对称化为 \(S^\ell(S^\ell - 2I + S^{-\ell})\)，既利用了偶对称性消去 \(z^2\) 与常数项，又看清了每次作用使多项式次数严格降 \(2\)。

### 4. 问题拆解（教学引导）

- **观察参数关联：捕捉 \(2023 = 2 \times 1010 + 3\) 的结构线索**：题目给出上界 \(3^{1010}-1\) 和指数 \(2023\)，注意到 \(2023 = 2 \times 1010 + 3\)。这种“大底数幂次减一”与“两倍指数再加小常数”的搭配，强烈暗示每增加一位三进制数字，多项式次数会下降 \(2\)。
- **分析权函数的数位可乘性与抵消性质**：\(f(k)\) 是 \(k\) 的三进制各位中 \(1\) 的个数，因此权因子 \((-2)^{f(k)}\) 等于每一位权因子的乘积（\(0, 2\) 位权为 \(1\)，\(1\) 位权为 \(-2\)）。进一步注意到 \(1 - 2 + 1 = 0\) 且 \(0\cdot 1 + 1\cdot(-2) + 2\cdot 1 = 0\)，说明每重位权组合都具有二阶差分抵消性质。
- **建立代数桥梁：生成函数或平移算子**：令 \(n = 1010\)，先写出 \(\sum_{k=0}^{3^n-1} (-2)^{f(k)} x^k = \prod_{j=0}^{n-1}(x^{2\cdot 3^j} - 2x^{3^j} + 1)\)，再通过平移算子 \(S\)（或指数生成函数 \(x = e^t\)）将其转化为对 \((z+k)^{2n+3}\) 的求和。

### 5. 答案拆解（逻辑骨架）

- **构造生成函数乘积恒等式**（*动机*：将离散的数位统计函数转化为多项式乘积。）：利用 \(f(3^{n-1}+k)=f(k)+1\) 与 \(f(2\cdot 3^{n-1}+k)=f(k)\)（\(0\le k\le 3^{n-1}-1\)），由数学归纳法证明多项式恒等式
\[\sum_{k=0}^{3^n-1} (-2)^{f(k)} x^k = \prod_{j=0}^{n-1} \left(x^{2\cdot 3^j} - 2x^{3^j} + 1\right).\]
这一步把按三进制数位定义的指数型求和转化为结构极简的乘积形式。
- **引入平移算子并完成对称化**（*动机*：把“对 \(k\) 求和”转化为“对称二阶差分算子作用于 \(z^{2n+3}\)”。）：定义多项式平移算子 \(S(p(z)) = p(z+1)\)，则 \(S^k(z^{2n+3}) = (z+k)^{2n+3}\)。将上式中的 \(x\) 替换为算子 \(S\)，并从每个因子中提出 \(S^{3^j}\)，利用 \(\sum_{j=0}^{n-1} 3^j = \frac{3^n-1}{2}\)，得到
\[p_n(z) = S^{(3^n-1)/2} \prod_{j=0}^{n-1} \left(S^{3^j} - 2I + S^{-3^j}\right) z^{2n+3}.\]
对称化后，每个因子 \(S^\ell - 2I + S^{-\ell}\) 保持多项式的奇偶性（将偶次幂映为偶次幂，奇次幂映为奇次幂）。
- **分析算子的降次与前两项递推规律**（*动机*：定量刻画对称二阶差分算子对最高两项系数的影响。）：对任意 \(\ell\) 和 \(m\ge 0\)，展开 \((S^\ell - 2I + S^{-\ell})z^m = (z+\ell)^m - 2z^m + (z-\ell)^m = 2\binom{m}{2}\ell^2 z^{m-2} + 2\binom{m}{4}\ell^4 z^{m-4} + O(z^{m-6})\)。可见每作用一次，多项式次数严格下降 \(2\)，且奇偶性不变。因此依次作用 \(n\) 个算子后，\(z^{2n+3}\) 降为 \(3\) 次奇多项式 \(C_n(z^3 + c z)\)。
- **数学归纳确定系数并还原平移量**（*动机*：通过归纳精确锁定三次多项式的系数，进而求出全部根。）：对作用个数 \(i\)（\(1\le i\le n\)）归纳证明：
\[\prod_{j=1}^i \left(S^{3^{n-j}} - 2I + S^{-3^{n-j}}\right) z^{2n+3} = C_i \left(z^{2n+3-2i} + \frac{(2n+3-2i)(n+1-i)}{6}\left(\sum_{j=1}^i 9^{n-j}\right) z^{2n+1-2i}\right) + O(z^{2n-1-2i}).\]
取 \(i=n\) 即得 \(\prod_{j=0}^{n-1}(S^{3^j}-2I+S^{-3^j})z^{2n+3} = C_n\left(z^3 + \frac{9^n-1}{16}z\right)\)，其根为 \(0\) 与 \(\pm \frac{\sqrt{9^n-1}}{4}i\)。最后还原外层的 \(S^{(3^n-1)/2}\)（即所有根减去 \(\frac{3^n-1}{2}\)），取 \(n=1010\) 即得全部解。

### 6. 易错点分析

- **平移方向与符号搞反**：常见错法——得到对称化后的根 \(w = 0, \pm \frac{\sqrt{9^n-1}}{4}i\) 后，直接写成 \(z = +\frac{3^n-1}{2} + w\)，把平移符号搞反。；错因——若 \(p_n(z) = S^{(3^n-1)/2} Q(z) = Q(z + \frac{3^n-1}{2})\)，则 \(p_n(z)=0\) 意味着 \(z + \frac{3^n-1}{2}\) 是 \(Q\) 的根，从而 \(z = w - \frac{3^n-1}{2}\)。；避坑策略——先用 \(n=1\)（此时 \(p_1(z) = z^5 - 2(z+1)^5 + (z+2)^5\)）代入检验中心对称轴：显然 \(z=-1\) 是根，因此平移量必为 \(-\frac{3^n-1}{2}\)。
- **二阶差分系数或泰勒展开系数计算失误**：常见错法——在展开 \((S^\ell - 2I + S^{-\ell})z^m\) 或 \(\left(\frac{\sinh(t 3^j/2)}{t 3^j/2}\right)^2\) 时漏掉因子 \(2\)，或混淆 \(\binom{m}{2}\) 与 \(\binom{m}{4}\)，导致 \(z^3\) 与 \(z\) 的系数比算错。；错因——\(\binom{m}{4} / \binom{m}{2} = \frac{(m-2)(m-3)}{12}\)，再乘以 \(\ell^4 / \ell^2\) 后在归纳中需要精确求和；漏掉平方或因子 \(2\) 会使根的虚部差 \(\sqrt{2}\) 倍。；避坑策略——用 \(n=1\)（次高项系数比为 \(\frac{9^1-1}{16} = \frac{1}{2}\)）和 \(n=2\) 快速验算，可立即发现常数因子错误。
- **未识别指数 \(2023 = 2\times 1010 + 3\) 的降次结构**：常见错法——直接对 \(k\) 硬展开 \((z+k)^{2023}\)，试图用组合恒等式或模运算直接求 \(z\)，没有把 \(3^{1010}\) 与 \(2023 = 2\times 1010 + 3\) 联系起来。；错因——\(3^{1010}\) 项的求和直接展开无法处理，必须利用三进制位乘积分解成 \(1010\) 个二阶差分算子的复合，将 \(2023\) 次降为 \(3\) 次。；避坑策略——注意到 \(1010\) 是 \(n\)，\(2023 = 2n+3\)，一旦指数换成 \(2n+3\)，就会发现 \(2n\) 次差分后恰好剩下 \(3\) 次多项式。

**教学小结**：当遇到“\(b^n\) 项求和且权函数仅依赖 \(b\) 进制各位数字、幂次又恰好在 \(kn+c\) 附近”的问题时，优先考虑将和式写成 \(n\) 个数位因子的乘积（通过普通生成函数配平移算子 \(S\)，或直接用指数生成函数 \(e^{tD}\)），再利用中心对称化将高次多项式自然降为低次奇/偶多项式。

## Putnam 2023 questions (Kedlaya archive community mirror) · A6（`putnam-2023-AB-questions-qA6`）

- **学段**：本科 · **盲解结果**：盲解正确（不同有效解法）
- **教学标签**：训练:压轴攻坚 / 奇偶与同余 / 归纳与递推 / 构造与反例 / 易错:边界与退化情形 / 易错:隐含假设与越界推广
- **知识专题**：组合博弈 / 排列与不动点 / 奇偶性分析

### 原题整理

Alice 和 Bob 玩一个游戏，他们轮流从 \(1\) 到 \(n\) 中选择整数。在任何整数被选择之前，Bob 先选择一个目标：“odd”（奇数）或“even”（偶数）。第 \(1\) 步由 Alice 从这 \(n\) 个整数中选择一个；第 \(2\) 步由 Bob 从剩下的整数中选择一个。两人交替从未被选择过的整数中各选一个，直到第 \(n\) 步（此时只剩一个数，别无选择）结束游戏。如果集合 \(\{k : \text{数字 } k \text{ 在第 } k \text{ 步被选择}\}\) 的大小的奇偶性与 Bob 的目标一致，则 Bob 获胜。问：对哪些正整数 \(n\)，Bob 具有必胜策略？

### 1. 只看原题盲解尝试

**切入思路**：按 \(n\) 的奇偶性分类讨论，Bob 总能通过选择与 \(n\) 相同的奇偶性作为目标而获胜（即对所有正整数 \(n \ge 1\)，Bob 均有必胜策略）：
1. 当 \(n = 2m\) 为偶数时，Bob 选择目标“even”（偶数）。将 \(\{1, 2, \dots, 2m\}\) 划分为 \(m\) 个配对 \(P_j = \{2j-1, 2j\}\)（\(j = 1, \dots, m\)）。每当 Alice 在第 \(2k+1\) 步选择某个 \(P_j\) 中的数时，Bob 在第 \(2k+2\) 步立即选择同一配对中的另一个数。每两步产生的不动点个数恒为 \(0\) 或 \(2\)，因此总不动点个数必为偶数。
2. 当 \(n = 2m+1\) 为奇数时，Bob 选择目标“odd”（奇数），并对 \(m\) 进行数学归纳。\(m=0\)（\(n=1\)）显然成立。对 \(m \ge 1\)，若 Alice 第一步选 \(1\) 或 \(2\)，Bob 分别选 \(2\) 或 \(1\)，前两步贡献偶数个不动点，剩余局面同构于 \(n-2\) 的情形，由归纳假设获胜；若 Alice 第一步选 \(a_1 \ge 3\)，Bob 第二步选 \(2\)（获得 \(1\) 个不动点），此后 Bob 需要保证从第 \(3\) 步到第 \(n\) 步产生偶数个不动点。通过维持“配对 \(P_j = \{2j-1, 2j\}\)（\(1 \le j \le m\)）的完整性”不变量（分为 Type 1 与 Type 2 两类状态，并在 Type 2 中确保所有缺失对的下标均严格小于半缺失对的下标 \(r\)），Bob 总能迫使剩余不动点个数为偶数（或在第 \(2r-1\) 步发生 \(1\) 个不动点后直接归约为标准奇数规模子游戏并由归纳假设补足奇数个不动点）。

**推演步骤**：
- 情形一：\(n = 2m\)（\(m \ge 1\)）为偶数。Bob 在游戏开始前选择目标“even”。将 \(\{1, 2, \dots, 2m\}\) 划分为 \(m\) 个互不相交的对 \(P_j = \{2j-1, 2j\}\)（\(j = 1, \dots, m\)）。Bob 的策略为：在每个偶数步 \(2k+2\)（\(0 \le k \le m-1\)），若 Alice 在第 \(2k+1\) 步选择了 \(x \in P_j\)，则 Bob 选择 \(P_j\) 中的另一个元素 \(y\)。由归纳法可知，在每个奇数步开始时，每个 \(P_j\) 要么两个数都可选，要么都已被选走，因此 \(y\) 总是合法的。若 \(j = k+1\) 且 \(x = 2k+1\)，则 \(y = 2k+2\)，这两步共产生 \(2\) 个不动点；若 \(j = k+1\) 且 \(x = 2k+2\)，则 \(y = 2k+1\)，产生 \(0\) 个不动点；若 \(j \ne k+1\)，则 \(\{x, y\} \cap \{2k+1, 2k+2\} = \emptyset\)，产生 \(0\) 个不动点。故每两步产生的不动点个数为 \(0\) 或 \(2\)（均为偶数），总不动点个数必为偶数，Bob 获胜。
- 情形二：\(n = 2m+1\)（\(m \ge 0\)）为奇数。Bob 选择目标“odd”。我们对 \(m\) 进行归纳证明。当 \(m = 0\)（\(n = 1\)）时，第 \(1\) 步必选 \(1\)，不动点个数为 \(1\)（奇数），Bob 获胜。
- 设 \(m \ge 1\) 且对所有更小的奇数 \(n'\) 结论成立。第 \(1\) 步 Alice 选 \(a_1 \in \{1, \dots, 2m+1\}\)。若 \(a_1 = 1\)，Bob 选 \(2\)（共 \(2\) 个不动点）；若 \(a_1 = 2\)，Bob 选 \(1\)（共 \(0\) 个不动点）。这两种情况下，前两步产生偶数个不动点，剩余步数集合 \(\{3, \dots, 2m+1\}\) 与剩余数字集合 \(\{3, \dots, 2m+1\}\) 经过平移后与 \(n - 2 = 2(m-1)+1\) 的原游戏完全同构，由归纳假设 Bob 可在剩余步骤中迫使产生奇数个不动点，从而总不动点个数为奇数，Bob 获胜。
- 若 \(a_1 \ge 3\)，Bob 第 \(2\) 步选 \(2\)，此时第 \(2\) 步构成 \(1\) 个不动点（奇数），因此 Bob 只需在后续步数 \(T = \{3, \dots, 2m+1\}\) 中迫使产生偶数个不动点。记 \(P_j = \{2j-1, 2j\}\)（\(1 \le j \le m\)）。在每个奇数步 \(t = 2k+1\)（\(1 \le k \le m\)）开始时，记剩余步数为 \(T = \{2k+1, \dots, 2m+1\}\)，剩余数字为 \(S\)（\(|S| = |T| = 2(m-k)+1\)），\(B = S \setminus T\)，\(C = T \setminus S\)。我们维护如下两类状态之一：
- **Type 1**（\(2m+1 \notin S\)）：\(S\) 由 \(B\) 中的唯一单元素 \(u\) 以及若干个完整的对 \(P_j\) 组成。
- **Type 2**（\(2m+1 \in S\)）：存在下标 \(r \in \{k+1, \dots, m\}\) 及 \(v \in P_r\)（其搭档为 \(v' \in P_r\)），使得 \(P_r \cap S = \{v'\}\)，\(S \setminus \{2m+1, v'\}\) 由 \(B\) 中的唯一单元素 \(u\) 与若干个完整的对 \(P_j\)（\(j \ne r\)）组成，且对所有 \(i > r\)（\(i \le m\)）均有 \(P_i \subseteq S\)（等价地，\(C\) 中所有完整的对 \(P_i\) 均满足 \(i < r\)）。
显然第 \(3\) 步（\(k=1\)）时，若 \(a_1 = 2m+1\) 则为 Type 1（\(u=1\)）；若 \(a_1 \in P_r\)（\(2 \le r \le m\)）则为 Type 2（\(u=1, v=a_1\)）。
- 当 \(k = m\) 时，\(T = \{2m+1\}\)，只可能是 Type 1（\(2m+1 \notin S\)），此时 \(S = \{u\}\) 且 \(u \ne 2m+1\)，最后一步产生 \(0\) 个不动点（偶数），Bob 获胜。当 \(k < m\) 时，检查 Type 1 与 Type 2 的转移（设 Alice 在第 \(2k+1\) 步选 \(x \in S\)）：
1. **Type 1**：
   - 若 \(x \in P_j\)，Bob 选 \(P_j\) 中另一元素 \(y\)，这两步产生 \(0\) 或 \(2\) 个不动点，第 \(2k+3\) 步仍为 Type 1（\(u\) 不变）。
   - 若 \(x = u\)，若 \(P_{k+1} \subseteq S\) 则 Bob 选 \(2k+1\)（\(0\) 个不动点，新单元素为 \(2k+2\)）；否则 \(P_{k+1} \cap S = \emptyset\) 且 \(2m+1 \notin S\)，故 \(|T \cap S| \le 2(m-k)-2\)，从而 \(|B| \ge 3\)，\(B\) 中必含至少一个完整对 \(P_j \subseteq B\)，Bob 选 \(P_j\) 中任一元素（\(0\) 个不动点），另一元素成为新单元素，仍为 Type 1。
- 2. **Type 2**：
   - 若 \(x \in P_j\)（\(j \ne r\)）：若 \(j < r\)，Bob 选 \(P_j\) 中另一元素（产生 \(0\) 或 \(2\) 个不动点；注意若 \(r = k+1\) 则 \(C=\{v\}\) 故 \(|B|=1\)，不存在 \(P_j \subseteq B\)，因此 \(j < r\) 必有 \(r \ge k+2\)），状态保持 Type 2 且 \(r\) 不变；若 \(j > r\) 且 \(r > k+1\)，Bob 选 \(y = v'\)（\(0\) 个不动点），\(P_r\) 完整移入 \(C\)，新的半缺失对下标变为 \(j > r \ge k+2\)，保持 Type 2；若 \(j > r\) 且 \(r = k+1\)（此时 \(B = \{u\}\)），若 \(v' = 2k+1\) 则 Bob 选 \(v'\)（\(0\) 个不动点，\(u\) 不变，新下标为 \(j\)），若 \(v' = 2k+2\) 则 Bob 选 \(u\)（\(0\) 个不动点，新单元素为 \(2k+2\)，新下标为 \(j\)），均保持 Type 2。
   - 若 \(x = u\)：若 \(r = k+1\)，Bob 选 \(2m+1\)（\(0\) 个不动点，新单元素为 \(v'\)，转为 Type 1）；若 \(r > k+1\)，类似 Type 1，若 \(P_{k+1} \subseteq S\) 则选 \(2k+1\)，否则选 \(B\) 中某个完整对 \(P_j\) 的元素，均产生 \(0\) 个不动点并保持 Type 2。
   - 若 \(x = 2m+1\)：若 \(r > k+1\) 或（\(r = k+1\) 且 \(v' = 2k+1\)），Bob 选 \(v'\)；若 \(r = k+1\) 且 \(v' = 2k+2\)，Bob 选 \(u\)。均产生 \(0\) 个不动点并转为 Type 1。
   - 若 \(x = v'\)：若 \(r > k+1\) 或（\(r = k+1\) 且 \(v' = 2k+2\)），Alice 未得不动点，Bob 选 \(2m+1\)（\(0\) 个不动点），转为 Type 1；若 \(r = k+1\) 且 \(v' = 2k+1\)，则 Alice 在第 \(2k+1\) 步获得 \(1\) 个不动点（奇数）！此时因 \(r = k+1\) 故 \(C = \{v\}\)、\(B = \{u\}\)，Bob 选 \(y = u\)（\(0\) 个不动点），第 \(2k+3\) 步时恰有 \(S' = T' = \{2k+3, \dots, 2m+1\}\)，还原为规模 \(2(m-k-1)+1\) 的标准游戏！由归纳假设，Bob 可在 \(T'\) 上迫使产生奇数个不动点，加上第 \(2k+1\) 步的 \(1\) 个不动点，总计偶数个不动点，Bob 获胜。
- 通过 Python 对 \(n = 1, 3, 5, 7, 9\) 遍历 Alice 的所有可能走法验证了上述显式策略，全部 \(100\%\) 获胜。

**盲解结论**：对所有正整数 \(n \ge 1\)，Bob 均有必胜策略（当 \(n\) 为偶数时 Bob 选择目标“even”，当 \(n\) 为奇数时 Bob 选择目标“odd”）。

### 2. 对照答案复盘

Turn 1 盲解完全正确：得出了与参考解答完全一致的结论（对所有正整数 \(n \ge 1\)，Bob 均有必胜策略，且目标是与 \(n\) 同奇偶），并通过 Python 穷举验证了 \(n \le 9\) 的所有奇数情形。在具体策略构造上，偶数情形两者完全一致（邻项配对 \(\{2j-1, 2j\}\)）；奇数情形则属于“不同但均有效的做法”（`different_valid_method`）：Turn 1 采用了带两类状态不变量的完整配对策略，分类较繁琐但也可行；参考解答则极为精炼——在 Bob 第 \(2\) 步选 \(2\) 拿到 \(1\) 个不动点后，只要 Alice 一直主动制造不动点就成对抵消（或在 \(j+1=k\) 时选 \(1\) 归约到 \(n-k\)），一旦 Alice 在某步没有制造不动点，Bob 立即切换为“每两步同时封堵自己与 Alice 下一步不动点”的极简策略，大幅简化了证明。

### 3. 困难点与破局关键

- **奇数情形下“最后一步强制性”与不对称局面的处理**：当 \(n\) 为奇数时，最后一步由 Alice 被迫完成，Bob 无法像偶数情形那样单纯靠静态配对控制全局奇偶性。如何处理“多出来的 \(1\) 步”，尤其是第 \(1\) 步 Alice 选 \(k > 2\) 后数字 \(1\) 滞留在可用集合中而 \(k\) 缺失的不对称局面，是本题最大的思维难点。
- **从“维持配对”到“全盘封堵零不动点”的策略切换**：参考解答最精彩之处在于发现：一旦 Bob 已经拥有奇数个不动点，并且 Alice 在某个奇数步 \(j\) 没能选出 \(j\)，Bob 不必再维持复杂的全局配对，只需在随后的每一步（偶数步 \(j'\)）通过优先抢占 \(j'+1\) 来“一举两得”地封死自己（\(j'\)）和 Alice 下一步（\(j'+1\)）产生不动点的可能。

### 4. 问题拆解（教学引导）

- **模型转化：排列与不动点**：将第 \(k\) 步选出的数记为 \(\pi(k)\)，则整局游戏等价于双方轮流构造一个 \(1\) 到 \(n\) 的排列 \(\pi \in S_n\)，Bob 获胜等价于控制 \(\pi\) 的不动点个数的奇偶性与他预先选定的目标一致。
- **小规模试算与猜想归纳**：先枚举 \(n = 1, 2, 3, 4\) 的小规模博弈树，立即发现对 \(n=1,3\) Bob 选“odd”必胜，对 \(n=2,4\) Bob 选“even”必胜，由此猜想对所有 \(n \ge 1\)，Bob 选择与 \(n\) 相同的奇偶性即可获胜。
- **寻找对称性与配对入口**：注意到 Bob 走偶数步且当 \(n\) 为偶数时最后一步（强制步）属于 Bob。若将 \(\{1, 2, \dots, n\}\) 两两配对 \(\{2j-1, 2j\}\)，每对的选法自然绑定在一起，极易控制不动点总数的奇偶性。

### 5. 答案拆解（逻辑骨架）

- **排列建模与偶数情形的配对策略**（*动机*：利用偶数规模的天然对称性，通过局部配对使每两步的不动点增量恒为 \(0\) 或 \(2\)。）：将游戏视为构造 \(\{1,\dots,n\}\) 的排列，目标即控制不动点个数的奇偶性。当 \(n\) 为偶数时，Bob 选“even”，并将集合划分为 \(\{1,2\},\{3,4\},\dots,\{n-1,n\}\)。每当 Alice 选某个对中的一个数，Bob 紧接着选同对的另一个数。由于对每个对 \(\{2k-1,2k\}\)，\(2k-1\) 是不动点当且仅当 \(2k\) 是不动点，故总不动点个数必为偶数。
- **奇数情形的归纳归约与第 \(2\) 步的占优选择**（*动机*：将 \(a_1 \in \{1,2\}\) 归约到规模 \(n-2\)，从而只需集中解决 \(a_1 = k > 2\) 的核心障碍，并用 \(b_2=2\) 先确立奇数个不动点的优势。）：当 \(n\) 为奇数时，Bob 选“odd”并对 \(n\) 归纳。第 \(1\) 步若 Alice 选 \(1\) 或 \(2\)，Bob 选另一个，前两步不动点为 \(2\) 或 \(0\)（偶数），余下部分等价于 \(n-2\) 的游戏，由归纳假设获胜。若 Alice 第 \(1\) 步选 \(k > 2\)，Bob 第 \(2\) 步选 \(2\)，此时不动点个数为 \(1\)（奇数）。
- **处理 Alice 持续取不动点的情形**（*动机*：若 Alice 试图强行通过连续取不动点来推进，Bob 要么成对跟进维持奇偶性，要么在撞上缺失的 \(k\) 时用滞留的 \(1\) 完成完美闭环归约。）：从第 \(3\) 步起，只要 Alice 在奇数步 \(j \ge 3\) 持续选择 \(j\)：若 \(j+1 < k\)，Bob 选 \(j+1\)，这两步共增加 \(2\) 个不动点（保持总数为奇数）；若 \(j+1 = k\)（此时 \(k\) 必为偶数），Bob 选 \(1\)。此时 \(\{1,2,\dots,k\}\) 恰在前 \(k\) 步用完，共产生 \(k-2\) 个（偶数个）不动点，余下部分等价于规模 \(n-k\)（仍为奇数）的新游戏，由归纳假设获胜。
- **切换为“零不动点封堵”策略结束战斗**（*动机*：一旦 Alice 断开不动点链条，Bob 无需再记复杂配对，只需利用“提前抢占 \(j'+1\)”的局部贪心即可同时封死两步的不动点。）：若在某个奇数步 \(j \ge 3\)，Alice 没有选择 \(j\)（注意若 \(k\) 为奇数且前面一直取 \(j\)，则至多在 \(j=k\) 时因 \(k\) 已被选而必触发此分支），此时已有不动点个数仍为奇数。此后在 Bob 的每个回合 \(j'\)（偶数步）：若 \(j'+1\) 尚可用，Bob 选 \(j'+1\)，这样自己（\(j'\)）和 Alice 下一步（\(j'+1\)）都不可能产生不动点；若 \(j'+1\) 已被用过，则 Alice 下一步已无法产生不动点，而因 \(j' < n\) Bob 至少还有 \(2\) 个数可选，必能选一个不等于 \(j'\) 的数。由此后续不再产生任何不动点，总数保持奇数，Bob 获胜。

### 6. 易错点分析

- **忽略奇数情形下最后一步的强制性与可用数字数量**：常见错法——在偶数情形模仿配对策略处理奇数 \(n\) 时，直接丢弃最后一个元素或忽略“最后一步 \(n\) 由 Alice 被迫完成”，误以为 Bob 在所有步骤都有选择权。；错因——当 \(n\) 为奇数时，第 \(n\) 步是 Alice 的强制步而非 Bob 的回合，若不控制最后一步或提前消除不动点可能，末尾的强制选择会直接翻转总不动点个数的奇偶性。；避坑策略——在构造配对或“封堵”策略时，务必显式检查每一步的合法性：不仅要验证所选数字未被用过，还要确认在奇数情形下 Bob 行动时剩余数字至少有 \(2\) 个（即 \(j < n\)）。
- **诱导归约时算错前序步骤贡献的不动点奇偶性**：常见错法——在奇数情形从第 \(1\) 步或第 \(k\) 步归约到更小规模（如 \(n-k\)）时，漏算前 \(k\) 步中 Alice 与 Bob 各自产生的不动点（例如误以为 \(k\) 步内有奇数个不动点），导致目标奇偶性算反。；错因——当 \(k\) 为偶数且 Alice 在第 \(3, 5, \dots, k-1\) 步均取到不动点、Bob 在第 \(2\) 步取 \(2\) 且第 \(k\) 步取 \(1\) 时，前 \(k\) 步恰有 \(1 + (k-4)/2 \times 2 + 1 = k-2\) 个不动点（偶数），只有偶数个不动点才能与剩余 \(n-k\) 步的奇数目标相加得到奇数。；避坑策略——明确区分“已产生的不动点个数奇偶性”与“剩余局部游戏的目标奇偶性”，并在还原到 \(n-2\) 或 \(n-k\) 规模时逐一核对前 \(2\) 步或前 \(k\) 步贡献的不动点总数的奇偶性。
- **未注意 \(k\) 为奇数时第 \(k\) 步的必然分支切换**：常见错法——在分析 \(j \ge 3\) 的奇数步时，未注意当 \(k\) 为奇数时 Alice 在第 \(k\) 步根本不可能选到 \(k\)（因 \(k\) 已在第 \(1\) 步被选走），从而错误地对 \(j+1 > k\) 的情形做无意义讨论。；错因——数字 \(k\) 在第 \(1\) 步已被 Alice 选走，故 \(j=k\) 时 \(k \notin S\)，必进入“Alice 未选 \(j\)”的封堵分支。；避坑策略——列举局部状态时，务必按 \(k\) 的奇偶性分类验证：若 \(k\) 为奇数，\(j\) 在到达 \(k\) 之前或至多在 \(j=k\) 时必因 \(k\) 已被选而触发“未选 \(j\)”分支，不会越界。

**教学小结**：在双人交替构造成对目标的组合博弈中，既要善于用“邻项配对”消去奇偶扰动，更要敏锐捕捉“一旦对手错过一次得分机会，后手即可通过抢占下一回合的目标元素来同时封锁两步”的局部贪心切换。

## Putnam 2023 questions (Kedlaya archive community mirror) · B1（`putnam-2023-AB-questions-qB1`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:基础热身 / 不变量与单调量 / 局部-整体转化 / 易错:充分性与必要性混淆 / 易错:边界与退化情形
- **知识专题**：组合计数 / 格路问题 / 不变量

### 原题整理

考虑一个 \(m \times n\) 的单位方格网格，方格用 \((i, j)\) 索引，其中 \(1 \le i \le m\) 且 \(1 \le j \le n\)。共有 \((m-1)(n-1)\) 枚硬币，初始时放置在满足 \(1 \le i \le m-1\) 且 \(1 \le j \le n-1\) 的方格 \((i, j)\) 中。如果一枚硬币占据方格 \((i, j)\)（其中 \(i \le m-1\) 且 \(j \le n-1\)），并且方格 \((i+1, j)\)、\((i, j+1)\) 与 \((i+1, j+1)\) 均未被占据，则一次合法移动是将该硬币从 \((i, j)\) 滑动到 \((i+1, j+1)\)。从初始状态出发，经过若干次（可能为空）合法移动后，总共可以到达多少种不同的硬币构型？

### 1. 只看原题盲解尝试

**切入思路**：将每条对角线 \(i - j = c\) 视为一个不变量：每次合法移动都保持硬币所在的对角线不变，且每条对角线上始终恰好有一个空格。将所有对角线上的空格位置按 \(c\) 从 \(-(n-1)\) 到 \(m-1\) 排列，恰好构成一条从 \((1,n)\) 到 \((m,1)\)、每步向下 \((+1,0)\) 或向左 \((0,-1)\) 的格路。一次合法移动等价于将格路中相邻的“下-左”步翻转为“左-下”步，从而所有由 \(m-1\) 个下步和 \(n-1\) 个左步组成的格路均可到达，总数为 \(\binom{m+n-2}{m-1}\)。

**推演步骤**：
- 当 \(m=1\) 或 \(n=1\) 时，硬币数为 \((m-1)(n-1)=0\)，无法进行任何移动，只有 \(1 = \binom{m+n-2}{m-1}\) 种构型。以下设 \(m, n \ge 2\)。
- 按 \(c = i - j\) 将网格划分成 \(m+n-1\) 条对角线 \(L_c = \{(i,j) \in [1,m]\times[1,n] : i - j = c\}\)，其中 \(-(n-1) \le c \le m-1\)。初始时，每条对角线 \(L_c\) 中除最大坐标方格（即满足 \(i=m\) 或 \(j=n\) 的唯一方格）外均放有硬币，因此 \(L_c\) 上共有 \(|L_c|-1\) 枚硬币与恰好 \(1\) 个空格。
- 由于每次合法移动将硬币从 \((i,j)\) 移至 \((i+1,j+1)\)，差值 \((i+1)-(j+1) = i-j\) 保持不变，因此每条对角线 \(L_c\) 上的硬币数始终为 \(|L_c|-1\)，从而始终存在唯一的空格，记为 \(e_c \in L_c\)。构型由元组 \((e_{-(n-1)}, e_{-(n-2)}, \dots, e_{m-1})\) 唯一确定。
- 在初始构型中，当 \(-(n-1) \le c \le m-n\) 时 \(e_c = (n+c, n)\)；当 \(m-n \le c \le m-1\) 时 \(e_c = (m, m-c)\)。这对应一条从 \(e_{-(n-1)}=(1,n)\) 到 \(e_{m-1}=(m,1)\) 的格路：先连续走 \(m-1\) 步向下步 \(D=(+1,0)\)，再连续走 \(n-1\) 步向左步 \(L=(0,-1)\)。
- 检验合法移动条件：从 \((i,j)\) 移动到 \((i+1,j+1)\)（记 \(c=i-j\)）合法，当且仅当 \((i+1,j+1)\)、\((i+1,j)\)、\((i,j+1)\) 均为空格，即 \(e_c = (i+1,j+1)\)、\(e_{c+1} = (i+1,j)\)、\(e_{c-1} = (i,j+1)\)。此时 \(e_c - e_{c-1} = (+1,0) = D\) 且 \(e_{c+1} - e_c = (0,-1) = L\)。移动后 \(e_c\) 变为 \(e'_c = (i,j)\)，满足 \(e'_c - e_{c-1} = (0,-1) = L\) 与 \(e_{c+1} - e'_c = (+1,0) = D\)。反之，若格路中第 \(c\) 步为 \(D\)、第 \(c+1\) 步为 \(L\)，令 \(e_c = (a,b)\)，则 \(e_{c-1}=(a-1,b)\) 与 \(e_{c+1}=(a,b-1)\) 在网格内保证 \(a, b \ge 2\)，从而 \((a-1,b-1) \to (a,b)\) 是一次合法移动。
- 因此，所有可达构型与满足以下条件的格路一一对应：从初始序列 \(D^{m-1}L^{n-1}\) 出发，通过反复将相邻的 \(DL\) 替换为 \(LD\) 所能得到的所有由 \(m-1\) 个 \(D\) 和 \(n-1\) 个 \(L\) 组成的序列。任意包含 \(m-1\) 个 \(D\) 和 \(n-1\) 个 \(L\) 的序列都可以通过把每个 \(L\) 依次左移（对应反向把 \(LD\) 换回 \(DL\)）还原为 \(D^{m-1}L^{n-1}\)，故所有 \(\binom{m+n-2}{m-1}\) 条格路均可到达。

**盲解结论**：\(\binom{m+n-2}{m-1}\)

### 2. 对照答案复盘

盲解结果与标准解答完全一致，最终答案均为 \(\binom{m+n-2}{m-1}\)。核心思路完全吻合：两者都将关注点从占据的硬币转移到每条对角线 \(i-j=c\) 上唯一的空格，建立可达构型与从 \((1,n)\) 到 \((m,1)\) 的格路之间的一一对应，并通过“逆向还原到初始路径”完成满射性（可达性）的严格证明。唯一细微差别在于坐标系表述方向（标准解答将 \(i\) 视作水平方向、\(j\) 视作竖直方向，而盲解按矩阵行列记为“下”和“左”），两者在数学上完全等价。

### 3. 困难点与破局关键

- **从“硬币”切换到“空格”的补集视角**：题目有 \((m-1)(n-1)\) 枚硬币，却只有 \(m+n-1\) 个空格。若盯着硬币看，状态空间看似很复杂；一旦改用“补集视角”观察空格，整体结构立刻简化为一条一维格路。
- **利用逆向思维证明满射性（可达性）**：证明每一条目标格路确实都能从初始状态到达，需要将前向构造转化为逆向归纳：只要当前格路不是初始格路，就必存在可以“回退”的转角，从而严格递减逆序数（或路径下方格数）。

### 4. 问题拆解（教学引导）

- **通过小规模特例猜想规律**：手算 \((m,n) = (2,2), (2,3), (3,3)\) 的情况，分别得到 \(2, 3, 6\) 种构型，敏锐猜测答案为组合数 \(\binom{m+n-2}{m-1}\)。
- **寻找对角线不变量与空格数量**：观察每次移动 \((i,j) \to (i+1,j+1)\) 的不变量：\(i-j\) 保持不变。计算每条对角线 \(i-j=c\) 上的空格数，发现每条对角线初始时恰有 \(1\) 个空格，且总数不变。
- **利用补集视角刻画状态空间**：将占据了 \((m-1)(n-1)\) 个方格的硬币构型转化为仅由 \(m+n-1\) 个空格构成的几何图形，并检验一次局部移动对空格图形的影响。

### 5. 答案拆解（逻辑骨架）

- **建立构型到格路的单射**（*动机*：为什么改写为“空格路径”：用少量空格代替大量硬币，能够把二维状态压缩为一条连续格路。）：记对角线 \(L_c = \{(i,j) : i-j=c\}\)。初始时每条对角线上除最末端外全是硬币，共有 \(m+n-1\) 个空格。由于移动仅沿对角线方向进行，每条对角线始终恰有一个空格，且初始空格连起来恰好是从 \((1,n)\) 到 \((m,1)\) 的一条折线（先沿一个方向走 \(m-1\) 步，再沿另一个方向走 \(n-1\) 步）。
- **刻画合法移动对应的路径变换**（*动机*：为什么操作保持格路性质：局部 \(2 \times 2\) 区域的状态更新恰好是格路上的一个局部转角翻转。）：一次合法移动要求 \((i,j)\) 有硬币，且 \((i+1,j)\)、\((i,j+1)\)、\((i+1,j+1)\) 均为空格。在空格路径上，这对应于连续两步 \((i,j+1) \to (i+1,j+1) \to (i+1,j)\)；移动后 \((i,j)\) 变为空格而 \((i+1,j+1)\) 被占据，路径变为 \((i,j+1) \to (i,j) \to (i+1,j)\)，即把路径上的一个直角凸角翻折，步数构成（\(m-1\) 步与 \(n-1\) 步）保持不变。
- **逆向归纳证明满射性并完成计数**（*动机*：为什么采用逆向思考：从任意目标格路出发“撤销一步”，比从初始状态正向构造步步序列更容易找到可操作的位置。）：对任意一条从 \((1,n)\) 到 \((m,1)\)、包含 \(m-1\) 步和 \(n-1\) 步的格路，若它不是初始格路，则必然至少包含一个“先 \((0,-1)\) 后 \((+1,0)\)”的凹角，即形如 \((i,j) \to (i,j-1) \to (i+1,j-1)\) 的三点片段。此时 \((i+1,j)\) 必为硬币，因此可以通过将硬币从 \((i,j-1)\)... 不，是将硬币从 \((i+1,j)\) 移回 \((i,j-1)\)？注意核对坐标：在格路上 \((i,j) \to (i,j-1) \to (i+1,j-1)\) 对应于 \((i+1,j)\) 被占据，回退一步就是把 \((i+1,j)\) 处的硬币（它是由 \((i,j-1)\) 还是 \((i,j-1)\)? 若回退前把 \((i+1,j)\) 移到 \((i,j-1)\) 不对，硬币移动是 \((a,b) \to (a+1,b+1)\)，因此回退是 \((a+1,b+1) \to (a,b)\)！在 \((i,j) \to (i,j-1) \to (i+1,j-1)\) 中，空格在 \((i,j-1)\) 上，而 \((i+1,j)\) 在对角线 \((i+1)-j = i-j+1\)? 等等！\(i-(j-1)=c+1\)，\((i+1)-j=c+1\)，它们在同一条对角线上，且 \((i+1,j)\) 确实被占据，而 \((i,j), (i,j-1), (i+1,j-1)\) 都是空格，所以把 \((i+1,j)\) 的硬币退回到 \((i,j-1)\) 不可行，应该把 \((i+1,j)\) 处的硬币退回到 \((i,j-1)\)... 啊，对角线是 \(i-j\) 不变，\((i+1,j)\) 退回 \((i,j-1)\) 正是 \((a+1,b+1) \to (a,b)\)（这里 \(a=i, b=j-1\)）！每次回退都使路径“向初始路径靠拢”（例如路径与初始路径围成的面积严格减少 \(1\)），有限步内必回到初始路径，从而每条格路皆可达，总数为 \(\binom{m+n-2}{m-1}\)。

### 6. 易错点分析

- **只证上界（单射），漏证可达性（满射）**：常见错法——只证明了所有可达构型都对应一条从 \((1,n)\) 到 \((m,1)\) 的格路，就直接断定答案是 \(\binom{m+n-2}{m-1}\)。；错因——状态转移往往存在不可达的“死状态”或受限构型，仅说明每个可达状态属于某个大小为 \(N\) 的集合，只能得到上界 \(\le N\)，不能自动说明所有 \(N\) 个状态都能到达。；避坑策略——在建立构型到组合对象的映射后，必须同时验证单射性（不同构型对应不同格路）与满射性（每条格路都能通过合法操作达到，通常可用逆向归纳或单调量来证）。
- **格路步数或退化边界处理失误**：常见错法——误把格路步数算成 \(m\) 和 \(n\)，或者在 \(m=1\) 或 \(n=1\) 时未检查公式是否仍然成立。；错因——从 \((1,n)\) 到 \((m,1)\) 的坐标差分别为 \(m-1\) 和 \(-(n-1)\)，共 \(m+n-2\) 步而非 \(m+n\) 步；当 \(m=1\) 或 \(n=1\) 时硬币数为 \(0\)，仅有一种构型，恰好对应 \(\binom{n-1}{0}=1\)。；避坑策略——在得出公式后，代入 \(m=1, n=1\) 以及 \(m=2, n=2\)、\(m=2, n=3\) 等小规模例子直接验证步数与总数。
- **混淆“操作序列数”与“可达构型数”**：常见错法——试图对合法的移动序列本身计数，或直接按“能移动多少枚硬币”进行分类计数。；错因——不同的移动顺序（例如先动 \((1,2)\) 再动 \((2,1)\) 与先动 \((2,1)\) 再动 \((1,2)\)）往往会到达完全相同的硬币构型，直接对操作序列计数会导致严重的重复计数。；避坑策略——一旦发现问题可以转化为状态图上的等价对象（如格路），应直接对终态构型建立双射，而不是对操作序列计数。

**教学小结**：当网格操作在某个方向上保持每条直线（或对角线）的棋子数不变时，转向“唯一空格”的补集视角往往能将复杂的二维博弈直接化归为经典的格路计数问题；而证明组合等价类全可达时，“逆向回退+单调量”是最有力的标准工具。

## Putnam 2023 questions (Kedlaya archive community mirror) · B2（`putnam-2023-AB-questions-qB2`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 奇偶与同余 / 构造与反例 / 易错:边界与退化情形 / 易错:隐含假设与越界推广
- **知识专题**：初等数论 / 同余与欧拉定理 / 进制表示

### 原题整理

对每个正整数 \(n\)，记 \(k(n)\) 为 \(2023 \cdot n\) 的二进制表示中数字 \(1\) 的个数。求 \(k(n)\) 的最小值。

### 1. 只看原题盲解尝试

**切入思路**：利用二进制中 \(1\) 的个数将问题转化为求最小的正整数 \(k\)，使得存在 \(k\) 个互不相同的 \(2\) 的幂次之和能被 \(2023 = 7 \times 17^2\) 整除。首先通过模 \(7\) 分析排除 \(k=1, 2\) 的可能性，然后利用 \(289 = 2^8 + 2^5 + 1\) 与欧拉定理（\(\varphi(289) = 272\)）构造出同时被 \(7\) 和 \(289\) 整除的三项之和 \(2^{280} + 2^5 + 1\)，从而证明最小值为 \(3\)。

**推演步骤**：
- 将 \(2023\) 分解质因数：\(2023 = 7 \times 289 = 7 \times 17^2\)。\(k(n)\) 的最小值等价于最小的正整数 \(k\)，使得存在严格递增的非负整数 \(0 \le a_1 < a_2 < \dots < a_k\) 满足 \(2^{a_1} + 2^{a_2} + \dots + 2^{a_k} \equiv 0 \pmod{2023}\)。
- 证明 \(k(n) \ge 3\)：
1. 若 \(k(n) = 1\)，则 \(2023 \cdot n = 2^a\)，但 \(2023\) 为奇数（且有素因子 \(7\)），不可能整除 \(2^a\)，矛盾。
2. 若 \(k(n) = 2\)，则 \(2023 \cdot n = 2^a + 2^b = 2^a(1 + 2^{b-a})\)（其中 \(0 \le a < b\)）。由于 \(\gcd(7, 2^a) = 1\) 且 \(7 \mid 2023\)，必有 \(1 + 2^{b-a} \equiv 0 \pmod 7\)，即 \(2^{b-a} \equiv 6 \pmod 7\)。然而 \(2\) 的幂次模 \(7\) 只有 \(1, 2, 4\) 三种余数（\(2^0 \equiv 1, 2^1 \equiv 2, 2^2 \equiv 4 \pmod 7\)），永远不会余 \(6\)，矛盾。
因此对所有正整数 \(n\)，均有 \(k(n) \ge 3\)。
- 构造 \(k(n) = 3\) 的例子：
注意到 \(289 = 256 + 32 + 1 = 2^8 + 2^5 + 1\)，故 \(2^8 + 2^5 + 1 \equiv 0 \pmod{289}\)。
由欧拉定理，\(\gcd(2, 289) = 1\) 且 \(\varphi(289) = 17^2 - 17 = 272\)，因此 \(2^{272} \equiv 1 \pmod{289}\)。
将 \(2^8\) 替换为 \(2^{8 + 272} = 2^{280}\)，模 \(289\) 的余数不变，仍有：
\[2^{280} + 2^5 + 1 \equiv 2^8 + 2^5 + 1 = 289 \equiv 0 \pmod{289}.\]
再检验模 \(7\) 的余数：因为 \(2^3 \equiv 1 \pmod 7\)，且 \(280 = 3 \times 93 + 1 \equiv 1 \pmod 3\)，\(5 \equiv 2 \pmod 3\)，所以：
\[2^{280} + 2^5 + 1 \equiv 2^1 + 2^2 + 1 = 7 \equiv 0 \pmod 7.\]
- 由于 \(\gcd(7, 289) = 1\) 且 \(7 \times 289 = 2023\)，故 \(2023 \mid (2^{280} + 2^5 + 1)\)。取正整数 \(n = \frac{2^{280} + 2^5 + 1}{2023}\)，则 \(2023 \cdot n = 2^{280} + 2^5 + 1\) 的二进制表示中恰好有 \(3\) 个 \(1\)，即 \(k(n) = 3\)。综上，\(k(n)\) 的最小值为 \(3\)。

**盲解结论**：3

### 2. 对照答案复盘

盲解完全正确且严谨：答案 \(3\) 与参考解答一致，整体思路与参考解答的 First solution 完全吻合（先通过模 \(7\) 排除 \(k=1,2\)，再结合 \(289 = 2^8 + 2^5 + 1\)、欧拉定理 \(\varphi(289)=272\) 与中国剩余定理构造出具体解 \(2^{280} + 2^5 + 1\)，甚至直接给出了满足同余方程组的显式正整数指数）。参考解答的 Second solution 还提供了另一种巧妙构造 \(2^{77} + 2^{16} + 1\)（利用 \((2^8-1)^2 \equiv 0 \pmod{17^2}\) 与 \(2^{68} \equiv -1 \pmod{17^2}\)），对应最小的正整数 \(n\)。

### 3. 困难点与破局关键

- **指数同余条件的解耦与中国剩余定理的应用**：由于 \(\operatorname{ord}_7(2) = 3\) 而 \(\varphi(17^2) = 16 \times 17 = 272\)，两者互素，学生需要敏锐地意识到可以通过改变指数 \(a, b\) 模 \(3\) 与模 \(272\) 的余数，用中国剩余定理分别独立地满足模 \(7\) 和模 \(289\) 的同余条件。
- **寻找模 \(289\) 下三项 \(2\) 的幂次之和为零的基础解**：若采用参考解答一的思路，需先观察到 \(289 = 256 + 32 + 1 = 2^8 + 2^5 + 1\)（恰好有三个 \(1\)）；若采用参考解答二的思路，则需通过二项式展开得到 \(2^{68} \equiv -1 \pmod{17^2}\) 并改写 \((2^8 - 1)^2 \equiv 0 \pmod{17^2}\)。

### 4. 问题拆解（教学引导）

- **条件翻译：二进制权重转化为幂次和整除问题**：二进制中有 \(k\) 个 \(1\)，等价于该数可以写成 \(k\) 个互不相同的 \(2\) 的幂次之和：\(2023n = 2^{a_1} + \dots + 2^{a_k}\)。由于 \(2023\) 是奇数，可提取最低次幂 \(2^{a_1}\) 并约去，转化为是否存在 \(k-1\) 个正整数指数使得 \(1 + 2^{b_1} + \dots + 2^{b_{k-1}} \equiv 0 \pmod{2023}\)。
- **结构分解：对模数做素因数分解并寻找强约束因子**：分解 \(2023 = 7 \times 17^2 = 7 \times 289\)。小素因子 \(7\) 往往对 \(2\) 的幂次有极强的限制（\(2^3 \equiv 1 \pmod 7\)），因此优先在模 \(7\) 下检验较小的 \(k\) 值。
- **确定切入点：先定下界再尝试构造上界**：模 \(7\) 迅速排除了 \(k=1, 2\)。接下来只需判断 \(k=3\) 是否可行，即寻找 \(a > b > 0\) 使得 \(2^a + 2^b + 1\) 同时被 \(7\) 和 \(289\) 整除，从而自然引导到欧拉定理与中国剩余定理。

### 5. 答案拆解（逻辑骨架）

- **利用模 \(7\) 排除 \(k(n) = 1, 2\)**（*动机*：证明目标最小值为 \(3\) 必须先排除 \(1\) 和 \(2\)，利用小素因子 \(7\) 可以最快给出否定性证明。）：记录 \(2023 = 7 \cdot 17^2\)。若 \(k(n)=1\)，则 \(2023n = 2^a\)，与 \(7 \mid 2023\) 矛盾；若 \(k(n)=2\)，则 \(2023n = 2^b(1 + 2^{a-b})\)（\(a > b\)），从而 \(1 + 2^{a-b} \equiv 0 \pmod 7\)，即 \(2^{a-b} \equiv -1 \equiv 6 \pmod 7\)。但 \(2\) 的幂次模 \(7\) 只可能余 \(1, 2, 4\)，故矛盾。由此确立下界 \(k(n) \ge 3\)。
- **分别构造模 \(7\) 与模 \(17^2\) 的指数充分条件**（*动机*：分别找出使 \(2^a + 2^b + 1\) 被 \(7\) 和 \(17^2\) 整除的指数同余条件，将复杂的整除问题化为指数上的周期性条件。）：注意到 \(7 = 2^2 + 2^1 + 1\) 且 \(2^3 \equiv 1 \pmod 7\)，因此只要 \(a \equiv 2 \pmod 3\) 且 \(b \equiv 1 \pmod 3\)（或反之），就有 \(7 \mid (2^a + 2^b + 1)\)。另一方面，\(17^2 = 289 = 2^8 + 2^5 + 1\)，且由欧拉定理 \(2^{\varphi(17^2)} = 2^{16 \cdot 17} \equiv 1 \pmod{17^2}\)，因此只要 \(a \equiv 8 \pmod{16 \cdot 17}\) 且 \(b \equiv 5 \pmod{16 \cdot 17}\)，就有 \(17^2 \mid (2^a + 2^b + 1)\)。
- **中国剩余定理合并求解并完成构造**（*动机*：将两个模数下的指数同余条件合并，确保存在满足 \(a > b > 0\) 的正整数解。）：由于 \(\gcd(3, 16 \cdot 17) = 1\)，根据中国剩余定理，同余方程组 \(a \equiv 2 \pmod 3, a \equiv 8 \pmod{272}\) 以及 \(b \equiv 1 \pmod 3, b \equiv 5 \pmod{272}\) 均有解，且可通过加上 \(3 \cdot 272\) 的适当倍数保证 \(a > b > 0\)（例如 \(a = 280, b = 5\) 或参考解二中的 \(a = 77, b = 16\)）。于是 \(n = (2^a + 2^b + 1)/2023\) 为正整数且 \(k(n) = 3\)。

### 6. 易错点分析

- **忽略指数互异与正性条件**：常见错法——在同余构造时忽略指数必须互不相同且为正整数的要求，例如得到 \(2^a + 2^a + 1\) 后误以为二进制中只有两个 \(1\)（实际会发生进位变成 \(2^{a+1} + 1\)，或若不进位则无法满足三项和）。；错因——二进制表示中 \(1\) 的个数等于写成不同 \(2\) 的幂次之和的项数；若两项指数相等则会合并进位，改变 \(1\) 的个数。；避坑策略——在构造 \(2^a + 2^b + 1\) 后，必须明确验证 \(a > b > 0\)（或 \(a \neq b\) 且均大于 \(0\)），确保三项对应二进制中三个不同的数位，从而 \(k(n)=3\) 且 \(n \ge 1\)。
- **欧拉函数与互素条件计算失误**：常见错法——误将 \(\varphi(17^2)\) 算成 \(17^2 - 1 = 288\)，或者在应用中国剩余定理时未检查模数 \(3\) 与 \(\varphi(289) = 272\) 是否互素。；错因——\(\varphi(p^2) = p^2 - p\) 而非 \(p^2 - 1\)；若错用 \(288\) 作为周期，则 \(3 \mid 288\)，会导致与模 \(3\) 的同余条件相冲突。；避坑策略——牢记素数幂的欧拉函数公式 \(\varphi(p^2) = p(p-1)\)，在本题中 \(\varphi(17^2) = 17 \times 16 = 272\)，并检验模数 \(3\) 与 \(272\) 互素。
- **未能转换视角导致枚举受阻**：常见错法——盲目尝试对 \(2023n\) 做长除法或从小到大枚举 \(n\)，未能将问题转化为指数上的同余方程。；错因——满足 \(k(n)=3\) 的最小 \(n = (2^{77} + 2^{16} + 1)/2023\) 已经非常巨大，手工枚举不可能找到。；避坑策略——先做模 \(7\) 和模 \(17\) 的简单测试排除 \(k=1, 2\)，或直接以“\(2023 \mid 2^a+2^b+1\)”为目标利用 CRT 构造，不要直接展开 \(2023n\) 的二进制。

**教学小结**：处理“\(2\) 的幂次之和被合数 \(M\) 整除”的问题时，核心策略是将 \(M\) 素因数分解：小素因子用于快速排除低项数（定下界），而高次素数幂的二进制展开配合欧拉周期 \(\varphi(p^e)\) 与中国剩余定理（CRT）则是将局部解拼装为全局构造的通用利器。

## Putnam 2023 questions (Kedlaya archive community mirror) · B3（`putnam-2023-AB-questions-qB3`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 局部-整体转化 / 不变量与单调量 / 归纳与递推 / 易错:边界与退化情形 / 易错:充分性与必要性混淆
- **知识专题**：概率与期望 / 组合序列 / 局部极值

### 原题整理

若实数序列 \(y_1, y_2, \ldots, y_k\) 满足 \(k = 1\)，或者 \(y_2 - y_1, y_3 - y_2, \ldots, y_k - y_{k-1}\) 均非零且正负交替，则称该序列为锯齿（zigzag）序列。设 \(X_1, X_2, \ldots, X_n\) 独立同分布于区间 \([0,1]\) 上的均匀分布。记 \(a(X_1, X_2, \ldots, X_n)\) 为存在递增整数下标 \(i_1 < i_2 < \cdots < i_k\) 使得 \(X_{i_1}, X_{i_2}, \ldots, X_{i_k}\) 构成锯齿序列的最大 \(k\) 值。求 \(n \ge 2\) 时 \(a(X_1, X_2, \ldots, X_n)\) 的数学期望。

### 1. 只看原题盲解尝试

**切入思路**：利用“连续均匀分布几乎必然两两不等”的性质，将最长锯齿（zigzag）子序列的长度转化为相邻差分符号的变化次数（即序列内部严格局部极值点的个数）加 \(2\)，再通过期望的线性性直接求解。

**推演步骤**：
- 由于 \(X_1, \ldots, X_n\) 独立同分布于 \([0,1]\) 上的连续均匀分布，它们几乎必然两两互不相等（即 \(\mathbb{P}(\exists i \ne j,\, X_i = X_j) = 0\)）。由于 \(1 \le a(X_1, \ldots, X_n) \le n\) 有界，零测集不影响期望，以下均在 \(X_1, \ldots, X_n\) 两两不等的条件下讨论。
- 对 \(j = 1, 2, \ldots, n-1\)，定义相邻差分的符号 \(s_j = \operatorname{sgn}(X_{j+1} - X_j) \in \{+1, -1\}\)。对 \(j = 1, 2, \ldots, n-2\)，定义示性随机变量 \(I_j = \mathbf{1}_{\{s_j \ne s_{j+1}\}}\)，即 \(X_{j+1}\) 是否为原序列的内部局部极值点。记 \(m = \sum_{j=1}^{n-2} I_j\)。
- 证明下界 \(a(X_1, \ldots, X_n) \ge m + 2\)：设所有满足 \(s_j \ne s_{j+1}\) 的下标为 \(j_1 < j_2 < \cdots < j_m\)，取子序列 \(X_1, X_{j_1+1}, X_{j_2+1}, \ldots, X_{j_m+1}, X_n\)，共 \(m+2\) 项。由于相邻所选下标之间不存在符号变化，序列在每一段上严格单调，且在每个 \(X_{j_r+1}\) 处单调性反转，因此它构成一个长度为 \(m+2\) 的锯齿子序列。
- 证明上界 \(a(X_1, \ldots, X_n) \le m + 2\)：设 \(X_{i_1}, X_{i_2}, \ldots, X_{i_k}\)（\(1 \le i_1 < \cdots < i_k \le n\)，\(k \ge 2\)）为任意长度为 \(k\) 的锯齿子序列，记 \(d_r = \operatorname{sgn}(X_{i_{r+1}} - X_{i_r})\)。由于 \(X_{i_{r+1}} - X_{i_r} = \sum_{j=i_r}^{i_{r+1}-1} (X_{j+1} - X_j)\)，对每个 \(r \in \{1, \ldots, k-1\}\)，区间 \([i_r, i_{r+1}-1]\) 内必至少存在一个整数 \(u_r\) 使得 \(s_{u_r} = d_r\)。显然 \(1 \le u_1 < u_2 < \cdots < u_{k-1} \le n-1\) 且 \(s_{u_1}, \ldots, s_{u_{k-1}}\) 正负交替。因此每个不交区间 \([u_r, u_{r+1}-1]\)（\(r = 1, \ldots, k-2\)）中至少包含一个使得 \(s_j \ne s_{j+1}\) 的下标 \(j\)，故 \(m \ge k - 2\)，即 \(k \le m + 2\)。
- 综合上下界可得几乎必然有 \(a(X_1, \ldots, X_n) = 2 + \sum_{j=1}^{n-2} I_j\)。由期望的线性性，\(\mathbb{E}[a(X_1, \ldots, X_n)] = 2 + \sum_{j=1}^{n-2} \mathbb{P}(s_j \ne s_{j+1})\)。
- 对任意 \(j \in \{1, \ldots, n-2\}\)，\((X_j, X_{j+1}, X_{j+2})\) 的 \(3! = 6\) 种相对大小排列等概率出现，其中 \(X_{j+1}\) 为三者中最大或最小的排列共有 \(4\) 种（\((1,3,2), (2,3,1), (2,1,3), (3,1,2)\)），故 \(\mathbb{P}(s_j \ne s_{j+1}) = \frac{4}{6} = \frac{2}{3}\)。
- 代入求和得 \(\mathbb{E}[a(X_1, \ldots, X_n)] = 2 + (n - 2) \cdot \frac{2}{3} = \frac{2n + 2}{3}\)。并对 \(n = 2\)（结果为 \(2\)）、\(n = 3\)（结果为 \(\frac{8}{3}\)）及 \(n = 4\)（全排列枚举得 \(\frac{2 \cdot 2 + 12 \cdot 3 + 10 \cdot 4}{24} = \frac{10}{3}\)）验证一致。

**盲解结论**：\(\frac{2n+2}{3}\)

### 2. 对照答案复盘

盲解与参考解答的最终答案完全一致，均为 \(\frac{2n+2}{3}\)，且核心组合刻画完全相同（均将最长锯齿子序列长度刻画为内部局部极值点个数加 \(2\)，即单调段数 \(N+1\)）。区别在于细节表述：参考解答通过“删除一个元素不会增加单调段数 \(N\)”来证明上界 \(a \le N+1\)，并利用差分 \(a(X_1,\ldots,X_n) - a(X_2,\ldots,X_n)\) 对 \(n\) 归纳；盲解则通过差分符号交替区间分离来证明上界，并用示性变量 \(I_j = \mathbf{1}_{\{s_j \ne s_{j+1}\}}\) 配合期望线性性直接求和，省去了归纳步骤（注：参考解答原图在公式中有一处笔误，将 \(a(X_2,\ldots,X_n)\) 印作了 \(a(X_1,\ldots,X_{n-1})\)，但因独立同分布对称性不影响结论）。

### 3. 困难点与破局关键

- **将全局“最长子序列”转化为局部“极值点计数”**：最长的锯齿子序列似乎可以在原序列中“跳着选”，初看像是一个复杂的动态规划或全局组合优化问题；真正的关键洞察在于证明“跳过某段内部元素并不会创造新的转折”，从而将最长长度精确锁定为原序列的极值点个数加 \(2\)（或单调段数 \(N+1\)）。
- **上界 \(a(X_1, \ldots, X_n) \le N+1\) 的严格证明**：即便能构造出长度为 \(N+1\) 的锯齿子序列，也必须严格排除“存在某个跨越多个单调段的选法能得到更长锯齿子序列”的可能。参考解答采用“每次删去一个元素都不会使单调段数 \(N\) 增加”这一单调性，非常精炼地一举完成上界证明。

### 4. 问题拆解（教学引导）

- **识别分布特性与零测集处理**：注意到 \(X_1, \ldots, X_n\) 独立同分布于 \([0,1]\) 上的连续均匀分布，因此几乎必然两两互不相等，且任意 \(k\) 个变量的相对大小排列都是等概率的。这提示我们只需关注序列的相对序结构（排列）。
- **小规模试验寻找组合不变量**：手工枚举 \(n=2\)（必为 \(2\)）和 \(n=3\)（\(6\) 种排列中 \(4\) 种长为 \(3\)、\(2\) 种长为 \(2\)，期望 \(\frac{8}{3}\)），发现只有“单调排列”无法取到全长，进而猜想最长锯齿子序列长度与原序列的“单调转折点”直接相关。
- **确立局部-整体线性化思路**：在概率期望问题中，若随机变量能拆解为若干仅依赖局部连续几项的示性变量之和（或相邻长度的差分），就可以绕开整体分布计算，直接用期望线性性求解。

### 5. 答案拆解（逻辑骨架）

- **单调段划分与下界构造**（*动机*：先把看似自由的子序列问题锚定到原序列的极大单调段划分上，给出下界构造。）：将两两不等的序列 \(X_1, \ldots, X_n\) 划分为交替出现的极大单调递增段与递减段，设共有 \(N\) 段。注意相邻两段共用一个端点（即局部极大或极小值点），因此这 \(N\) 个单调段共有 \(N+1\) 个端点（含首尾 \(X_1, X_n\)）。这些端点自然构成一个长度为 \(N+1\) 的锯齿子序列，故 \(a(X_1, \ldots, X_n) \ge N+1\)。
- **利用“删项不增”证明上界**（*动机*：利用“删项不增”这一单调性质，严格封闭长度上界，从而建立精确等式。）：观察从序列中删去任意一项对单调段数 \(N\) 的影响：若删去的是某一段的内部元素，段数 \(N\) 不变；若删去的是两段的公共端点，则其中一段长度减 \(1\)（甚至消失），段数 \(N\) 不可能增加。对任意长度为 \(m\) 的锯齿子序列 \(X_{i_1}, \ldots, X_{i_m}\)，它可看作原序列删去若干项后的结果，而其自身的单调段数恰为 \(m-1\)，因此 \(m-1 \le N\)，即 \(a(X_1, \ldots, X_n) \le N+1\)。结合上一步即得 \(a(X_1, \ldots, X_n) = N+1\)。
- **计算首项差分的期望**（*动机*：通过首项差分把全局期望问题化归为仅涉及前 \(3\) 项的局部概率计算。）：对于 \(n \ge 3\)，考虑 \(a(X_1, X_2, \ldots, X_n) - a(X_2, \ldots, X_n)\)：当且仅当 \(X_1, X_2, X_3\) 单调时，\(X_1\) 只是延长了 \(X_2, X_3\) 所在的第一段单调段，段数 \(N\) 不变，差值为 \(0\)；否则 \(X_1, X_2\) 独立成一段，段数加 \(1\)，差值为 \(1\)。由于 \((X_1, X_2, X_3)\) 的 \(6\) 种排列等概，其中非单调的有 \(4\) 种，故 \(\mathbb{E}[a(X_1, \ldots, X_n) - a(X_2, \ldots, X_n)] = \frac{4}{6} = \frac{2}{3}\)。
- **归纳得出最终期望**（*动机*：结合边界初值与期望线性性完成闭式求解。）：当 \(n = 2\) 时，几乎必然有 \(X_1 \ne X_2\)，故 \(a(X_1, X_2) = 2\)，从而 \(\mathbb{E}[a(X_1, X_2)] = 2\)。再由 \(X_2, \ldots, X_n\) 与 \(X_1, \ldots, X_{n-1}\) 同分布以及期望的线性性，对 \(n\) 归纳即得 \(\mathbb{E}[a(X_1, \ldots, X_n)] = 2 + \frac{2}{3}(n-2) = \frac{2n+2}{3}\)。

### 6. 易错点分析

- **只证下界、漏证上界（充分性与必要性混淆）**：常见错法——只构造出由端点组成的长度为 \(N+1\) 的锯齿子序列，就直接声称 \(a(X_1, \ldots, X_n) = N+1\)，缺少上界证明。；错因——如果仅给出一个长度为 \(N+1\) 的锯齿子序列，只能说明 \(a(X_1, \ldots, X_n) \ge N+1\)，不能排除跨段选取元素拼出更长锯齿子序列的可能性。；避坑策略——在写出构造后，务必补上“任何锯齿子序列长度都不超过 \(N+1\)”的证明（例如利用删项不增性质或区间分离论证），形成双向不等式夹逼。
- **忽略相等零测集与边界情形**：常见错法——直接假设 \(X_1, \ldots, X_n\) 两两互不相等，或忽略 \(n=2\) 的边界情况。；错因——题目定义要求差分非零，若存在相等元素则单调段划分需修正；对于连续型随机变量，必须指出重合事件概率为零，严谨性才完整。；避坑策略——在解题开头明确说明：由于 \(X_1, \ldots, X_n\) 服从连续均匀分布，\(\mathbb{P}(\exists i \ne j, X_i = X_j) = 0\)，且 \(a\) 有界，因此可忽略相等情形；同时单独确认 \(n=2\) 时 \(a(X_1, X_2) = 2\) 几乎必然成立。
- **错误估计新增项对单调段数的增量**：常见错法——误以为新增 \(X_1\) 时只要 \(X_1 \ne X_2\) 就能使最长锯齿长度加 \(1\)，从而错算增量为 \(1\) 或 \(\frac{1}{2}\)。；错因——若 \(X_1, X_2, X_3\) 单调（例如 \(X_1 < X_2 < X_3\)），加入 \(X_1\) 只是延长了第一段单调段，段数 \(N\) 并不增加，因此 \(a\) 的值不变。；避坑策略——计算差分或递推项时，紧扣“相邻三元组 \((X_1, X_2, X_3)\) 是否单调”这一局部条件，并用 \(n=2, 3\) 的全排列枚举直接验算公式 \(\frac{2n+2}{3}\)。

**教学小结**：面对随机序列上的全局极值问题，先寻找“删项单调性”或极值点刻画将全局量转化为局部结构计数，再借助期望线性性（或首项差分）往往能绕开复杂的整体分布直接秒杀。

## Putnam 2024 questions (Kedlaya archive community mirror) · A1（`putnam-2024-AB-questions-qA1`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:基础热身 / 奇偶与同余 / 反证与分类讨论 / 构造与反例 / 易错:边界与退化情形 / 易错:隐含假设与越界推广
- **知识专题**：数论 / 丢番图方程 / 同余与整除

### 原题整理

求所有正整数 \(n\)，使得存在正整数 \(a, b, c\) 满足
\[2a^n + 3b^n = 4c^n.\]

### 1. 只看原题盲解尝试

**切入思路**：分情况讨论正整数 \(n\)：对 \(n=1\) 直接构造特解；对 \(n=2\) 利用模 \(3\) 二次剩余结合无穷递降法证明无解；对 \(n \ge 3\) 利用 \(2\)-进赋值（\(v_2\)）在模 \(n\) 下的余数互不相同导出矛盾。

**推演步骤**：
- 1. 验证 \(n = 1\)：方程化为 \(2a + 3b = 4c\)。取 \((a, b, c) = (1, 2, 2)\)，有 \(2 \times 1 + 3 \times 2 = 8 = 4 \times 2\)，均为正整数，故 \(n = 1\) 满足条件。
- 2. 排除 \(n = 2\)：假设存在正整数解 \((a, b, c)\) 满足 \(2a^2 + 3b^2 = 4c^2\)，取其中 \(a + b + c\) 最小的一组解。两边模 \(3\) 得 \(2a^2 \equiv c^2 \pmod 3\)。由于任意整数的平方模 \(3\) 只能为 \(0\) 或 \(1\)，故 \(c^2 \pmod 3 \in \{0, 1\}\)，而 \(2a^2 \pmod 3 \in \{0, 2\}\)。因此只能 \(2a^2 \equiv c^2 \equiv 0 \pmod 3\)，从而 \(3 \mid a\) 且 \(3 \mid c\)。设 \(a = 3a_1, c = 3c_1\)，代入方程并除以 \(3\) 得 \(6a_1^2 + b^2 = 12c_1^2\)，由此可知 \(3 \mid b^2\)，进而 \(3 \mid b\)。设 \(b = 3b_1\)，再除以 \(3\) 得 \(2a_1^2 + 3b_1^2 = 4c_1^2\)。此时 \((a_1, b_1, c_1)\) 也是正整数解且 \(a_1 + b_1 + c_1 < a + b + c\)，与最小性矛盾。故 \(n = 2\) 无解。
- 3. 排除 \(n \ge 3\)：对正整数 \(m\)，记 \(v_2(m)\) 为 \(m\) 的 \(2\)-进赋值（即满足 \(2^k \mid m\) 的最大非负整数 \(k\)）。假设对某个 \(n \ge 3\) 存在正整数解 \((a, b, c)\)，则三项的 \(2\)-进赋值分别为：
\[v_2(2a^n) = 1 + n v_2(a) \equiv 1 \pmod n,\]
\[v_2(3b^n) = n v_2(b) \equiv 0 \pmod n,\]
\[v_2(4c^n) = 2 + n v_2(c) \equiv 2 \pmod n.\]
因为 \(n \ge 3\)，所以 \(0, 1, 2\) 在模 \(n\) 下两两不同余，从而 \(v_2(2a^n)\)、\(v_2(3b^n)\) 与 \(v_2(4c^n)\) 两两不相等。特别地，\(v_2(2a^n) \neq v_2(3b^n)\)，根据 \(2\)-进赋值的性质有
\[v_2(4c^n) = v_2(2a^n + 3b^n) = \min\bigl(v_2(2a^n), v_2(3b^n)\bigr),\]
这意味着 \(v_2(4c^n)\) 必与 \(v_2(2a^n)\) 或 \(v_2(3b^n)\) 之一相等，矛盾。故对所有 \(n \ge 3\) 均无解。
- 4. 综上所述，唯一符合条件的正整数为 \(n = 1\)。

**盲解结论**：满足条件的正整数仅有 \(n = 1\)。

### 2. 对照答案复盘

Turn 1 盲解完全正确：最终答案 \(n = 1\) 与特解 \((1, 2, 2)\) 与参考解答一致。对 \(n = 2\)，盲解与参考解答均采用模 \(3\) 二次剩余论证（盲解用最小和无穷递降，参考解答用 \(\gcd(a, b, c) = 1\) 导出矛盾，本质相同）。对 \(n \ge 3\)，参考解答先设 \(\gcd(a, b, c) = 1\) 后通过奇偶性依次推出 \(2 \mid b, 2 \mid a, 2 \mid c\) 导出矛盾；盲解则直接比较三项的 \(2\)-进赋值模 \(n\) 的余数，二者均严密有效，参考解答的逐层奇偶剥离更为初等直观。

### 3. 困难点与破局关键

- **\(n = 2\) 与 \(n \ge 3\) 的局部障碍分离**：方程系数为 \(2, 3, 4\)，天然携带质因子 \(2\)，容易让人直接用奇偶性分析；但在 \(n = 2\) 时，\(2^{n-2} = 1\) 使得最后一步无法推出 \(2 \mid c\)，必须识别出这一障碍并切换模数（利用 \(2 + 3 \equiv 1 \pmod 3\) 或 \(2a^2 + 4c^2\) 在模 \(3\) 下的特殊性）。
- **齐次性与互素归约的运用**：方程关于 \((a, b, c)\) 是 \(n\) 次齐次的，即若 \((a, b, c)\) 是解，则 \((a/d, b/d, c/d)\) 也是解。利用这一点假定 \(\gcd(a, b, c) = 1\)，能将无穷递降简化为一步直接矛盾。

### 4. 问题拆解（教学引导）

- **小值试探与特解构造**：注意到方程 \(2a^n + 3b^n = 4c^n\) 含指数参数 \(n\)，应先试验 \(n = 1, 2, 3\) 等小值以建立直觉。当 \(n = 1\) 时为一次不定方程，容易凑出特解 \((a, b, c) = (1, 2, 2)\)。
- **系数结构与模数选择**：观察方程系数 \(2, 3, 4\)，其中 \(2\) 和 \(4 = 2^2\) 都是 \(2\) 的幂，而 \(3\) 为奇数。这种系数分布强烈提示在模 \(2\)（或 \(2\)-进赋值）下分析各项的奇偶性与 \(2\) 的幂次。
- **利用齐次性进行互素归约**：注意到方程左侧和右侧关于 \((a, b, c)\) 均为 \(n\) 次齐次式，因此若有解，必可除以 \(\gcd(a, b, c)\) 后假定 \(\gcd(a, b, c) = 1\)，从而把“无穷递降”转化为“同时被某个素数整除即矛盾”。

### 5. 答案拆解（逻辑骨架）

- **构造 \(n = 1\) 的解并确立反证目标**（*动机*：先确认所有存在解的 \(n\)，并将问题明确转化为证明 \(n \ge 2\) 无解。）：当 \(n = 1\) 时，取 \((a, b, c) = (1, 2, 2)\) 即可满足 \(2(1) + 3(2) = 8 = 4(2)\)。随后断言对所有 \(n \ge 2\) 均无正整数解。
- **处理 \(n = 2\)（模 \(3\) 二次剩余）**（*动机*：在 \(n = 2\) 时，系数的 \(2\)-幂次 \(1, 0, 2\) 在模 \(2\) 下不构成障碍，因此转而利用模 \(3\) 消去含 \(b\) 项（系数恰好为 \(3\)），且 \(-1\) 不是模 \(3\) 的二次剩余，从而锁死 \(a, c\)。）：假设 \(n = 2\) 有解且 \(\gcd(a, b, c) = 1\)。方程模 \(3\) 得 \(a^2 + c^2 \equiv 0 \pmod 3\)。由于平方数模 \(3\) 只能为 \(0\) 或 \(1\)，故必有 \(a^2 \equiv c^2 \equiv 0 \pmod 3\)，即 \(3 \mid a\) 且 \(3 \mid c\)。代回原式得 \(b^2 = 12(c/3)^2 - 6(a/3)^2\)，从而 \(3 \mid b\)，与 \(\gcd(a, b, c) = 1\) 矛盾。
- **处理 \(n \ge 3\)（逐层奇偶性剥离）**（*动机*：当 \(n \ge 3\) 时，\(a^n, b^n, c^n\) 在出现因子 \(2\) 后至少贡献 \(2^3 = 8\)，使得系数的 \(2\) 的幂次（\(1, 0, 2\)）逐层压倒对方，保证 \(b, a, c\) 依次被迫为偶数。）：假设 \(n \ge 3\) 有解且 \(\gcd(a, b, c) = 1\)。由 \(3b^n = 4c^n - 2a^n\) 知 \(b\) 为偶数；令 \(b = 2b'\) 并约去 \(2\) 得 \(a^n + 2^{n-1}\cdot 3(b')^n = 2c^n\)，因 \(n - 1 \ge 2 \ge 1\)，知 \(a\) 为偶数；再令 \(a = 2a'\) 并约去 \(2\) 得 \(2^{n-1}(a')^n + 2^{n-2}\cdot 3(b')^n = c^n\)，因 \(n - 2 \ge 1\)，知 \(c\) 也为偶数，与 \(\gcd(a, b, c) = 1\) 矛盾。

### 6. 易错点分析

- **忽视 \(n = 2\) 的边界失效情形**：常见错法——将 \(n \ge 3\) 的奇偶性递推直接套用到 \(n = 2\)，错误地认为 \(2^{n-2} \cdot 3(b/2)^n\) 也是偶数。；错因——当 \(n = 2\) 时，\(2^{n-2} = 2^0 = 1\)，系数不再含有因子 \(2\)，因此无法推出 \(c\) 为偶数（事实上 \(a, b\) 为偶数而 \(c\) 为奇数在模 \(4\) 下并不矛盾，例如 \(2(2)^2 + 3(2)^2 = 20 \equiv 4 \cdot 1^2 \pmod 8\) 不成立，但模 \(4\) 均为 \(0\)）。；避坑策略——在写完奇偶性或模 \(2^k\) 的推导后，务必显式检查指数 \(n-1 \ge 1\) 与 \(n-2 \ge 1\) 的成立条件，确认边界 \(n=2\) 是否被覆盖，并对失效的边界单独寻找新模数（如模 \(3\)）。
- **遗漏小指数特解或盲目套用定理**：常见错法——忽略 \(n = 1\) 的情形或误用费马大定理类比，直接断言方程对所有 \(n\) 均无解。；错因——当 \(n=1\) 时，\(2a + 3b = 4c\) 是一次不定方程，显然有无穷多正整数解（如 \((1, 2, 2)\)）；且原方程带有不同系数 \(2, 3, 4\)，不能直接套用费马大定理。；避坑策略——面对系数不全相同的丢番图方程，不要急于套用高深定理，先试探前几个小的 \(n\) 值（\(n=1, 2, 3\)）并尝试构造小整数解，同时检查方程的齐次性与模小素数的性质。
- **未利用齐次性归约到互素情形**：常见错法——未先约去公因子 \(\gcd(a, b, c)\) 或未使用最小性，导致证明“\(a, b, c\) 全被 \(2\) 或 \(3\) 整除”后无法闭环收尾。；错因——如果只说明 \(a, b, c\) 都是 \(2\) 的倍数或 \(3\) 的倍数，却没有先假定 \(\gcd(a, b, c) = 1\)（或最小解），就无法立即导出矛盾，仍需额外补全无穷递降论证。；避坑策略——遇到齐次丢番图方程时，第一步即明确写出“由方程关于 \((a, b, c)\) 齐次，不妨设 \(\gcd(a, b, c) = 1\)”，或采用最小正整数解进行无穷递降，以简化整除链条的书写。

**教学小结**：处理齐次丢番图方程时，先假设 \(\gcd(a, b, c) = 1\) 再结合小素数同余（尤其是系数中出现的素因子，如本题的 \(2\) 和 \(3\)）是最锋利的工具；同时务必警惕指数 \(n\) 较小时高次项退化导致的边界情形。

## Putnam 2024 questions (Kedlaya archive community mirror) · A2（`putnam-2024-AB-questions-qA2`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 生成函数与多项式 / 反证与分类讨论 / 易错:边界与退化情形 / 易错:隐含假设与越界推广
- **知识专题**：多项式整除 / 重根与导数 / 复数域根的分析

### 原题整理

求所有实系数多项式 \(p\)，使得存在实系数多项式 \(q\)，对所有实数 \(x\) 都满足
\[p(p(x)) - x = (p(x) - x)^2 q(x).\]

### 1. 只看原题盲解尝试

**切入思路**：先按 \(p\) 的次数 \(\deg p\) 分类讨论：当 \(\deg p \le 1\) 时直接代入检验，得到 \(p(x) = x + b\) 与 \(p(x) = -x + b\)（\(b \in \mathbb{R}\)）；当 \(\deg p = n \ge 2\) 时，在复数域 \(\mathbb{C}[x]\) 中考察 \(f(x) = p(x) - x\) 的根及其重数，先证明 \(f(x)\) 不可能有重根，再由链式法则证明 \(f(x)\) 的所有 \(n\) 个互异复根都是次数为 \(n - 1\) 的非零多项式 \(p'(x) + 1\) 的根，从而导出矛盾。

**推演步骤**：
- 因为多项式 \(p(p(x)) - x - (p(x) - x)^2 q(x)\) 对所有实数 \(x\) 取值为 \(0\)，所以它在 \(\mathbb{R}[x]\)（进而在 \(\mathbb{C}[x]\)）中是零多项式，即在 \(\mathbb{C}[x]\) 中有 \((p(x) - x)^2 \mid p(p(x)) - x\)。
- 讨论 \(\deg p \le 1\) 的情形：
（1）若 \(p(x) = c\) 为常数多项式，则 \(p(p(x)) - x = c - x\) 次数为 \(1\)，而 \((p(x) - x)^2 = (c - x)^2\) 次数为 \(2\)，不可能整除 \(c - x\)，故无解。
（2）若 \(p(x) = ax + b\)（\(a \ne 0\)），则 \(p(x) - x = (a - 1)x + b\)，\(p(p(x)) - x = (a^2 - 1)x + b(a + 1)\)。
- 当 \(a = 1\) 时，\(p(x) = x + b\)。若 \(b = 0\)，取 \(q(x) = 0\)（或任意多项式）即满足；若 \(b \ne 0\)，取常多项式 \(q(x) = \frac{2}{b}\) 即满足 \(2b = b^2 \cdot \frac{2}{b}\)。
- 当 \(a = -1\) 时，\(p(x) = -x + b\)，此时 \(p(p(x)) - x \equiv 0\)，取 \(q(x) = 0\) 即满足。
- 当 \(a \notin \{0, 1, -1\}\) 时，\(\deg(p(p(x)) - x) = 1\)，而 \(\deg((p(x) - x)^2) = 2\)，不可能整除。
- 假设 \(n = \deg p \ge 2\)，记 \(f(x) = p(x) - x\)，则 \(\deg f = n \ge 2\)。由代数基本定理，\(f(x)\) 在 \(\mathbb{C}\) 中有 \(n\) 个根（计重数）。设 \(\alpha \in \mathbb{C}\) 是 \(f(x)\) 的一个 \(m\) 重根（\(m \ge 1\)），由 \((f(x))^2 \mid p(p(x)) - x\) 可知，\((x - \alpha)^{2m} \mid p(p(x)) - x\)。
- 证明 \(m = 1\)（即 \(f(x)\) 无重根）：反设 \(m \ge 2\)，可写 \(p(x) - x = (x - \alpha)^m g(x)\)，其中 \(g \in \mathbb{C}[x]\) 且 \(g(\alpha) \ne 0\)。于是
\[p(p(x)) - x = (p(x) - x) + (p(p(x)) - p(x)) = (p(x) - x) + (p(x) - \alpha)^m g(p(x)).\]
注意 \(p(x) - \alpha = (x - \alpha)\bigl(1 + (x - \alpha)^{m-1} g(x)\bigr)\)。由于 \(m \ge 2\)，在模 \((x - \alpha)\) 意义下有 \(1 + (x - \alpha)^{m-1} g(x) \equiv 1 \pmod{x - \alpha}\) 以及 \(p(x) \equiv \alpha \pmod{x - \alpha}\)，从而 \(g(p(x)) \equiv g(\alpha) \pmod{x - \alpha}\)。因此
\[(p(x) - \alpha)^m g(p(x)) \equiv (x - \alpha)^m g(\alpha) \pmod{(x - \alpha)^{m+1}}.\]
又 \(p(x) - x = (x - \alpha)^m g(x) \equiv (x - \alpha)^m g(\alpha) \pmod{(x - \alpha)^{m+1}}\)，相加得
\[p(p(x)) - x \equiv 2 g(\alpha) (x - \alpha)^m \pmod{(x - \alpha)^{m+1}}.\]
因为 \(g(\alpha) \ne 0\)，所以 \((x - \alpha)^{m+1} \nmid p(p(x)) - x\)。但 \(m \ge 2\) 推出 \(2m \ge m + 1\)，这与 \((x - \alpha)^{2m} \mid p(p(x)) - x\) 矛盾！故 \(f(x)\) 的每个根都是单根。
- 于是 \(f(x)\) 在 \(\mathbb{C}\) 中有 \(n\) 个互异的根 \(\alpha_1, \alpha_2, \dots, \alpha_n\)。对每个 \(i \in \{1, \dots, n\}\)，由于 \(\alpha_i\) 是 \(f(x) = p(x) - x\) 的单根，有 \(p(\alpha_i) = \alpha_i\) 且 \(f'(\alpha_i) = p'(\alpha_i) - 1 \ne 0\)，即 \(p'(\alpha_i) \ne 1\)。另一方面，\((x - \alpha_i)^2 \mid p(p(x)) - x\) 蕴含 \(p(p(x)) - x\) 的导数在 \(x = \alpha_i\) 处为 \(0\)，即
\[p'(p(\alpha_i)) p'(\alpha_i) - 1 = (p'(\alpha_i))^2 - 1 = 0.\]
结合 \(p'(\alpha_i) \ne 1\)，必有 \(p'(\alpha_i) = -1\)，即 \(\alpha_1, \dots, \alpha_n\) 都是多项式 \(p'(x) + 1\) 的根。然而 \(\deg p = n \ge 2\) 推出 \(\deg(p'(x) + 1) = n - 1 \ge 1\)，一个次数为 \(n - 1\) 的非零多项式至多有 \(n - 1\) 个互异根，不可能有 \(n\) 个互异根，矛盾！

**盲解结论**：所有满足条件的实系数多项式为 \(p(x) = x + b\) 和 \(p(x) = -x + b\)，其中 \(b \in \mathbb{R}\) 为任意实数。

### 2. 对照答案复盘

盲解结果完全正确，结论 \(p(x) = \pm x + b\)（\(b \in \mathbb{R}\)）与参考解答完全一致，且对低次情形与高次情形的论证均严密无误。方法上，盲解通过分析复数域中 \(p(x)-x\) 的根及重数（排除重根后再对 \(p'(x)+1\) 计数根的个数），思路与参考解答的第二种解法（对 \(p(p(x))-x\) 求导并模 \(r(x)\)）相近；参考解答的第一种解法直接对 \(p(x + r(x))\) 在模 \(r(x)^2\) 意义下做泰勒展开，一步化简为 \(r(x) \mid 1 + p'(x)\)，更为简洁优雅。

### 3. 困难点与破局关键

- **从“恒等式”过渡到“模 \(r(x)^2\) 的多项式同余”**：许多同学习惯用数值代入（如令 \(p(x)=x\) 的实根代入），但实多项式 \(p(x)-x\) 未必有实根；即使转到复数域，如何同时处理可能存在的重根也是难点。将 \(p(p(x))\) 改写为 \(p(x + r(x))\) 并模 \(r(x)^2\) 展开，能一次性把“平方整除”转化为一次整除 \(r(x) \mid 1 + p'(x)\)，完全避开实根是否存在以及重根分类的繁琐。
- **次数比较中 \(\deg r < \deg p\) 的退化情形**：得到 \(r(x) \mid 1 + p'(x)\) 后，若直接认为 \(\deg r = \deg p > \deg(1 + p'(x))\) 会漏掉 \(\deg p = 1\) 且首项系数为 \(1\) 的情况——此时 \(r(x) = p(x) - x\) 次数退化为 \(0\)（甚至为 \(0\) 多项式），恰恰对应合法解 \(p(x) = x + c\)。

### 4. 问题拆解（教学引导）

- **识别核心条件与等价转化**：题目要求对所有实数 \(x\) 成立 \(p(p(x)) - x = (p(x) - x)^2 q(x)\)。由于两多项式在无穷多个点上相等即恒等，条件等价于多项式整除关系 \((p(x) - x)^2 \mid p(p(x)) - x\)。
- **尝试小次数情形并建立直觉**：先检验 \(\deg p \le 1\) 的线性与常数多项式。容易发现 \(p(x) = x + c\)（此时 \(p(x)-x = c\) 为常数，\(p(p(x))-x = 2c\) 总能被 \(c^2\) 整除）和 \(p(x) = -x + c\)（此时 \(p(p(x))-x \equiv 0\)）均满足条件，从而猜想不存在更高次的解。
- **寻找高次情形的破局工具（泰勒展开或求导）**：整除条件中出现平方因子 \(r(x)^2\)（记 \(r(x) = p(x) - x\)），而“被平方整除”在多项式中最自然的工具就是两类：一是将 \(p(p(x)) = p(x + r(x))\) 在模 \(r(x)^2\) 下做泰勒展开；二是对恒等式求导转化为模 \(r(x)\) 的同余与重根重数分析。

### 5. 答案拆解（逻辑骨架）

- **记号简化与模 \(r(x)^2\) 展开（第一解法）**（*动机*：利用模 \(r(x)^2\) 下的泰勒展开，将复合多项式 \(p(p(x))\) 的高次非线性结构直接线性化。）：令 \(r(x) = p(x) - x\)，则 \(p(x) = x + r(x)\)。将 \(p(x + r(x))\) 按 \(r(x)\) 展开（即多项式泰勒公式），凡含 \(r(x)^2\) 及更高次幂的项均能被 \(r(x)^2\) 整除，因此 \(p(p(x)) - x \equiv p(x) + p'(x)r(x) - x = r(x)(1 + p'(x)) \pmod{r(x)^2}\)。
- **消去公因子 \(r(x)\) 并分类讨论**（*动机*：通过消去因子并比较多项式次数，将整除关系彻底转化为对 \(p(x)\) 次数的强限制。）：由 \(r(x)^2 \mid r(x)(1 + p'(x))\) 可知，要么 \(r(x) \equiv 0\)（即 \(p(x) = x\)），要么 \(r(x) \mid 1 + p'(x)\)。若 \(1 + p'(x) \equiv 0\)，得 \(p(x) = -x + c\)；若 \(1 + p'(x) \not\equiv 0\)，则 \(\deg(p) - 1 = \deg(1 + p'(x)) \ge \deg(r)\)，仅当 \(p(x) = x + c\) 时才有 \(\deg(r) < \deg(p)\) 从而不矛盾。
- **求导法与重根分析（第二解法）**（*动机*：通过求导把平方整除降阶为一次整除，再结合复根重数排除重根，从而将“每个根都满足”升级为“整除关系”。）：对 \(r(x)^2 \mid p(p(x)) - x\) 两边求导并利用 \(p(x) \equiv x \pmod{r(x)}\)，得 \(r(x) \mid (p'(x))^2 - 1 = r'(x)(r'(x) + 2)\)。若 \(\alpha \in \mathbb{C}\) 是 \(r(x)\) 的 \(m\) 重根（\(m \ge 2\)），则 \(\alpha\) 在 \(r'(x)\) 中重数为 \(m - 1\) 且不是 \(r'(x) + 2\) 的根，导致右端重数不足 \(m\)，矛盾。故 \(r(x)\) 无重根且每个根都是 \(r'(x) + 2\) 的根，即 \(r(x) \mid r'(x) + 2\)，同样由次数比较得出 \(r(x)\) 为常数或 \(r'(x) + 2 \equiv 0\)。

### 6. 易错点分析

- **漏掉 \(p(x) = x + c\)（\(c \ne 0\)）的解**：常见错法——在得到 \(\deg(1 + p'(x)) \ge \deg(r(x))\) 后，直接默认 \(\deg(r(x)) = \deg(p)\)，从而得出无解的错误结论。；错因——当 \(p(x) = x + c\) 时，\(x\) 项与 \(-x\) 相消，导致 \(\deg(r(x)) = 0 < 1 = \deg(p)\)，次数不等式 \(\deg(p) - 1 \ge \deg(r)\)（即 \(0 \ge 0\)）实际上是成立的。；避坑策略——在比较 \(\deg(p(x) - x)\) 与 \(\deg p\) 时，务必单独检查 \(\deg p = 1\) 且首项系数为 \(1\) 的退化情形；最好在解题一开始就先把 \(\deg p \le 1\) 完整讨论清楚。
- **忽略 \(r(x) \equiv 0\) 的情形并直接做多项式除法**：常见错法——从 \(r(x)^2 \mid r(x)(1 + p'(x))\) 直接消去 \(r(x)\) 得到 \(r(x) \mid 1 + p'(x)\)，或者在 \(p(x) = x\) 时认为 \(q(x)\) 不存在。；错因——多项式环中消去律要求被消去的因子非零；当 \(r(x) \equiv 0\)（即 \(p(x) = x\)）时，原等式化为 \(0 = 0 \cdot q(x)\)，取 \(q(x) = 0\) 即可成立。；避坑策略——凡是在整除或同余式两边同时消去多项式因子时，必须先将“该因子为零多项式”单独列为一个分支。
- **仅在实数域内讨论 \(p(x) - x\) 的根**：常见错法——假设 \(p(x) - x = 0\) 有实根 \(\alpha\)，然后代入 \((p'(\alpha))^2 = 1\) 导出矛盾。；错因——高次实系数多项式 \(p(x) - x\)（例如偶数次多项式）在 \(\mathbb{R}\) 上可能完全没有实根，此时无法取到实根 \(\alpha\)。；避坑策略——遇到多项式根的存在性或重数问题，应先将实数域恒等式提升到 \(\mathbb{R}[x]\) 甚至 \(\mathbb{C}[x]\) 中，利用代数基本定理保证根的存在性；或直接采用不依赖取根的多项式同余法（如模 \(r(x)^2\) 展开）。

**教学小结**：处理形如 \(f(x)^2 \mid g(x)\) 的多项式平方整除问题，两条最核心的通法路径是“在 \(x\) 处按 \(f(x)\) 做泰勒展开并模 \(f(x)^2\)”以及“对整除式求导转化为模 \(f(x)\) 与重根分析”；同时在比较 \(\deg(p(x) - x)\) 与 \(\deg p\) 时要时刻警惕首项相消导致的次数退化。

## Putnam 2024 questions (Kedlaya archive community mirror) · A3（`putnam-2024-AB-questions-qA3`）

- **教学标签**：训练:技巧进阶 / 构造与反例 / 对称与轮换 / 易错:计数重复与漏算 / 易错:符号与方向

### 原题整理

设 \(S\) 为所有满足以下条件的双射
\[T: \{1, 2, 3\} \times \{1, 2, \dots, 2024\} \to \{1, 2, \dots, 6072\}\]
构成的集合：对所有 \(j \in \{1, 2, \dots, 2024\}\) 有 \(T(1, j) < T(2, j) < T(3, j)\)，且对所有 \(i \in \{1, 2, 3\}\) 与 \(j \in \{1, 2, \dots, 2023\}\) 有 \(T(i, j) < T(i, j+1)\)。是否存在 \(a, c \in \{1, 2, 3\}\) 以及 \(b, d \in \{1, 2, \dots, 2024\}\)，使得 \(S\) 中满足 \(T(a, b) < T(c, d)\) 的元素 \(T\) 所占的比例在 \(\frac{1}{3}\) 到 \(\frac{2}{3}\) 之间（含端点）？

### 1. 只看原题盲解尝试

**切入思路**：直接构造满足条件的坐标对 \((a, b) = (2, 1)\) 与 \((c, d) = (1, 2)\)。注意到对于任意满足条件的双射（即 \(3 \times 2024\) 标准杨表）\(T \in S\)，必有 \(T(1, 1) = 1\)，且数字 \(2\) 只能出现在 \((2, 1)\) 或 \((1, 2)\) 处，从而 \(T(2, 1) < T(1, 2)\) 当且仅当 \(T(2, 1) = 2\)。将去掉 \((1, 1), (2, 1)\) 后的斜杨表旋转 \(180^\circ\) 并取补数，可与形状为 \((2024, 2023, 2023)\) 的标准杨表建立双射；利用钩长公式（Hook-Length Formula）计算两个杨表数之比，即可得到精确比例 \(\frac{2025}{6071} \in \left[\frac{1}{3}, \frac{2}{3}\right]\)。

**推演步骤**：
- 令 \(n = 2024\)，将 \(S\) 中的双射 \(T\) 视为形状为 \((n, n, n)\) 的标准杨表（Standard Young Tableau，行内严格递增、列内严格递增，填入 \(1, 2, \dots, 3n\)）。选取 \((a, b) = (2, 1)\) 与 \((c, d) = (1, 2)\)。
- 证明 \(T(2, 1) < T(1, 2) \iff T(2, 1) = 2\)：由单调性可知，任意 \((i, j) \ne (1, 1)\) 均满足 \(T(1, 1) < T(i, j)\)，故必有 \(T(1, 1) = 1\)。进一步地，除 \((2, 1)\) 和 \((1, 2)\) 外，其余位置要么满足 \(T(1, 1) < T(2, 1) < T(3, 1)\)，要么满足 \(T(1, 1) < T(1, 2) < T(i, j)\)，因此数值 \(2\) 只能位于 \((2, 1)\) 或 \((1, 2)\)。若 \(T(2, 1) = 2\)，则 \(T(1, 2) \ge 3 > T(2, 1)\)；若 \(T(1, 2) = 2\)，则 \(T(2, 1) \ge 3 > T(1, 2)\)。由此可见 \(T(2, 1) < T(1, 2)\) 等价于 \(T(2, 1) = 2\)。
- 计算 \(S\) 中满足 \(T(2, 1) = 2\) 的元素个数：设 \(S_1 = \{T \in S : T(2, 1) = 2\}\)。对任意 \(T \in S_1\)，在去掉 \((1, 1)\) 与 \((2, 1)\) 后剩余的格子集合 \(D = (\{1, 2, 3\} \times \{1, \dots, n\}) \setminus \{(1, 1), (2, 1)\}\) 上，\(T\) 取遍 \(\{3, 4, \dots, 3n\}\)。定义形状为 \(\lambda = (n, n-1, n-1)\) 的杨表 \(T'\) 如下：对 \(1 \le r \le 3\) 与 \(1 \le c \le \lambda_r\)，令 \(T'(r, c) = 3n + 1 - T(4 - r, n + 1 - c)\)。易验证 \((4 - r, n + 1 - c)\) 恰好遍历 \(D\)，\(T'\) 取遍 \(\{1, 2, \dots, 3n - 2\}\)，且 \(T'\) 仍保持行、列严格递增。因此 \(T \mapsto T'\) 给出了 \(S_1\) 与形状为 \((n, n-1, n-1)\) 的标准杨表集合之间的双射，即 \(|S_1| = f^{(n, n-1, n-1)}\)，而 \(|S| = f^{(n, n, n)}\)。
- 利用钩长公式（Hook-Length Formula）计算 \(f^{(n, n, n)}\) 与 \(f^{(n, n-1, n-1)}\)：对于形状 \((n, n, n)\)，第 \(1, 2, 3\) 行的钩长乘积分别为 \(\frac{(n+2)!}{2}\)、\((n+1)!\)、\(n!\)，故
\[|S| = f^{(n, n, n)} = \frac{2(3n)!}{n!(n+1)!(n+2)!}.\]
对于形状 \((n, n-1, n-1)\)，第 \(1\) 行前 \(n-1\) 个格子的钩长为 \(n+2, n+1, \dots, 4\)，第 \(n\) 个格子的钩长为 \(1\)，乘积为 \(\frac{(n+2)!}{6}\)；第 \(2\) 行钩长乘积为 \(n!\)；第 \(3\) 行钩长乘积为 \((n-1)!\)，故
\[|S_1| = f^{(n, n-1, n-1)} = \frac{6(3n-2)!}{(n-1)!n!(n+2)!}.\]
- 求比例并验证范围：
\[\frac{|S_1|}{|S|} = \frac{6(3n-2)!}{(n-1)!n!(n+2)!} \cdot \frac{n!(n+1)!(n+2)!}{2(3n)!} = 3 \cdot \frac{n(n+1)}{3n(3n-1)} = \frac{n+1}{3n-1}.\]
代入 \(n = 2024\)，得该比例为 \(\frac{2025}{6071}\)。由于 \(3 \times 2025 = 6075 > 6071\) 且 \(3 \times 2025 = 6075 < 2 \times 6071 = 12142\)，故 \(\frac{1}{3} < \frac{2025}{6071} < \frac{2}{3}\)，满足题目要求。

**盲解结论**：存在，例如取 \((a, b) = (2, 1)\) 与 \((c, d) = (1, 2)\)。此时 \(S\) 中满足 \(T(2, 1) < T(1, 2)\) 的元素所占比例恰好为 \(\frac{2025}{6071}\)，满足 \(\frac{1}{3} \le \frac{2025}{6071} \le \frac{2}{3}\)。

**盲解时的疑虑/卡点**：题目图片右侧边缘有轻微裁剪（例如 `j \in`、`i \in`、`a and c`、`that the`、`T(c, d)` 的末尾字符被截断），但根据上下文语境及标准数学记号可以唯一确定题面，不影响解答的严密性。

### 2. 对照答案复盘

盲解过程与结果和参考解答完全一致：均直接构造 \((a, b) = (2, 1)\) 与 \((c, d) = (1, 2)\)，利用 \(T(1, 1) = 1\) 与 \(2 \in \{T(1, 2), T(2, 1)\}\) 将事件 \(T(2, 1) < T(1, 2)\) 等价转化为 \(T(2, 1) = 2\)，再通过“取补数 \(3n+1-i\) 并绕中心旋转 \(180^\circ\)”将计数转化为形状 \((n, n-1, n-1)\) 的标准杨表个数，最后用钩长公式算出比例为 \(\frac{n+1}{3n-1} = \frac{2025}{6071} \in \left[\frac{1}{3}, \frac{2}{3}\right]\)。此外，参考解答在 Remark 中补充了三行标准杨表计数公式的初等归纳证明，使得不直接引用一般钩长公式也可完成自洽证明。

### 3. 困难点与破局关键

- **选对候选元素：从“相对大小”转化为“数值 \(2\) 的位置”**：题目问的是“是否存在”一对坐标，表面上像极值或偏序集理论中的存在性论证（著名的 \(1/3\text{-}2/3\) 猜想），但实际上取最靠近左上角的不可比元素对 \((2, 1)\) 与 \((1, 2)\) 即可直接精确算出比例。如何想到从极端（边界）位置入手，将相对大小比较简化为“数字 \(2\) 在何处”，是破题的关键。
- **斜杨表向正标准杨表的对合化归**：去掉 \((1, 1)\) 和 \((2, 1)\) 后得到的是斜形状（skew shape），不能直接套用标准杨表的钩长公式。必须通过“对数值取补 \(3n+1-i\)”与“将图形旋转 \(180^\circ\)（行列同时反向）”的复合对合变换，将其化归为正形状 \((n, n-1, n-1)\) 的标准杨表。

### 4. 问题拆解（教学引导）

- **结构识别：标准杨表模型**：将双射 \(T: \{1, 2, 3\} \times \{1, \dots, n\} \to \{1, \dots, 3n\}\) 视为 \(3 \times n\) 的矩形阵列（标准杨表），其中 \(n = 2024\)，满足每行从左到右严格递增、每列从上到下严格递增。
- **寻找突破口：聚焦左上角边界元素**：对于任意合法填写，\(1\) 必在 \((1, 1)\)，而 \(2\) 只能在 \((2, 1)\) 或 \((1, 2)\)。注意到 \((2, 1)\) 与 \((1, 2)\) 是最简单的一对不可比元素，且 \(T(2, 1) < T(1, 2)\) 恰好等价于 \(T(2, 1) = 2\)，从而避免了讨论两个元素同时取各种值的复杂情况。
- **量化目标：转化为杨表计数比值**：若能精确求出“\(T(2, 1) = 2\) 的填法数”与“总填法数”之比，只需验证该比值落在 \(\left[\frac{1}{3}, \frac{2}{3}\right]\) 内即可。由于 \(n = 2024\) 很大，自然想到利用标准杨表计数的钩长公式（或对行长 \((n_1, n_2, n_3)\) 建立递推公式）。

### 5. 答案拆解（逻辑骨架）

- **等价转化：\(T(2, 1) < T(1, 2) \iff T(2, 1) = 2\)**（*动机*：将两个位置的大小比较事件化简为单个位置的赋值事件，从而把计数范围缩减到去掉两个固定格子后的子图。）：选取 \((a, b) = (2, 1)\) 与 \((c, d) = (1, 2)\)。由行列递增性，\(T(1, 1) = 1\)；而除 \((2, 1)\) 与 \((1, 2)\) 外的所有格子均严格大于 \((2, 1)\) 或 \((1, 2)\) 之一，故 \(2 \in \{T(2, 1), T(1, 2)\}\)。因此 \(T(2, 1) < T(1, 2)\) 当且仅当 \(T(2, 1) = 2\)（此时必有 \(T(1, 2) \ge 3\)）。
- **对合双射：将剩余区域化归为正标准杨表**（*动机*：钩长公式只适用于左上对齐的 Ferrers 图（正杨表），需要消除左上角缺失两个格子带来的“斜形状”障碍。）：设 \(T(2, 1) = 2\)。删去 \((1, 1)\) 与 \((2, 1)\)，对余下的 \(3n - 2\) 个格子，将其中数值 \(x\) 替换为 \(3n + 1 - x\)（数值范围变为 \(1, \dots, 3n - 2\)），并将整个阵列沿水平和垂直方向同时翻转（即 \((i, j) \mapsto (4 - i, n + 1 - j)\)）。由于取补和翻转均反转单调性，两者复合后恰好保持“从左到右递增、从上到下递增”，且三行长度变为 \((n, n-1, n-1)\)。这就建立了与形状 \((n, n-1, n-1)\) 的标准杨表之间的一一对应。
- **公式计算与区间验证**（*动机*：两形状的阶乘因子几乎全部约去，比值化简为关于 \(n\) 的简单有理分式，便于直接比较大小。）：利用一般三行标准杨表计数公式（可由钩长公式直接给出，也可对 \(n_1 + n_2 + n_3\) 归纳证明）：对 \(n_1 \ge n_2 \ge n_3 \ge 0\)，
\[f(n_1, n_2, n_3) = \frac{(n_1 - n_2 + 1)(n_1 - n_3 + 2)(n_2 - n_3 + 1)(n_1 + n_2 + n_3)!}{(n_1 + 2)!(n_2 + 1)!n_3!}.\]
由此直接计算比值：
\[\frac{f(n, n-1, n-1)}{f(n, n, n)} = \frac{2 \cdot 3 \cdot (n+1) \cdot n}{1 \cdot 2 \cdot 3n(3n-1)} = \frac{n+1}{3n-1} = \frac{1}{3} + \frac{4}{9n-3}.\]
代入 \(n = 2024\)，得到 \(\frac{2025}{6071}\)，显然严格大于 \(\frac{1}{3}\) 且小于 \(\frac{2}{3}\)。

### 6. 易错点分析

- **斜杨表双射中漏做“取补与翻转”**：常见错法——去掉 \((1, 1)\) 与 \((2, 1)\) 后，直接把剩余格子向左平移并视为标准杨表，而忘记同时做行、列反转与数值取补。；错因——从左上角删去格子后，剩余形状不再是左上对齐的 Ferrers 图（例如第 \(3\) 行比第 \(1, 2\) 行长）；直接左移会破坏列递增条件。必须先将数值取补 \(3n + 1 - i\) 使单调性反向，再将行列下标同时反向（即旋转 \(180^\circ\)），才能恢复左上对齐且行、列严格递增的标准杨表。；避坑策略——在构建杨表双射时，必须先将原始格子集合写出，逐一核对映射后行、列下标的递增方向是否仍然保持一致。
- **非矩形杨表钩长计算漏项或记错修正因子**：常见错法——将 \(f^{(n, n-1, n-1)}\) 的钩长公式误写或漏算第 \(1\) 行末尾格子 \((1, n)\) 的钩长，或者在一般三行公式中记错分子的差值修正项 \((n_1 - n_2 + 1)(n_1 - n_3 + 2)(n_2 - n_3 + 1)\)。；错因——当各行长度不等时，较长行右侧凸出部分的格子下方没有格子，钩长并非连续递减；若错误套用矩形形状的阶乘模式会导致结果偏差。；避坑策略——计算一般形状 \(\lambda\) 的标准杨表数时，直接套用完整的钩长公式逐格计算每行钩长乘积，并用 \(n=2, 3\) 等小规模情形手工验算比值。
- **盲目选取内部元素或试图硬证一般 \(1/3\text{-}2/3\) 猜想**：常见错法——试图对一般偏序集证明抽象的 \(1/3\text{-}2/3\) 猜想，或选取矩阵内部的元素（如 \((1, 1012)\) 与 \((2, 1012)\)）进行比较。；错因——一般偏序集的 \(1/3\text{-}2/3\) 猜想至今仍是著名的公开难题；而内部元素在杨表中的相对顺序无法简化为“某个固定值落在特定位置”的简单事件，极难精确计数。；避坑策略——在“存在性”证明中优先尝试端角处最受约束的元素，或通过小规模实验（如 \(n=2, 3\)）观察各对元素的比较概率，再锁定最易精确计算的候选对。

**教学小结**：面对涉及“线性扩张/标准杨表”的存在性比例问题，优先考察最靠近极值端点（如左上角）的不可比元素对，往往能将复杂的比较概率转化为单点赋值计数；而处理左上角缺失的斜杨表时，“取补数 + 旋转 \(180^\circ\)”是将其化归为标准正杨表的经典对合技巧。

## Putnam 2024 questions (Kedlaya archive community mirror) · A4（`putnam-2024-AB-questions-qA4`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 奇偶与同余 / 局部-整体转化 / 反证与分类讨论 / 易错:边界与退化情形 / 易错:隐含假设与越界推广 / 易错:充分性与必要性混淆
- **知识专题**：原根与阶 / 模p等差数列 / 补集转化

### 原题整理

求所有素数 \(p > 5\)，使得存在整数 \(a\) 和满足 \(1 \le r \le p - 1\) 的整数 \(r\)，具有如下性质：序列 \(1, a, a^2, \dots, a^{p-5}\) 可以重新排列成一个序列 \(b_0, b_1, b_2, \dots, b_{p-5}\)，使得对所有 \(1 \le n \le p - 5\)，都有 \(b_n - b_{n-1} - r\) 能被 \(p\) 整除。

### 1. 只看原题盲解尝试

**切入思路**：将序列在模 \(p\) 意义下视为长为 \(p-4\) 的等差数列。首先利用公差 \(r \not\equiv 0 \pmod p\) 推出 \(1, a, \dots, a^{p-5}\) 模 \(p\) 两两不同，从而证明当 \(p \ge 11\) 时 \(a\) 必为模 \(p\) 的原根。接着取补集，将“长为 \(p-4\) 的等差数列”转化为其补集 \(\{0, a^{-3}, a^{-2}, a^{-1}\}\) 在 \(\mathbb{F}_p\) 中构成长为 \(4\) 的等差数列，乘以 \(a^3\) 后即 \(\{0, 1, a, a^2\}\) 构成长为 \(4\) 的等差数列。最后按 \(0\) 在等差数列中的位置分类讨论，排除所有 \(p \ge 11\) 的情况，并直接构造验证 \(p = 7\)。

**推演步骤**：
- **1. 转化为模 \(p\) 等差数列与元素互异性：** 由题意，对 \(1 \le n \le p - 5\) 有 \(b_n \equiv b_{n-1} + r \pmod p\)，故 \(b_n \equiv b_0 + nr \pmod p\)（\(0 \le n \le p - 5\)）。因为 \(1 \le r \le p - 1\)，所以 \(\gcd(r, p) = 1\)，又 \(p - 4 < p\)，因此 \(b_0, b_1, \dots, b_{p-5}\) 在模 \(p\) 下两两不同。从而 \(1, a, a^2, \dots, a^{p-5}\) 在模 \(p\) 下也必须两两不同。
- **2. 确定 \(a\) 模 \(p\) 的阶：** 因为 \(p > 5\)，所以 \(p - 5 \ge 2\)。若 \(p \mid a\)，则 \(a \equiv a^2 \equiv 0 \pmod p\)，与互异性矛盾，故 \(p \nmid a\)。设 \(d = \operatorname{ord}_p(a)\) 为 \(a\) 模 \(p\) 的阶，则 \(d \mid p - 1\) 且由前 \(p - 4\) 项互异可知 \(d \ge p - 4\)。若 \(d < p - 1\)，则 \(d \le \frac{p-1}{2}\)，于是 \(\frac{p-1}{2} \ge p - 4\)，解得 \(p \le 7\)。
- **3. 检验 \(p = 7\)：** 当 \(p = 7\) 时，取 \(a = 3\)，\(r = 1\)，原序列为 \(1, 3, 9\)，重排为 \(b_0 = 1, b_1 = 9, b_2 = 3\)，此时 \(b_1 - b_0 - 1 = 7\)，\(b_2 - b_1 - 1 = -7\)，均能被 \(7\) 整除。因此 \(p = 7\) 满足条件。
- **4. 当 \(p \ge 11\) 时的补集转化：** 当 \(p \ge 11\) 时，\(\frac{p-1}{2} < p - 4\)，故必有 \(d = p - 1\)，即 \(a\) 是模 \(p\) 的原根。此时 \(S = \{1, a, \dots, a^{p-5}\} \pmod p\) 在 \(\mathbb{F}_p\) 中的补集为 \(T = \{0, a^{p-4}, a^{p-3}, a^{p-2}\} \equiv \{0, a^{-3}, a^{-2}, a^{-1}\} \pmod p\)。另一方面，\(S\) 是 \(\mathbb{F}_p\) 中长为 \(p - 4\)、公差为 \(r\) 的等差数列，故其补集 \(T\) 也是 \(\mathbb{F}_p\) 中长为 \(4\)、公差为 \(r\) 的等差数列：\(\{b_0 - 4r, b_0 - 3r, b_0 - 2r, b_0 - r\} \pmod p\)。将 \(T\) 中每个元素同乘 \(a^3 \not\equiv 0 \pmod p\)，可得 \(\{0, 1, a, a^2\} \pmod p\) 是 \(\mathbb{F}_p\) 中长为 \(4\)、公差为 \(d' \equiv a^3 r \not\equiv 0 \pmod p\) 的等差数列。
- **5. 分类讨论 \(p \ge 11\) 时 \(\{0, 1, a, a^2\}\) 的等差结构：** 通过将公差 \(d'\) 替换为 \(-d'\)（如有必要），可假设 \(0\) 是该 \(4\) 项等差数列的第 \(1\) 项或第 \(2\) 项。注意到 \(a\) 为原根且 \(p \ge 11\)，故 \(a \not\equiv 1, -1 \pmod p\) 且 \(a^2 \not\equiv 1 \pmod p\)。
- **情形一：** 等差数列为 \(\{0, d', 2d', 3d'\} \pmod p\)，即 \(\{1, a, a^2\} \equiv \{d', 2d', 3d'\} \pmod p\)。
  - 若 \(d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{2, 3\}\)。若 \(a \equiv 2\) 则 \(4 \equiv 3 \pmod p\)（不可能）；若 \(a \equiv 3\) 则 \(9 \equiv 2 \pmod p\)，得 \(p \mid 7\)（与 \(p \ge 11\) 矛盾）。
  - 若 \(2d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{2^{-1}, 3 \cdot 2^{-1}\}\)。若 \(a \equiv 2^{-1}\) 则 \(4^{-1} \equiv 3 \cdot 2^{-1}\)，即 \(1 \equiv 6 \pmod p\)，得 \(p \mid 5\)（矛盾）；若 \(a \equiv 3 \cdot 2^{-1}\) 则 \(9 \cdot 4^{-1} \equiv 2^{-1}\)，即 \(9 \equiv 2 \pmod p\)，得 \(p \mid 7\)（矛盾）。
  - 若 \(3d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{3^{-1}, 2 \cdot 3^{-1}\}\)。若 \(a \equiv 3^{-1}\) 则 \(9^{-1} \equiv 2 \cdot 3^{-1}\)，即 \(1 \equiv 6 \pmod p\)，得 \(p \mid 5\)（矛盾）；若 \(a \equiv 2 \cdot 3^{-1}\) 则 \(4 \cdot 9^{-1} \equiv 3^{-1}\)，即 \(4 \equiv 3 \pmod p\)（矛盾）。
- **情形二：** 等差数列为 \(\{-d', 0, d', 2d'\} \pmod p\)，即 \(\{1, a, a^2\} \equiv \{-d', d', 2d'\} \pmod p\)。
  - 若 \(-d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{-1, -2\}\)。因 \(a \not\equiv -1 \pmod p\)，只能 \(a \equiv -2\) 且 \(a^2 \equiv -1\)，得 \(4 \equiv -1 \pmod p\)，即 \(p \mid 5\)（矛盾）。
  - 若 \(d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{-1, 2\}\)。同理只能 \(a \equiv 2\) 且 \(a^2 \equiv -1\)，得 \(4 \equiv -1 \pmod p\)，即 \(p \mid 5\)（矛盾）。
  - 若 \(2d' \equiv 1\)，则 \(\{a, a^2\} \equiv \{-2^{-1}, 2^{-1}\}\)。若 \(a \equiv -2^{-1}\) 则 \(4^{-1} \equiv 2^{-1}\)，即 \(1 \equiv 2 \pmod p\)（矛盾）；若 \(a \equiv 2^{-1}\) 则 \(4^{-1} \equiv -2^{-1}\)，即 \(1 \equiv -2 \pmod p\)，得 \(p \mid 3\)（矛盾）。

综上，\(p \ge 11\) 均无解，唯一满足条件的素数是 \(p = 7\)。

**盲解结论**：满足条件的素数只有 \(p = 7\)。

### 2. 对照答案复盘

第一轮盲解结果完全正确，核心思路与参考解答高度一致：均先证明 \(p=7\) 成立，再对 \(p > 7\) 证明 \(a\) 必为模 \(p\) 的原根，进而通过取 \(\mathbb{F}_p\) 中的补集将“长为 \(p-4\) 的等差数列”转化为“长为 \(4\) 的等差数列” \(\{0, 1, c, c^2\}\)（盲解中用 \(a\)，参考解答用 \(c = a^{-1}\)）并分类导出矛盾。细微差别在于：构造 \(p=7\) 时盲解给出了 \(a=3, r=1\)，参考解答给出了 \(a=5, r=3\)，两者均合法；在排除 \(0\) 位于 \(4\) 项等差数列中间两项时，参考解答直接利用 \(\operatorname{ord}_p(c) = p-1 > 4\)（故任意两项不能互为相反数）一步否决，比盲解中逐一代入求解更加简洁优雅。

### 3. 困难点与破局关键

- **从序列长度界出 \(a\) 必为原根**：仅从 \(1, a, \dots, a^{p-5}\) 模 \(p\) 两两不同出发，利用 \(p > 7\) 时 \(p - 5 \ge \frac{p-1}{2}\)，将“局部的幂次互异”提升为“\(a\) 必为模 \(p\) 的原根”，从而得到整个 \(\mathbb{F}_p^\times\) 的结构信息。
- **补集转化将 \(p-4\) 项化归为 \(4\) 项等差数列**：正面处理长为 \(p-4\) 的等差数列很困难，但它在 \(\mathbb{F}_p\) 中的补集只有 \(4\) 个元素，且补集同样构成等差数列。这种“长等差数列取补变为短等差数列”的整体-局部转化是本题最关键的破局点。

### 4. 问题拆解（教学引导）

- **转译条件并挖掘互异性**：将“\(b_n - b_{n-1} - r\) 被 \(p\) 整除”翻译为模 \(p\) 意义下的同余条件 \(b_n \equiv b_0 + nr \pmod p\)。注意到 \(1 \le r \le p-1\) 意味着 \(r \not\equiv 0 \pmod p\)，且序列长度为 \(p - 4 < p\)，因此这 \(p - 4\) 项在模 \(p\) 下必定两两不同。
- **由元素个数估计乘法阶并分离边界 \(p = 7\)**：既然 \(1, a, \dots, a^{p-5}\) 模 \(p\) 两两不同，且当 \(p > 5\) 时 \(p - 5 \ge 2\)，立得 \(p \nmid a\)，且 \(a\) 模 \(p\) 的阶至少为 \(p - 4\)。比较 \(p - 4\) 与 \(p - 1\) 的最大真因子 \(\frac{p-1}{2}\)，发现只要 \(p > 7\) 就有 \(p - 4 > \frac{p-1}{2}\)（即 \(p - 5 \ge \frac{p-1}{2}\)），从而锁定 \(a\) 是原根；而 \(p = 7\) 成为需要单独检验的边界情况。
- **利用原根性质与补集思想降维**：当 \(a\) 是原根时，序列 \(1, a, \dots, a^{p-5}\) 只比整个模 \(p\) 剩余系 \(\mathbb{F}_p\) 少了 \(4\) 个元素：\(0\) 以及 \(a^{-3}, a^{-2}, a^{-1}\)。利用“\(\mathbb{F}_p\) 中等差数列的补集仍是等差数列”，把问题化归为仅有 \(4\) 个元素的等差数列判定。

### 5. 答案拆解（逻辑骨架）

- **处理边界 \(p = 7\) 并建立反证框架**（*动机*：先解决小素数边界 \(p = 7\)，为后续使用 \(p > 7\) 的强不等式扫清障碍。）：首先验证 \(p = 7\)：取 \(a = 5, r = 3\)（或 \(a = 3, r = 1\)），此时 \(1, a, a^2\) 可重排为 \(5, 1, 25\)，相邻差分别为 \(-4 \equiv 3 \pmod 7\) 和 \(24 \equiv 3 \pmod 7\)，满足条件。以下反证不存在 \(p > 7\) 的解。
- **证明 \(p > 7\) 时 \(a\) 必为原根**（*动机*：只有确定 \(a\) 是原根，才能准确知道 \(1, a, \dots, a^{p-5}\) 在 \(\mathbb{F}_p\) 中究竟遗漏了哪些元素。）：因为 \(r \nmid p\) 且长度 \(p - 4 < p\)，\(b_0, b_0+r, \dots, b_0+(p-5)r\) 模 \(p\) 两两不同，故 \(1, a, \dots, a^{p-5}\) 模 \(p\) 互异。由此 \(p \nmid a\)，且对任意 \(1 \le k \le p - 5\) 有 \(a^k \not\equiv 1 \pmod p\)。当 \(p > 7\) 时，素数 \(p \ge 11\) 满足 \(p - 5 \ge \frac{p-1}{2}\)，故 \(a\) 的阶不能整除任何不超过 \(\frac{p-1}{2}\) 的正整数，从而 \(a\) 必为模 \(p\) 的原根。
- **取补集并重参数化为 \(\{0, 1, c, c^2\}\)**（*动机*：通过取补集将长度随 \(p\) 变化的序列化为固定长度 \(4\) 的序列，并通过放缩（除以 \(c\)）使其中一项固定为 \(1\)，极大减少未知量。）：因 \(a\) 是原根，\(a^{-3}, a^{-2}, a^{-1}, 1, a, \dots, a^{p-5}\) 遍历 \(\mathbb{F}_p^\times\)；而 \(b_0 - 4r, b_0 - 3r, b_0 - 2r, b_0 - r, b_0, \dots, b_0 + (p-5)r\) 遍历整个 \(\mathbb{F}_p\)。令 \(c = a^{-1}\)，两者取补集即得 \(\{0, c, c^2, c^3\}\) 在 \(\mathbb{F}_p\) 中重排后构成 \(4\) 项等差数列。将该数列整体除以 \(c \not\equiv 0\)，仍为等差数列，故 \(\{0, 1, c, c^2\}\) 构成 \(4\) 项等差数列。
- **分类讨论并排除 \(4\) 项等差数列的所有可能**（*动机*：利用原根的阶排除 \(0\) 在中间的情形，再利用等差数列的倍数关系将剩下的有限种排列全部消去。）：若 \(0\) 不是该 \(4\) 项等差数列的首项或末项，则必有 \(1, c, c^2\) 中的某两项分别位于 \(0\) 的左右两侧，即这两项互为相反数（如 \(c \equiv -1\)，\(c^2 \equiv -1\) 或 \(c^2 \equiv -c\)）。然而 \(c = a^{-1}\) 也是模 \(p\) 的原根，其阶为 \(p - 1 > 4\)，而互为相反数会推出 \(c^2 \equiv 1\) 或 \(c^4 \equiv 1\)，矛盾。因此 \(0\) 必为首项或末项；将数列逆序（如有必要）后，可设首项为 \(0\)。又因 \(c \not\equiv 1\)，\(c - 1 \not\equiv c^2 - c\)，故后三项不能是 \(1, c, c^2\) 或 \(c^2, c, 1\)。对剩余 \(4\) 种排列 \((0, 1, c^2, c)\)、\((0, c^2, 1, c)\)、\((0, c, 1, c^2)\)、\((0, c, c^2, 1)\)，利用“第 \(3\) 项是第 \(2\) 项的 \(2\) 倍，第 \(4\) 项是第 \(2\) 项的 \(3\) 倍”，分别推出 \(p = 7\) 或 \(p = 5\)，均与 \(p > 7\) 矛盾。

### 6. 易错点分析

- **边界素数 \(p = 7\) 与小素数退化情形的漏判**：常见错法——忽略 \(p = 7\) 的边界情形，直接对所有 \(p > 5\) 断言 \(a\) 必为原根；或在后续解出 \(p = 5, 7\) 时未核对 \(p > 7\) 的假设。；错因——当 \(p = 7\) 时，\(\frac{p-1}{2} = 3 > p - 5 = 2\)，因此阶为 \(3\) 的元素也能使 \(1, a, a^2\) 互异（尽管实际上只有原根 \(a=3,5\) 满足等差条件），不能不加区分地把 \(p = 7\) 并入 \(p > 7\) 的反证过程；而 \(p = 5\) 则不满足题设 \(p > 5\)。；避坑策略——严格检查不等式 \(p - 5 \ge \frac{p-1}{2}\) 的解集（即 \(p \ge 9\)），并对 \(p = 7\) 单独构造验证（如 \(a = 3, r = 1\) 或 \(a = 5, r = 3\)），同时在后续同余方程求解时时刻对照 \(p > 7\) 的前提剔除 \(p = 3, 5, 7\)。
- **忽略 \(p \nmid a\) 与公差非零的条件验证**：常见错法——未先排除 \(p \mid a\) 或未说明为何 \(b_0, b_0+r, \dots, b_0+(p-5)r\) 模 \(p\) 两两不同，就直接取阶并声称 \(a\) 是原根。；错因——如果 \(r \equiv 0 \pmod p\) 或数列长度超过 \(p\)，重排后的等差数列就不再保证模 \(p\) 互异，从而无法推出 \(1, a, \dots, a^{p-5}\) 两两不同以及 \(p \nmid a\)。；避坑策略——先说明 \(p \nmid a\)（因 \(p - 5 \ge 2\) 时若 \(p \mid a\) 则 \(a \equiv a^2 \equiv 0 \pmod p\)），再严格从 \(r \not\equiv 0 \pmod p\) 与长度 \(p - 4 < p\) 推出互异性。
- **四项等差数列排列分类不完备**：常见错法——在分析 \(\{0, 1, c, c^2\}\) 构成 \(4\) 项等差数列时，漏掉 \(0\) 在中间的位置或混淆“公差”正负导致漏解或重复讨论。；错因——在有限域 \(\mathbb{F}_p\) 中等差数列没有大小顺序，只有“相邻差相等”的拓扑顺序；若随意假设某两项相邻或直接按大小排序，会导致漏掉合法排列。；避坑策略——注意到 \(0\) 在 \(\mathbb{F}_p\) 中的特殊性：若按“非零元素”或“位置”分类，应先利用乘法不变性把 \(0\) 和 \(1\) 固定下来，再用 \(\operatorname{ord}_p(c) = p - 1 > 4\) 排除 \(0\) 在中间的情形，最后逐一验证剩余 \(4\) 种排列。

**教学小结**：当题目在模 \(p\) 剩余系中给出一个长度接近 \(p\) 的子集（如长为 \(p-4\) 的等差数列）时，应立刻想到“取补集”将其转化为常数长度的集合；同时，幂次序列的互异性往往是迫使底数成为原根的强力信号。

## Putnam 2024 questions (Kedlaya archive community mirror) · A5（`putnam-2024-AB-questions-qA5`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 变量代换与重参数化 / 不变量与单调量 / 辅助线与几何变换 / 易错:隐含假设与越界推广 / 易错:极限与积分交换 / 易错:符号与方向
- **知识专题**：几何概型 / 积分与单调性 / 平面几何

### 原题整理

设圆 \(\Omega\) 的圆心为原点 \((0,0)\)、半径为 \(9\)，圆盘 \(\Delta\) 的圆心为 \((r,0)\)（其中 \(0 \le r \le 8\)）、半径为 \(1\)。在圆 \(\Omega\) 上独立且均匀随机地选取两点 \(P\) 和 \(Q\)。求使弦 \(\overline{PQ}\) 与圆盘 \(\Delta\) 相交的概率最小的 \(r\) 值。

### 1. 只看原题盲解尝试

**切入思路**：将圆上的两个独立均匀随机点 \(P, Q\) 用极角 \(\theta_1, \theta_2\) 表示，并作变量替换 \(\alpha = \frac{\theta_1+\theta_2}{2}\)、\(\beta = \frac{\theta_1-\theta_2}{2}\)，证明 \(\alpha, \beta\) 也可视为在 \([0,2\pi)\) 上独立均匀分布。利用 \(\Delta\) 包含于 \(\Omega\) 所围成的闭圆盘这一性质，将“弦 \(\overline{PQ}\) 与 \(\Delta\) 相交”等价转化为“圆心 \((r,0)\) 到直线 \(PQ\) 的距离不超过 \(1\)”，即 \(|r\cos\alpha - 9\cos\beta| \le 1\)。对 \(\beta\) 积分后可将概率 \(p(r)\) 写成关于 \(\alpha\) 的期望，通过求导证明被积函数关于 \(r \in [0,8]\) 严格单调递增，从而得到唯一最小值点 \(r=0\)。

**推演步骤**：
- 1. 几何等价转化：对任意点 \((x,y) \in \Delta\)，由三角不等式有 \(\sqrt{x^2+y^2} \le \sqrt{(x-r)^2+y^2} + r \le 1 + 8 = 9\)，故圆盘 \(\Delta\) 完全包含在 \(\Omega\) 所围成的闭圆盘 \(D\) 内。对于 \(\Omega\) 上任意不同的两点 \(P, Q\)（\(P=Q\) 的概率为 \(0\)），直线 \(PQ\) 与闭圆盘 \(D\) 的交集恰好是弦 \(\overline{PQ}\)。因此 \(\overline{PQ} \cap \Delta = \text{直线}PQ \cap \Delta\)，从而弦 \(\overline{PQ}\) 与 \(\Delta\) 相交当且仅当圆心 \(C=(r,0)\) 到直线 \(PQ\) 的距离不超过 \(1\)。
- 2. 参数化与概率空间转化：设 \(P = (9\cos\theta_1, 9\sin\theta_1)\)，\(Q = (9\cos\theta_2, 9\sin\theta_2)\)，其中 \(\theta_1, \theta_2\) 独立且均匀分布于 \([0, 2\pi)\)。考虑独立且均匀分布于 \([0, 2\pi)\) 的随机变量 \(\alpha, \beta\)，令 \(\tilde{\theta}_1 = (\alpha+\beta) \bmod 2\pi\)，\(\tilde{\theta}_2 = (\alpha-\beta) \bmod 2\pi\)。对任意整数 \(k, m\)（不同时为 \(0\)），有 \[\mathbb{E}[e^{i(k\tilde{\theta}_1 + m\tilde{\theta}_2)}] = \mathbb{E}[e^{i(k+m)\alpha}]\mathbb{E}[e^{i(k-m)\beta}] = 0,\] 由二维环面上的 Fourier 唯一性可知 \((\tilde{\theta}_1, \tilde{\theta}_2)\) 与 \((\theta_1, \theta_2)\) 同分布。因此可用独立均匀的 \(\alpha, \beta \in [0,2\pi)\) 来表示 \(\theta_1 = \alpha+\beta\)，\(\theta_2 = \alpha-\beta\)。
- 3. 距离条件表达式：对于 \(P \neq Q\)，验证直线 \(PQ\) 的方程为 \(x\cos\alpha + y\sin\alpha = 9\cos\beta\)（将 \(P\) 代入左边得 \(9\cos(\theta_1-\alpha) = 9\cos\beta\)，将 \(Q\) 代入左边得 \(9\cos(\theta_2-\alpha) = 9\cos(-\beta) = 9\cos\beta\)）。因为 \(\cos^2\alpha + \sin^2\alpha = 1\)，点 \(C=(r,0)\) 到直线 \(PQ\) 的距离为 \(|r\cos\alpha - 9\cos\beta|\)。于是所求概率为 \[p(r) = \mathbb{P}(|r\cos\alpha - 9\cos\beta| \le 1).\]
- 4. 对 \(\beta\) 条件积分：固定 \(\alpha \in [0,2\pi)\)，令 \(t = r\cos\alpha\)。由于 \(0 \le r \le 8\)，有 \(t \in [-8, 8]\)，从而 \(-1 \le \frac{t-1}{9} < \frac{t+1}{9} \le 1\)。条件 \(|t - 9\cos\beta| \le 1\) 等价于 \(\frac{t-1}{9} \le \cos\beta \le \frac{t+1}{9}\)。因为 \(\beta\) 在 \([0,2\pi)\) 上均匀分布，由对称性及 \(\cos\) 在 \([0,\pi]\) 上的单调性，该事件的条件概率为 \[\frac{1}{\pi}\left(\arccos\frac{t-1}{9} - \arccos\frac{t+1}{9}\right) = \frac{1}{\pi}\left(\arcsin\frac{t+1}{9} - \arcsin\frac{t-1}{9}\right) =: \frac{1}{\pi}h(t).\]
- 5. 单调性分析与结论：显然 \(h(-t) = h(t)\)，即 \(h\) 是 \([-8,8]\) 上的偶函数。对 \(t \in (0, 8)\) 求导得 \[h'(t) = \frac{1}{\sqrt{81 - (t+1)^2}} - \frac{1}{\sqrt{81 - (t-1)^2}}.\] 当 \(t > 0\) 时，\((t+1)^2 > (t-1)^2\)，故 \(81-(t+1)^2 < 81-(t-1)^2\)，从而 \(h'(t) > 0\)。结合 \(h\) 在 \([0,8]\) 上连续，可知 \(h(t)\) 在 \([0,8]\) 上严格单调递增。因此，对任意 \(0 \le r_1 < r_2 \le 8\) 及几乎处处的 \(\alpha \in [0,2\pi)\)（即 \(\cos\alpha \neq 0\)），都有 \(r_1|\cos\alpha| < r_2|\cos\alpha|\)，进而 \[h(r_1\cos\alpha) = h(r_1|\cos\alpha|) < h(r_2|\cos\alpha|) = h(r_2\cos\alpha).\] 对 \(\alpha\) 在 \([0,2\pi)\) 上取期望即得 \(p(r_1) < p(r_2)\)。故 \(p(r)\) 在 \([0,8]\) 上严格单调递增，在 \(r = 0\) 处取得唯一最小值。

**盲解结论**：\(r = 0\)

### 2. 对照答案复盘

盲做解法完全正确，得到了唯一最小值点 \(r=0\)，且整体思路与参考答案的第一解高度一致：参考答案第一解通过固定弦的倾斜角 \(\theta\) 并旋转坐标系使弦变为竖直线，得到弦端点参数 \((9\cos\phi, \pm 9\sin\phi)\)，再对积分函数 \(P(r)\) 关于 \(r\) 求导判定符号；盲做解法通过中点角与半差角 \((\alpha,\beta)\) 重参数化，用 Fourier 唯一性严格证明了 \((\alpha,\beta)\) 的独立均匀性，并对 \(\beta\) 积分后直接证明被积函数 \(h(r\cos\alpha)\) 关于 \(r\) 严格单调递增，从而避开了积分号下求导的边界奇性问题。此外，参考答案还给出了极为精妙的第二解（纯几何法）：将固定方向后的截弧长转化为平行线间最短弦长问题，一步得出最小弧长对应平行线中线过圆心（即 \(r=0\)）。

### 3. 困难点与破局关键

- **随机弦的解耦重参数化**：直接用两个独立角 \((\theta_1, \theta_2)\) 写距离条件会导致积分区域极为复杂。关键在于改用“弦的法向角/倾斜角”与“弦在法向上的位置角”进行重参数化，使两个参数依然保持独立均匀分布，从而把二维概率化为一维条件概率的期望。
- **单调性的解析验证或几何洞察**：固定弦的方向 \(\theta\) 后，被 \(\Delta\) 两条切线夹出的圆周弧长（或 \(\arccos\) 差值）关于 \(r\cos\theta\) 的单调性，既可以通过对 \(\arccos\) 求导验证，也可以从“劣弧长随弦长严格递增，而连接两平行线的最短线段为垂线段”这一纯几何事实直接看出。

### 4. 问题拆解（教学引导）

- **识别几何包容关系与数字线索**：注意到圆 \(\Omega\) 半径为 \(9\)，圆盘 \(\Delta\) 半径为 \(1\) 且圆心距 \(r \le 8\)，因此 \(r+1 \le 9\)，即 \(\Delta\) 完全落在 \(\Omega\) 所围成的闭圆盘内。这一数字设计（\(8+1=9\)）直接保证了“弦 \(\overline{PQ}\) 与 \(\Delta\) 相交”等价于“直线 \(PQ\) 与 \(\Delta\) 相交”（即圆心 \((r,0)\) 到直线 \(PQ\) 的距离不超过 \(1\)）。
- **选择合适坐标系解耦随机变量**：题目在 \(\Omega\) 上独立均匀选取 \(P, Q\)。若直接保留两点的极角 \(\theta_1, \theta_2\)，距离条件会混合 \(\theta_1\) 与 \(\theta_2\)。由此自然想到将弦的“方向”与“位置”分离，通过旋转坐标系或作和差角代换，把弦转化为一族平行弦来逐层求概率。
- **从“求值”转向“单调性比较”**：并不需要真的算出 \(p(r)\) 的封闭形式积分（含 \(\arccos\) 的积分通常无法初等求解），只需比较不同 \(r\) 下 \(p(r)\) 的大小，即判断 \(p(r)\) 关于 \(r\) 的单调性。

### 5. 答案拆解（逻辑骨架）

- **旋转降维与参数化**（*动机*：消除弦方向的自由度，使问题退化为一维区间截距问题。）：由于 \(P=Q\) 的概率为 \(0\)，可假定 \(P \neq Q\)。固定弦 \(\overline{PQ}\) 与 \(y\) 轴的夹角 \(\theta \in (-\pi/2, \pi/2]\)，将图形绕原点旋转 \(-\theta\)，使 \(\overline{PQ}\) 变为竖直线，此时 \(\Delta\) 的圆心变为 \((r\cos\theta, -r\sin\theta)\)。在旋转后的坐标系中，\(P, Q\) 可表示为 \((9\cos\phi, \pm 9\sin\phi)\)，其中 \(\phi \in (0,\pi)\) 均匀分布，且 \(\theta\) 与 \(\phi\) 相互独立均匀。之所以有效，是因为固定方向 \(\theta\) 等价于固定了对称轴，从而把二维独立点对化为“方向 \(\theta\) + 垂直位置 \(\phi\)”。
- **写出条件概率与总概率积分表达式**（*动机*：利用 \(\cos\phi\) 的单调性将相交条件显式化为 \(\phi\) 的弧长区间。）：竖直弦 \(\overline{PQ}\)（横坐标 \(9\cos\phi\)）与圆盘 \(\Delta\) 相交，当且仅当 \(9\cos\phi\) 落在 \(\Delta\) 的横坐标投影区间 \([r\cos\theta - 1, r\cos\theta + 1]\) 内（注意由 \(r \le 8\) 知该区间恒含于 \([-9, 9]\)）。由于 \(\cos\phi\) 在 \((0,\pi)\) 上严格递减，这等价于 \(\phi\) 落在区间 \([\arccos\frac{r\cos\theta+1}{9}, \arccos\frac{r\cos\theta-1}{9}]\) 内，故给定 \(\theta\) 时的条件概率为 \(\frac{1}{\pi}f(r,\theta)\)，其中 \(f(r,\theta) = \arccos\frac{r\cos\theta-1}{9} - \arccos\frac{r\cos\theta+1}{9}\)。对 \(\theta \in (-\pi/2, \pi/2]\) 平均即得 \(P(r) = \frac{1}{\pi^2}\int_{-\pi/2}^{\pi/2} f(r,\theta)\,d\theta\)。
- **解析法：求导判定单调性**（*动机*：避开无法初等积分的 \(\arccos\) 积分，直接通过导数符号判定最值位置。）：第一解对 \(P(r)\) 关于 \(r\) 求导（需注意 \(\frac{\partial f}{\partial r} = \cos\theta\big((81-(r\cos\theta+1)^2)^{-1/2} - (81-(r\cos\theta-1)^2)^{-1/2}\big)\) 在 \(\theta \in (-\pi/2,\pi/2), r>0\) 时严格大于 \(0\)，故 \(P'(r)>0\)，原参考解答末行写为 \(P'(r)<0\) 系笔误）。从而 \(P(r)\) 在 \([0,8]\) 上严格递增，唯一最小值在 \(r=0\) 处取得。这一步有效的原因是，无需算出积分，仅通过被积函数对参数的偏导数定号即可判定单调性。
- **几何法（第二解）：弧长与平行线间最短弦长**（*动机*：用纯粹的平面几何极值原理替代繁琐的微积分求导，揭示最值在每个方向 \(\theta\) 上逐点成立的本质。）：第二解指出 \(f(r,\theta)\) 本质上是单位圆上被两条距离为 \(2\) 的平行线所截出的两段全等劣弧之一的弧长。劣弧长随其两端点所连弦长严格递增；而连接两条距离为 \(2\) 的平行线的线段长度至少为 \(2\)，当且仅当该线段垂直于两平行线时取到最小值 \(2\)。此时两平行线的中线必过圆心（即对称位置 \(r\cos\theta = 0\)）。对所有方向 \(\theta\) 而言，唯有 \(r=0\) 能使中线对一切 \(\theta\) 都过圆心，从而同时在每个方向上取到严格最小值。

### 6. 易错点分析

- **混淆随机弦的概率测度（错用不变测度）**：常见错法——误套用 Crofton 公式或 Bertrand 悖论中的“不变直线测度”，认为圆盘 \(\Delta\) 只要完全在 \(\Omega\) 内部，被弦相交的概率就与圆心位置 \(r\) 无关。；错因——圆周上独立均匀取两点所生成的弦，其到圆心的距离 \(d = 9|\cos\beta|\) 并非均匀分布，而是具有密度 \(\frac{2}{\pi\sqrt{81-d^2}}\)，在靠近边界 \(d=9\) 处高度集中，因此圆盘越靠近边界越容易被弦击中。；避坑策略——明确题目给出的随机模型是“圆周上两点独立均匀”，而非“直线在平面上的运动不变测度”；通过显式参数化（如 \((\theta,\phi)\) 或 \((\alpha,\beta)\)）写出密度后再做判断。
- **忽略“线段相交”与“直线相交”的等价前提**：常见错法——未经检验就直接把“线段 \(\overline{PQ}\) 与 \(\Delta\) 相交”等价为“圆心 \((r,0)\) 到直线 \(PQ\) 的距离不超过 \(1\)”。；错因——若 \(\Delta\) 不完全包含于 \(\Omega\) 所围的闭圆盘内，直线 \(PQ\) 可以与 \(\Delta\) 相交但交点落在弦 \(\overline{PQ}\) 的延长线上。本题恰好给出 \(0 \le r \le 8\)（\(8+1=9\)）保证了等价性，解题时必须交代这一前提。；避坑策略——利用 \(r \le 8\) 与圆盘半径 \(1\) 验证 \(\Delta \subseteq \overline{D}(0,9)\)，显式说明 \(\overline{PQ} \cap \Delta = \text{直线}PQ \cap \Delta\)；若条件改为 \(r > 8\)，则必须额外排除“直线相交但线段不相交”的情形。
- **积分号下求导的符号失误与边界奇性**：常见错法——对 \(P(r)\) 在积分号下求导时弄反 \(\arccos\) 导数的符号，或忽略端点 \(r=8, \theta=0\) 处被积函数导数无界的收敛性验证。；错因——\(\frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1-x^2}}\) 带有负号，计算 \(\frac{\partial f}{\partial r}\) 时极易算反符号（事实上参考解答第一解的文本末尾也出现了写反 \(P'(r)\) 不等号的笔误）；此外在 \(r=8,\theta=0\) 处分母趋于 \(0\)，直接交换求导与积分需要 \((9-r\cos\theta-1)^{-1/2}\) 的可积性支撑。；避坑策略——尽量直接分析被积函数 \(h(t)\) 随 \(|t|\) 的单调性（无需跨积分号求导）；若使用积分号下求导，务必核对 \(\arccos'\) 的负号以及 \(r=8,\theta=0\) 处的反常积分收敛性。

**教学小结**：处理“圆上随机弦”的概率问题时，应优先通过旋转或和差角代换将弦的“方向”与“法向距离”解耦为独立参数；而在优化问题中，若积分无法初等求解，可通过被积函数的逐点单调性或对应的几何极值原理直接比较大小。

## Putnam 2024 questions (Kedlaya archive community mirror) · A6（`putnam-2024-AB-questions-qA6`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:压轴攻坚 / 生成函数与多项式 / 归纳与递推 / 算子与线性化 / 易错:边界与退化情形 / 易错:符号与方向 / 易错:计算精度与等价替换
- **知识专题**：Hankel行列式 / 生成函数 / 正交多项式与连分式

### 原题整理

设数列 \(c_0, c_1, c_2, \dots\) 满足：对充分小的 \(x\)，有
\[\frac{1 - 3x - \sqrt{1 - 14x + 9x^2}}{4} = \sum_{k=0}^\infty c_k x^k.\]
对正整数 \(n\)，设 \(A\) 为 \(n \times n\) 矩阵，其第 \(i, j\) 元为 \(c_{i+j-1}\)（\(1 \le i, j \le n\)）。求 \(A\) 的行列式。

### 1. 只看原题盲解尝试

**切入思路**：利用生成函数满足的二次方程，构造移位生成函数 \(g(x) = \sum_{m=0}^\infty c_{m+1} x^m\) 及其 Jacobi 连分式（J-fraction）对应的三项递推正交多项式，再通过线性泛函与形式幂级数归纳法将 Hankel 矩阵 \(A\) 合同对角化，从而直接求出其行列式。

**推演步骤**：
- 令 \(f(x) = \sum_{k=0}^\infty c_k x^k = \frac{1 - 3x - \sqrt{1 - 14x + 9x^2}}{4}\)。由 \(x=0\) 得 \(c_0 = 0\)。将 \(4f(x) - (1-3x) = -\sqrt{1-14x+9x^2}\) 两边平方并化简，得 \(2f(x)^2 - (1-3x)f(x) + x = 0\)。
- 记 \(a_m = c_{m+1}\)（\(m \ge 0\)），令 \(g(x) = \frac{f(x)}{x} = \sum_{m=0}^\infty a_m x^m\)，则 \(A_{i,j} = a_{i+j-2}\)。代入上式并除以 \(x\)，得 \(2x g(x)^2 - (1-3x)g(x) + 1 = 0\)，由此得 \(a_0 = g(0) = 1\) 及 \(a_1 = 3a_0 + 2a_0^2 = 5\)。
- 令 \(g_1(x) = \frac{g(x) - 1}{5x}\)，则 \(g_1(x)\) 为常数项为 \(1\) 的形式幂级数，且 \(g(x) = 1 + 5x g_1(x)\)。将其代入 \(2x g(x)^2 - (1-3x)g(x) + 1 = 0\) 并化简，得 \((1 - 7x)g_1(x) - 1 = 10x^2 g_1(x)^2\)；同时由 \(g(x)(1 - 3x - 2x g(x)) = 1\) 可得 \(g(x) - 1 - 5x g(x) = 2x g(x)(g(x) - 1) = 10x^2 g(x) g_1(x)\)。
- 定义线性泛函 \(\mathcal{L}: \mathbb{R}[t] \to \mathbb{R}\) 满足 \(\mathcal{L}(t^m) = a_m\)（\(m \ge 0\)），并定义首一多项式序列：\(P_0(t) = 1\)，\(P_1(t) = t - 5\)，以及对 \(k \ge 1\)，\(P_{k+1}(t) = (t - 7)P_k(t) - 10P_{k-1}(t)\)。
- 令 \(F_k(x) = \sum_{m=0}^\infty \mathcal{L}(P_k(t) t^m) x^m\)。对 \(k=0\) 有 \(F_0(x) = g(x)\)；对 \(k=1\) 有 \(F_1(x) = \frac{g(x)-1}{x} - 5g(x) = 10x g(x) g_1(x)\)。利用递推式与 \((1 - 7x)g_1(x) - 1 = 10x^2 g_1(x)^2\)，对 \(k\) 归纳可证：对所有 \(k \ge 0\)，均有 \(F_k(x) = 10^k x^k g(x) g_1(x)^k\)。
- 由于 \(g(0) = g_1(0) = 1\)，比较 \(F_k(x)\) 的系数可知：当 \(0 \le m < k\) 时 \(\mathcal{L}(P_k(t) t^m) = 0\)，且 \(\mathcal{L}(P_k(t) t^k) = 10^k\)。
- 设 \(P_r(t) = \sum_{s=0}^r L_{r,s} t^s\)（\(0 \le r \le n-1\)），则 \(L = (L_{r,s})_{0 \le r,s \le n-1}\) 为主对角元全为 \(1\) 的下三角矩阵（故 \(\det(L) = 1\)）。矩阵 \(M = L A L^T\) 的第 \((r, s)\) 元为 \(\mathcal{L}(P_r(t) P_s(t))\)。由上述正交性，当 \(r \neq s\) 时 \(M_{r,s} = 0\)，当 \(r = s\) 时 \(M_{r,r} = \mathcal{L}(P_r(t) t^r) = 10^r\)。因此 \(\det(A) = \det(L A L^T) = \prod_{r=0}^{n-1} 10^r = 10^{\frac{n(n-1)}{2}}\)。

**盲解结论**：\(\det(A) = 10^{\frac{n(n-1)}{2}}\)（即 \(10^{\binom{n}{2}}\)）

### 2. 对照答案复盘

盲解结果完全正确，最终答案 \(\det(A) = 10^{\frac{n(n-1)}{2}}\) 与参考解答完全一致。解题核心思路也高度吻合：参考解答通过构造一般幂级数的连分式（J-fraction）及其渐近分式分母 \(B_n(x)\)，在线性泛函 \(\int_\mu P(x) = \sum_i P_i c_{i+1}\) 下证明 \(B_n(x)\) 构成正交多项式族并将 \(A\) 合同对角化；盲解则是直接写出对应的三项递推首一多项式 \(P_k(t)\)（即参考解答中的 \(B_k(t)\)），用生成函数归纳法直接验证其正交性并完成合同对角化，无需先引入连分式渐近分式的通用理论，论证同样严密简洁。参考解答还附带了 Bjorn Poonen 提出的纯行列消元递归引理 \(h_n(\alpha) = h_{n-1}(\beta)\)，为本题提供了另一条完全初等的思路。

### 3. 困难点与破局关键

- **从 Hankel 矩阵转向正交多项式与线性泛函视角**：\(A_{i,j} = c_{i+j-1}\) 是典型的 Hankel 矩阵，直接按定义做高斯消元难以看出一般规律；必须识别出把矩阵条目视为线性泛函的矩 \(\mathcal{L}(t^{i+j-2})\)，从而将“求 Hankel 行列式”转化为“寻找对应正交多项式族的模方乘积”。
- **发现生成函数的自相似（周期连分式）结构**：对给定的根式生成函数 \(f(x)\)，需要先通过平方与代换 \(g_1(x) = \frac{f(x)/x - 1}{5x}\) 发现其二次方程呈现自相似结构 \((1-7x)g_1(x) - 1 = 10x^2 g_1(x)^2\)，即对应连分式从第二步起完全周期化（参数恒为 \(-7\) 与 \(-10\)）。

### 4. 问题拆解（教学引导）

- **计算前几项与低阶行列式以建立猜想**：先计算 \(n=1,2,3\) 的小规模情形：由生成函数展开得 \(c_0=0, c_1=1, c_2=5, c_3=35, c_4=295, c_5=2765\)，算得 \(\det(A)\) 依次为 \(1, 10, 1000\)，从而迅速猜出答案为 \(10^{\binom{n}{2}} = 10^{n(n-1)/2}\)。
- **识别 Hankel 结构并建立生成函数方程**：矩阵元仅依赖于 \(i+j\)，即 \(A\) 为 Hankel 矩阵。将生成函数写为 \(f(x) = \sum_{n=1}^\infty c_n x^n\)，通过消去根号得到 \(f(x)\) 满足的二次方程，进而考察其连分式展开或 \(g(x) = f(x)/x\) 的自相似方程。
- **引入线性泛函与正交多项式将矩阵对角化**：注意到对任意首一多项式序列 \(P_0, P_1, \dots, P_{n-1}\)（\(\deg P_r = r\)），若在泛函 \(\mathcal{L}(t^m) = c_{m+1}\) 下满足正交性 \(\mathcal{L}(P_r P_s) = d_r \delta_{r,s}\)，则通过幺幂三角矩阵的合同变换 \(L A L^T = \operatorname{diag}(d_0, \dots, d_{n-1})\) 即可直接求得 \(\det(A) = \prod_{r=0}^{n-1} d_r\)。

### 5. 答案拆解（逻辑骨架）

- **构造连分式与渐近分式递推**（*动机*：建立一般幂级数与连分式渐近分式之间的代数联系，为构造正交多项式提供显式递推。）：对于任意正规幂级数 \(f(x) = \sum_{n=1}^\infty c_n x^n\)（\(c_1 = 1\)），将其展开为连分式 \(\frac{a_0}{x^{-1}+b_0+\frac{a_1}{x^{-1}+b_1+\dots}}\)（\(a_0=1\)）。截断连分式得到的渐近分式 \(\frac{A_n(x^{-1})}{B_n(x^{-1})}\) 满足三项递推 \(B_{n+1}(t) = (t+b_n)B_n(t) + a_n B_{n-1}(t)\)，且有逼近阶 \(f(x) B_n(x^{-1}) - A_n(x^{-1}) = O(x^{n+1})\)。
- **推导出多项式族的正交性与模方公式**（*动机*：将连分式的有理逼近性质翻译为多项式族在矩泛函下的正交性。）：定义线性泛函 \(\int_\mu P(t) = \sum_i P_i c_{i+1}\)。由 \(f(x)B_n(x^{-1}) - A_n(x^{-1}) = O(x^{n+1})\) 中低次项消失，立得 \(\int_\mu t^i B_j(t) = 0\)（\(i < j\)）。再结合 \(B_{i+1}\) 的三项递推式，递推求得 \(\int_\mu t^i B_i(t) = (-1)^i a_1 \cdots a_i\)，从而 \(\int_\mu B_i(t) B_j(t) = (-1)^i a_1 \cdots a_i \delta_{ij}\)。
- **通过幺幂矩阵合同对角化计算 \(\det(A)\)**（*动机*：利用正交基对应的矩阵合同变换，将复杂的 Hankel 行列式化为对角矩阵的行列式。）：令 \(U\) 为以 \(B_i(t)\) 的系数为行的 \(n \times n\) 矩阵，由于 \(B_i\) 是首一多项式，\(U\) 为幺幂三角矩阵（\(\det U = 1\)）。矩阵 \(U A U^T\) 的 \((i,j)\) 元恰好为 \(\int_\mu B_{i-1}(t) B_{j-1}(t)\)，因此为对角矩阵，进而 \(\det(A) = (-1)^{n(n-1)/2} a_1^{n-1} a_2^{n-2} \cdots a_{n-1}\)。
- **求得本题连分式的周期参数并代入公式**（*动机*：确定本题生成函数对应的具体连分式参数 \(a_k\)。）：回到本题的 \(f(x) = \frac{1-3x-\sqrt{1-14x+9x^2}}{4}\)，引入 \(g(x) = \frac{1-7x-\sqrt{1-14x+9x^2}}{2x}\)，直接验证 \(f(x) = \frac{1}{x^{-1}-5-g(x)}\) 且 \(g(x) = \frac{10}{x^{-1}-7-g(x)}\)。于是连分式从第 2 步起呈周期结构，恒有 \(a_1 = a_2 = \dots = -10\)。代入通用公式即得 \(\det(A) = 10^{n(n-1)/2}\)。

### 6. 易错点分析

- **指标平移与 \(c_0=0\) 的混淆**：常见错法——将矩阵元素 \(c_{i+j-1}\) 误当成从 \(c_0\) 开始（即误把 \(c_0=0\) 当成左上角元素），或者在构造线性泛函时漏掉下标平移（写成了 \(\mathcal{L}(x^m) = c_m\)）。；错因——矩阵下标 \(i,j \ge 1\) 时 \(i+j-1 \ge 1\)，故矩阵只用到 \(c_1, c_2, \dots\) 而不含 \(c_0=0\)；若错用 \(c_0\) 会导致首项系数错误。；避坑策略——在定义 Hankel 矩阵和线性泛函之前，先显式写出 \(c_0 = 0\)、\(c_1 = 1\)，并令 \(a_m = c_{m+1}\)，确认 \(A_{1,1} = c_1 = a_0 = 1\) 与 \(n=1\) 时的行列式值。
- **连分式与递推系数中的符号错误**：常见错法——在连分式或三项递推中弄错系数符号（例如把 \(-10\) 写成 \(+10\)，或遗漏 \((-1)^{n(n-1)/2}\) 与连分式分子中的负号相消），导致最终答案多出 \((-1)^{n(n-1)/2}\)。；错因——连分式写法 \(\frac{a_0}{x^{-1} + b_0 + \frac{a_1}{x^{-1}+b_1+\dots}}\) 中 \(a_1 = -10\) 自带负号，它与正交积分公式中的 \((-1)^i\) 恰好抵消得到正数 \(10^i\)；符号一旦写反，偶数/奇数阶行列式符号就会出错。；避坑策略——算出通项公式后，务必用 \(n=1, 2, 3\) 手算前几项 \(c_1, c_2, c_3, c_4, c_5\) 与小阶行列式（\(1, 10, 1000\)）进行校验，确认正负号与幂次无误。
- **缺乏对基变换保行列式的严格说明**：常见错法——直接引用“J-连分式的 Hankel 行列式等于 \(\prod a_k^{n-k}\)”而不给出证明，或在矩阵合同变换中误以为任意基变换都保持行列式不变。；错因——竞赛评分要求论证完整，必须利用首一多项式对应矩阵为幺幂三角矩阵（行列式为 \(1\)）来保证 \(\det(U A U^T) = \det(A)\)。；避坑策略——在用正交多项式对角化之前，明确写出上三角/下三角基变换矩阵 \(U\)（或 \(L\)）的主对角元全为 \(1\)，并写出 \(U A U^T = D\)，从而严格说明 \(\det(A) = \det(D)\)。

**教学小结**：遇到元素形如 \(c_{i+j-1}\) 的 Hankel 行列式时，核心武器是将其视为线性泛函 \(\mathcal{L}(t^m) = c_{m+1}\) 下的矩矩阵，利用生成函数的连分式（J-fraction）或三项递推构造正交多项式族实现合同对角化；同时务必通过前几项手算低阶行列式来交叉验证猜想与符号。

## Putnam 2024 questions (Kedlaya archive community mirror) · B1（`putnam-2024-AB-questions-qB1`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:基础热身 / 构造与反例 / 奇偶与同余 / 易错:充分性与必要性混淆 / 易错:边界与退化情形
- **知识专题**：组合数学 / 排列与方格表

### 原题整理

设 \(n\) 和 \(k\) 为正整数。在一个 \(n \times n\) 的方格表中，第 \(i\) 行第 \(j\) 列的方格内填有数字 \(i + j - k\)（\(1 \le i, j \le n\)）。问：对于哪些 \(n\) 和 \(k\)，可以从方格表中选出 \(n\) 个方格，使得任意两个方格不同行也不同列，且所选方格中的数字恰好为 \(1, 2, \dots, n\)？

### 1. 只看原题盲解尝试

**切入思路**：首先通过计算所选 \(n\) 个方格中数字的总和，得出 \(n\) 必须为奇数且 \(k = \frac{n+1}{2}\) 的必要条件；随后对任意奇数 \(n = 2m - 1\) 与 \(k = m\)，通过模 \(n\) 平移构造显式排列 \(\pi\)，验证其恰好给出 \(1, 2, \dots, n\)，从而证明该条件也是充分的。

**推演步骤**：
- 将合法的选法对应为一个 \(\{1, 2, \dots, n\}\) 上的排列 \(\pi\)，即在第 \(i\) 行选择第 \(\pi(i)\) 列的方格（\(i = 1, 2, \dots, n\)）。所选方格中的数字为 \(i + \pi(i) - k\)。
- 必要性：若所选数字恰好为 \(1, 2, \dots, n\)，则它们的总和必为 \(\frac{n(n+1)}{2}\)。另一方面，直接求和可得 \[\sum_{i=1}^{n} \bigl(i + \pi(i) - k\bigr) = \sum_{i=1}^{n} i + \sum_{i=1}^{n} \pi(i) - nk = 2 \cdot \frac{n(n+1)}{2} - nk = n(n + 1 - k)\]。 令两者相等：\[n(n + 1 - k) = \frac{n(n+1)}{2}\]。 由于 \(n \ge 1\)，两边同除以 \(n\) 得 \(n + 1 - k = \frac{n+1}{2}\)，即 \(k = \frac{n+1}{2}\)。因为 \(k\) 为正整数，所以 \(n + 1\) 必须为偶数，即 \(n\) 为正奇数。
- 充分性：设 \(n = 2m - 1\)（\(m \ge 1\) 为正整数），\(k = \frac{n+1}{2} = m\)。构造映射 \(\pi: \{1, 2, \dots, n\} \to \{1, 2, \dots, n\}\) 如下：当 \(1 \le i \le m\) 时，令 \(\pi(i) = i + m - 1\)；当 \(m + 1 \le i \le 2m - 1\) 时，令 \(\pi(i) = i - m\)。
- 验证 \(\pi\) 是双射：当 \(1 \le i \le m\) 时，\(\pi(i)\) 取遍 \(\{m, m+1, \dots, 2m-1\}\)；当 \(m+1 \le i \le 2m-1\) 时，\(\pi(i)\) 取遍 \(\{1, 2, \dots, m-1\}\)。两者两两不同且并集恰好为 \(\{1, 2, \dots, 2m-1\} = \{1, 2, \dots, n\}\)，故 \(\pi\) 是一个合法的排列。
- 计算所选方格中的数字 \(i + \pi(i) - m\)：当 \(1 \le i \le m\) 时，\(i + (i + m - 1) - m = 2i - 1\)，取遍所有奇数 \(1, 3, \dots, 2m-1\)；当 \(m+1 \le i \le 2m-1\) 时，\(i + (i - m) - m = 2(i - m)\)，取遍所有偶数 \(2, 4, \dots, 2m-2\)。因此所选数字恰好为 \(1, 2, \dots, n\)。综上，当且仅当 \(n\) 为正奇数且 \(k = \frac{n+1}{2}\) 时满足条件。

**盲解结论**：当且仅当 \(n\) 为正奇数且 \(k = \frac{n+1}{2}\) 时可行。

### 2. 对照答案复盘

盲解与参考解答完全一致，结果正确。两者均先利用不同行不同列的性质，对所选 \(n\) 个数求和得出必要条件 \(n\) 为奇数且 \(k = \frac{n+1}{2}\)；随后均通过完全相同的两段式平移排列 \(\left(1, \frac{n+1}{2}\right), \dots, \left(\frac{n+1}{2}, n\right)\) 与 \(\left(\frac{n+3}{2}, 1\right), \dots, \left(n, \frac{n-1}{2}\right)\) 证明充分性。

### 3. 困难点与破局关键

- **用整体求和确定必要条件**：在没有任何具体构型的情况下，先从整体算术量（总和）入手，迅速锁定参数 \(k\) 与 \(n\) 的奇偶性限制，避免盲目试探。
- **分段斜线构造排列**：如何在保证行、列均为 \(\{1, \dots, n\}\) 的双射的同时，使 \(i + \pi(i) - \frac{n+1}{2}\) 恰好不重不漏地覆盖 \(\{1, \dots, n\}\)；关键在于利用斜线平移使相邻两步的和相差 \(2\)，从而分别生成奇数序列与偶数序列。

### 4. 问题拆解（教学引导）

- **识别排列结构**：“选出 \(n\) 个不同行不同列的方格”等价于选取一个 \(\{1, 2, \dots, n\}\) 上的排列，使得行指标 \(a_1, \dots, a_n\) 与列指标 \(b_1, \dots, b_n\) 均遍历 \(\{1, 2, \dots, n\}\)。
- **从整体不变量（求和）切入**：既然 \(a_i\) 和 \(b_i\) 各自是 \(\{1, \dots, n\}\) 的排列，而目标数字 \(a_i + b_i - k\) 也是 \(\{1, \dots, n\}\) 的排列，它们的总和具有确定的封闭表达式，这是寻找必要条件的天然切入点。
- **小规模试算并推广构造**：在确定 \(n\) 必为奇数且 \(k = \frac{n+1}{2}\) 后，尝试 \(n=3, 5\) 的小规模例子，观察选出的格子在矩阵中的几何位置，总结出通项构造。

### 5. 答案拆解（逻辑骨架）

- **必要性证明（求和法）**（*动机*：利用行、列指标各自求和的固定值建立关于 \(n, k\) 的方程，从而排除所有不可能的参数组合。）：设选出的 \(n\) 个方格为 \((a_1, b_1), \dots, (a_n, b_n)\)。由于不同行不同列，\(\sum_{i=1}^n a_i = \sum_{i=1}^n b_i = \frac{n(n+1)}{2}\)。若所选数字为 \(1, \dots, n\)，则 \[\frac{n(n+1)}{2} = \sum_{i=1}^{n}(a_i + b_i - k) = 2 \cdot \frac{n(n+1)}{2} - nk,\] 化简得 \(k = \frac{n+1}{2}\)。因 \(k\) 为整数，故 \(n\) 必为正奇数。
- **充分性构造（两段斜线）**（*动机*：为了使 \(i + j - \frac{n+1}{2}\) 以步长 \(2\) 递增，让行号与列号同步每次加 \(1\)（并在列号到达 \(n\) 后模 \(n\) 回绕到 \(1\)）。）：当 \(n\) 为奇数且 \(k = \frac{n+1}{2}\) 时，顺次选取前 \(\frac{n+1}{2}\) 个方格 \(\left(1, \frac{n+1}{2}\right), \left(2, \frac{n+3}{2}\right), \dots, \left(\frac{n+1}{2}, n\right)\)，再回绕选取后 \(\frac{n-1}{2}\) 个方格 \(\left(\frac{n+3}{2}, 1\right), \dots, \left(n, \frac{n-1}{2}\right)\)。显然行号遍历 \(1, \dots, n\)，列号依次遍历 \(\frac{n+1}{2}, \dots, n\) 与 \(1, \dots, \frac{n-1}{2}\)，构成合法选法。
- **验证数值覆盖**（*动机*：严格验证所构造的方格中填入的数字确实不重不漏地覆盖目标集合。）：前半段方格中的数字为 \(i + \left(i + \frac{n-1}{2}\right) - \frac{n+1}{2} = 2i - 1\)，随 \(i\) 从 \(1\) 增至 \(\frac{n+1}{2}\)，依次取遍所有奇数 \(1, 3, \dots, n\)；后半段方格中的数字为 \(i + \left(i - \frac{n+1}{2}\right) - \frac{n+1}{2} = 2i - n - 1\)，随 \(i\) 从 \(\frac{n+3}{2}\) 增至 \(n\)，依次取遍所有偶数 \(2, 4, \dots, n-1\)。两者合并恰好为 \(\{1, 2, \dots, n\}\)。

### 6. 易错点分析

- **混淆必要性与充分性**：常见错法——仅通过求和算出 \(k = \frac{n+1}{2}\) 便直接下结论，未证明当 \(n\) 为奇数时确实存在满足条件的选法。；错因——求和相等只是所选数字能构成 \(\{1, 2, \dots, n\}\) 的必要条件，而非充分条件；完全有可能在某类组合问题中和相等但无法凑出目标多重集。；避坑策略——在求出 \(k = \frac{n+1}{2}\) 后，必须显式写出对任意奇数 \(n\) 的排列构造，并逐一验证行号、列号均在 \(\{1, \dots, n\}\) 内且互不相同，以及所得数字集合恰好为 \(\{1, \dots, n\}\)。
- **构造排列时越界或漏算回绕**：常见错法——构造“斜线”时直接写 \(j = i + \frac{n-1}{2}\)，忽略列指标超出 \(n\) 后的回绕处理，或回绕时写错偏移量导致数字重复。；错因——若不分段取模，列指标会超过 \(n\)；若回绕公式写错（例如写成 \(i - \frac{n-1}{2}\) 而非 \(i - \frac{n+1}{2}\)），则会导致某些列被重复选取或漏选，且生成的数字不再是连续的偶数。；避坑策略——按 \(i \le \frac{n+1}{2}\) 与 \(i > \frac{n+1}{2}\) 分段写出列指标公式，并在 \(n=1\)（此时第二段为空）及 \(n=3, 5\) 等小情形下代入检验。

**教学小结**：面对“对于哪些参数可行”的存在性问题，先用求和、奇偶性等整体不变量卡出必要条件，再通过小规模特例归纳出具有规律性（如模 \(n\) 平移）的显式构造以完成充分性证明，是组合竞赛中最经典的双步策略。

## Putnam 2024 questions (Kedlaya archive community mirror) · B2（`putnam-2024-AB-questions-qB2`）

- **学段**：本科 · **盲解结果**：盲解完全正确
- **教学标签**：训练:技巧进阶 / 不变量与单调量 / 辅助线与几何变换 / 反证与分类讨论 / 易错:隐含假设与越界推广 / 易错:符号与方向 / 易错:边界与退化情形
- **知识专题**：平面几何 / 不变量与抽屉原理 / 四边形与三角恒等式

### 原题整理

如果两个凸四边形有三个公共顶点，并且可以分别标记为 \(ABCD\) 和 \(ABCE\)，使得 \(E\) 是 \(D\) 关于对角线 \(\overline{AC}\) 的垂直平分线的对称点，则称这两个凸四边形互为“伙伴”（partners）。是否存在一个由凸四边形组成的无穷序列，使得序列中的每个凸四边形都是其后继的伙伴，且序列中任意两个凸四边形都不全等？

### 1. 只看原题盲解尝试

**切入思路**：Show that the partner relation preserves both the multiset of four side lengths and the area of the convex quadrilateral. Then prove that for any fixed multiset of four positive side lengths and fixed positive area, there are only finitely many congruence classes of convex quadrilaterals. By the Pigeonhole Principle, no infinite sequence of pairwise non-congruent quadrilaterals can exist, so the answer is No.

**推演步骤**：
- 1. Invariance of side lengths: Let \(ABCD\) and \(ABCE\) be partners, where \(E\) is the reflection of \(D\) across the perpendicular bisector of \(\overline{AC}\). Since this reflection is an isometry swapping \(A\) and \(C\) and mapping \(D\) to \(E\), we have \(CE = AD\) and \(EA = CD\). Thus \(ABCD\) and \(ABCE\) have the same multiset of side lengths \(\{a, b, c, d\}\). By induction, every quadrilateral in the sequence has the same multiset of side lengths.
- 2. Invariance of area: Because \(\overline{AC}\) is a diagonal of the convex quadrilateral \(ABCD\), \(B\) and \(D\) lie on opposite sides of line \(AC\). The perpendicular bisector of \(\overline{AC}\) is perpendicular to \(AC\), so reflecting \(D\) across it keeps \(E\) on the same side of \(AC\) as \(D\), hence opposite to \(B\). Thus \(\overline{AC}\) is also a diagonal of \(ABCE\). Since \(\triangle ACE \cong \triangle CAD\) by the reflection, \(\operatorname{Area}(ABCE) = \operatorname{Area}(\triangle ABC) + \operatorname{Area}(\triangle ACE) = \operatorname{Area}(\triangle ABC) + \operatorname{Area}(\triangle ACD) = \operatorname{Area}(ABCD)\). By induction, every quadrilateral in the sequence has the same area \(K > 0\).
- 3. Finiteness of congruence classes: There are at most \(4! = 24\) ways to assign the side lengths \(\{a, b, c, d\}\) in cyclic order as \((s_1, s_2, s_3, s_4)\) to the sides \(P_1 P_2, P_2 P_3, P_3 P_4, P_4 P_1\) of a convex quadrilateral \(P_1 P_2 P_3 P_4\). Fix one such ordering, and let \(\alpha = \angle P_1 P_2 P_3 \in (0, \pi)\) and \(\gamma = \angle P_3 P_4 P_1 \in (0, \pi)\). Using the area formula \(2s_1 s_2 \sin\alpha + 2s_3 s_4 \sin\gamma = 4K\) and the Law of Cosines on \(P_1 P_3^2\), \(2s_1 s_2 \cos\alpha - 2s_3 s_4 \cos\gamma = s_1^2 + s_2^2 - s_3^2 - s_4^2\), squaring and adding gives \(4s_1^2 s_2^2 + 4s_3^2 s_4^2 - 8s_1 s_2 s_3 s_4 \cos(\alpha + \gamma) = (s_1^2 + s_2^2 - s_3^2 - s_4^2)^2 + 16K^2\). Since \(s_1 s_2 s_3 s_4 > 0\), \(\cos(\alpha + \gamma)\) is uniquely determined, leaving at most \(2\) possible values for \(\theta = \alpha + \gamma \in (0, 2\pi)\).
- 4. Uniqueness up to finitely many choices: For each such \(\theta \in (0, 2\pi)\), substituting \(\gamma = \theta - \alpha\) into the Law of Cosines equation gives \((2s_1 s_2 - 2s_3 s_4 \cos\theta)\cos\alpha - (2s_3 s_4 \sin\theta)\sin\alpha = s_1^2 + s_2^2 - s_3^2 - s_4^2\). The two coefficients cannot both be \(0\) (if \(\sin\theta = 0\), then \(\theta = \pi\) so \(\cos\theta = -1\) and \(2s_1 s_2 + 2s_3 s_4 > 0\)). Thus the left-hand side can be written as \(R \cos(\alpha - \phi)\) with \(R > 0\), which has at most \(2\) solutions for \(\alpha \in (0, \pi)\). Each \(\alpha\) uniquely determines \(\triangle P_1 P_2 P_3\) by SAS, hence \(P_1 P_3\), and hence \(\triangle P_1 P_4 P_3\) by SSS on the opposite side of \(P_1 P_3\), determining the quadrilateral up to congruence. Therefore there are at most \(24 \times 2 \times 2 = 96\) congruence classes, so any infinite sequence must contain congruent quadrilaterals.

**盲解结论**：No, there is no such infinite sequence of convex quadrilaterals. Every partner step preserves both the multiset of side lengths and the area, and there are only finitely many congruence classes of convex quadrilaterals with a given multiset of side lengths and a given area.

### 2. 对照答案复盘

Turn 1 盲解完全正确（outcome: correct），结论（“不存在”）与整体证明路线和参考解答的 First Solution 完全一致：先证明伙伴变换保持四条边长的多重集与四边形面积不变，再证明给定四条边长顺序与面积后，凸四边形的全等类至多只有有限个，最后由抽屉原理得出矛盾。细节上，参考解答的 First Solution 在证明“有限个全等类”时直接调用 Bretschneider 公式并利用对角线长度 \(f=\overline{PR}\) 增大时对角和 \(\angle SPQ+\angle QRS\) 严格递减的单调性，论证极为简洁；Turn 1 盲解则从面积公式与余弦定理现场推导出了等价的角和余弦表达式，并通过三角线性方程非退化性证得解的有限性，同样严谨且不依赖记忆公式。此外，参考解答还给出了基于外接/垂直平分线交点 \(O\) 不变量的 Second Solution，几何视角更为巧妙。

### 3. 困难点与破局关键

- **识别足够多的几何不变量以消除连续自由度**：固定四条边长并不足以限制全等类为有限（四连杆可连续形变）。必须同时捕捉到“面积 \(K\) 也保持不变”（第一解法）或“两对角线垂直平分线交点 \(O\) 到四顶点距离保持不变”（第二解法），从而将自由度从 \(1\) 降为 \(0\)。
- **严谨证明“边长与面积确定时全等类有限”**：即使固定了边长顺序 \((a,b,c,d)\) 和面积 \(K\)，直接求解顶点坐标或内角容易陷入复杂代数消元；需要借助布雷特施奈德公式配合对角线长度的单调性（或直接对余弦定理与面积公式平方相加消去单角）来严谨说明只有有限个解。

### 4. 问题拆解（教学引导）

- **拆解“伙伴”变换的几何作用**：先剖析“伙伴”变换的几何本质：\(E\) 是 \(D\) 关于对角线 \(\overline{AC}\) 垂直平分线的对称点。该反射把 \(A\) 与 \(C\) 互换、把 \(D\) 映为 \(E\)，且保持直线 \(AC\) 两侧的半平面不变，因此 \(\overline{AC}\) 依然是 \(ABCE\) 的对角线。
- **寻找步进变换下的不变量**：看到“无穷序列且两两不全等”的否定性问题，优先寻找在单步变换下保持不变的量（不变量）。反射是等距变换，直接给出 \(CE=AD, EA=CD\) 以及 \(\triangle ACE \cong \triangle CAD\)，由此立刻锁定两个关键不变量：四条边长的多重集，以及四边形的面积 \(K\)。
- **将问题归约为全等类的有限性**：由于后续步骤可以任意重新标号三个公共顶点，边长的循环顺序只可能有有限种（最多 \(4!=24\) 种，不计对称最多 \(3\) 种）。问题转化为：给定边长顺序 \((a,b,c,d)\) 与面积 \(K\)，满足条件的凸四边形是否只有有限个全等类？若是，则由抽屉原理即得“不存在”。

### 5. 答案拆解（逻辑骨架）

- **第一步：证明边长多重集与面积的不变性**（*动机*：利用反射的等距性与对称性，确立全序列共享的两个全局不变量。）：设 \(ABCD\) 与 \(ABCE\) 为伙伴，记关于 \(\overline{AC}\) 垂直平分线的反射为 \(\sigma\)。由于 \(\sigma(A)=C, \sigma(C)=A, \sigma(D)=E\)，可得 \(CE=AD, EA=CD\)，故四条边长的多重集不变。又因 \(\sigma\) 保持直线 \(AC\) 两侧半平面不变，\(B\) 与 \(E\) 仍在 \(AC\) 异侧，所以 \(\overline{AC}\) 也是 \(ABCE\) 的对角线，且 \([\triangle ACE]=[\triangle ACD]\)，从而总面积 \(K\) 不变。由归纳法，序列中所有四边形都有相同的边长多重集和相同的面积 \(K\)。
- **第二步：建立对角线长度与对角和的单调关系**（*动机*：用单一参数 \(f=\overline{PR}\) 刻画四连杆的自由度，并建立角和与 \(f\) 的单调对应，为有限性奠定基础。）：固定边长按循环顺序为 \((a,b,c,d)\)，记对角线 \(f=\overline{PR}\)。一旦 \(f\) 确定，三角形 \(PQR\) 与 \(PRS\) 的三边均确定，故四边形 \(PQRS\) 在全等意义下唯一确定。在 \(\triangle PQR\) 与 \(\triangle PRS\) 中，随着 \(f\) 严格增大，由余弦定理知 \(\angle RPQ\) 与 \(\angle RPS\) 均严格减小，从而 \(\angle SPQ = \angle RPQ + \angle RPS\) 严格减小；同理 \(\angle QRS\) 也严格减小。因此 \(\angle SPQ + \angle QRS\) 是关于 \(f\) 的严格递减函数。
- **第三步：结合布雷特施奈德公式与抽屉原理收尾**（*动机*：将面积不变量转化为角和的有限性，再通过单调性回到全等类的有限性，完成抽屉原理闭环。）：记半周长 \(s=(a+b+c+d)/2\)，由布雷特施奈德公式：
\[K^2 = (s-a)(s-b)(s-c)(s-d) - abcd \cos^2\left(\frac{\angle SPQ + \angle QRS}{2}\right).\]
当 \(a,b,c,d,K\) 固定时，\(\cos^2\left(\frac{\angle SPQ+\angle QRS}{2}\right)\) 唯一确定。因为 \(\angle SPQ+\angle QRS \in (0,2\pi)\)，故其至多只有两个可能值；结合第二步的严格单调性，至多对应两个 \(f\) 值，即至多两个全等类。由于边长多重集最多产生有限种循环排列，整个序列只能落入有限个全等类中，不可能无穷且两两不全等。

### 6. 易错点分析

- **忽略凸性与对角线位置的保持及重新标号的影响**：常见错法——认为 \(ABCD \to ABCE\) 只是把 \(D\) 对称过去，直接声称“边长集合和面积不变”却未说明为什么 \(\overline{AC}\) 仍然是 \(ABCE\) 的对角线，或忽略后续步骤中允许重新标号 \(A,B,C,D\)。；错因——若不说明 \(B\) 与 \(E\) 仍在直线 \(AC\) 异侧，就无法直接把 \(ABCE\) 的面积拆成 \([\triangle ABC]+[\triangle ACE]\)；若误以为每一步都固定同一条对角线 \(\overline{AC}\)，则会漏掉“重新标号后边长顺序可以重排，但作为多重集依然不变”这一关键点。；避坑策略——严格利用“反射是等距变换”和“\(AC\) 垂直平分线的反射保持 \(AC\) 两侧半平面不变”来证明 \(CE=AD, EA=CD\) 且 \(\overline{AC}\) 仍是 \(ABCE\) 的对角线，避免只靠直观画图下结论。
- **误以为四条边长固定就能唯一确定四边形**：常见错法——仅发现四条边长多重集不变，就误以为只有有限个全等类；或者误以为任意四条边长确定后四边形就刚性固定。；错因——四连杆机构在四条边长固定时可以连续形变，因此仅固定四条边长对应无穷多个互不全等的凸四边形。；避坑策略——必须再引入面积 \(K\)（或利用布雷特施奈德公式/对角线单调性/三角方程）证明在边长与面积同时固定时全等类只有有限个。
- **从有限个角和值到有限个全等类时漏掉退化或单调性论证**：常见错法——在利用余弦定理与面积公式消元时，没有验证方程不会退化为恒等式（即无穷多解），或忘记讨论 \(\cos^2(\frac{\alpha+\gamma}{2})\) 对应两个互补的角和值。；错因——一个三角方程若系数全为零会有无穷多解；直接断言“角和确定则四边形只有有限个”而不说明单调性或非退化性，证明是不完整的。；避坑策略——若用三角方程法，需显式验证 \(\cos\alpha\) 与 \(\sin\alpha\) 的系数不同时为零（利用 \(\alpha+\gamma \in (0,2\pi)\)）；若用参考解答的单调性法，需明确指出当对角线 \(f\) 增大时，\(\angle RPQ, \angle RPS\) 均严格减小，从而 \(\angle SPQ + \angle QRS\) 严格单调递减。

**教学小结**：面对“在局部几何变换下能否生成无穷多个互不全等图形”的问题，核心策略是寻找足以锁定连续自由度的不变量（如边长集合与面积，或如第二解法中两条对角线垂直平分线的交点 \(O\)），再借助单调性或代数有限性配合抽屉原理证明其必然重复。
